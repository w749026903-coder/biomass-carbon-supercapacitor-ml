# 循环稳定性数据库 v0.1

2026-10-17。此版本已实际建库，状态为“候选数据库”；正式训练视图仍为空。

首先打开《数据库查看.html》，可按文献、材料样品、循环终点和待核问题查看。原始论文仍在D:/文献，查看页提供本地原文链接。

主文件为`cycling_v0_1.sqlite`。已登记当前126篇文献、137份正文/补充/可读文本文件，录入89个循环候选终点，来自51篇来源、67个暂定材料编号和83次测试。另存73条材料表征观测、2492条字段证据、234条待核事项。观测与问题的条数不代表独立样本数。

## 数据的层级

| 表 | 一行表示什么 |
|---|---|
| papers | 一篇当前在库文献；方法背景/范围外资料也留目录身份，不冒充实验样本 |
| source_files | 一份有哈希的正文、SI或XML对应的可读文本 |
| materials | 论文内一个原样品名的暂定材料身份 |
| material_observations | 一条表征报告值，保留测法、单位、阶段、来源；相同材料在多个终点重复引用不增加材料数 |
| cycling_tests | 同一材料在一套循环协议下的一次测试 |
| cycling_endpoints | 该测试在某个循环次数的报告保持率 |
| raw_records / field_evidence | 导入前完整摘录，以及逐字段原值、空值、出处和核验状态 |
| issues / admissions | 原有冻结、新发现的问题，以及逐记录准入决定 |
| source_relationships | 已知数据复用或待核的来源关系 |

同一曲线的多个终点共用测试编号，同一样品跨体系共用材料编号。新补充编号N001/N002/N004/N005/N009已映射为SRC123–SRC127，旧编号与完整原始JSON仍可追溯。R107两个循环节点没有变成两个材料；R112两/三电极没有合并为一次测试。

## 可用视图

`endpoint_review`保留全部89条候选。`primary_screening_candidates`是两电极对称、明确GCD、暂定碳材料、精确点值、至少1000次且未标冲突等条件下的优先核录队列，共12终点/10暂定材料/10篇；它是工作队列，不能直接训练。1000次是本项目筛查边界，不是普遍质量标准。

`training_ready`只接收完成来源、材料、协议、基线、质量分母、独立性和冻结核查的明确准入记录。目前0行。表的检查约束阻止“只把eligible改成1”绕过其他核查。未因为本次建库自行解除冻结。

## 核验与使用边界

完整性、外键、唯一性、重复节点、原值保留、超过100%保持率不截断、分组泄漏拦截等16项检查通过。所有导入输入有SHA256；核验见《数据库与建模入口核验.json》与《数据库核验与覆盖摘要.json》。复核代码和已运行的SQL结果另存《数据库复核.ipynb》。

缺失统计仅说明当前摘录尚未配对，不能证明原文没有报告。约等于值和下限保持原关系；R018、R069等冲突保留，R091孔体积印刷单位未擅改，EDS与XPS没有合并。

`exports`保存JSON读取副本；主数据与关联约束在SQLite中。`build_database.py`拒绝覆盖本版本数据库，后续补录应创建v0.2等新版本并记录差异；不要通过删除数据库来重跑旧快照。

模型思路见《建模思路.md》。随机森林、XGBoost、MLP与两种简单基线共用按来源分组的嵌套比较流程。配置和未来入口在`modeling`；默认运行只检查数据，不拟合模型。当前缺少scikit-learn/XGBoost，未安装依赖、未运行拟合分支，因此不能把代码存在说成模型已经完成。

筹备阶段已实际完成数据库和预检查；逐记录终审、补缺、训练数据发布、模型拟合及独立验证仍需继续。文献库与旧候选快照保持不变。
