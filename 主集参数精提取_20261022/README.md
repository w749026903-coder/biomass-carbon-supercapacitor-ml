## 防止把不同参数混在一起

- **KAC-5：先800°C碳化，再600°C活化**，两步均2 h、5°C/min；没有把800°C写成活化温度。
- **SS-300：先300°C预碳化，再600°C活化**；样品后缀不是最终活化温度。
- **NCHU20：200°C前处理20 min、10°C/min；700°C活化90 min。** 原文没有给活化升温速率，不能把前处理速率移过去，也没有把该前处理擅称水热过程。
- **AHPC：500°C预碳化与700/800/850/900°C活化分开。** 原文未明确活化升温速率，保留未知；AC-850是无KOH对照，没有活化温度点值，也未借用其它样品的1.5 h。
- **QSC、CA-AA、AO-PC、稻草AC、SC-0.03等**的独立碳化步骤单列，不强填为化学活化。QSC-2/3/4的800°C活化不传给QSC对照。
- **EUAC1-60：900 W微波处理60 min。** 功率不是温度；1 h标注为总微波作用时间，不冒称等温炉保温时间。
- **OAC623：673 K活化对应399.85°C，623 K氧化对应349.85°C。** 这是名义单位换算，不增加仪器测量精度；氧化速率不作为活化速率。
- **WET-1/DRY-1负载约10 mg/cm²**为作者明确值，保留而不按常见范围裁剪。SC-0.03的8 mg活性物质/明确1 cm²涂布面积按名义值记录。

YZPC、CA-AA、OPB系列负载范围分别保留；RMAC、CCL等只有电极质量范围、有效涂布面积未闭合，不转成mg/cm²。ALPC的ORR催化墨水与超级电容器电极分别阅读；超级电容器3E名义负载1.2 mg/cm²，不借用ORR的5 mg墨水原料或器件总质量。所有负载只绑定实际测试，未随材料跨3E/2E传播。
