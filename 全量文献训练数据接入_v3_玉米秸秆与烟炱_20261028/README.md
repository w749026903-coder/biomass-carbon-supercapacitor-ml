## 科学审查

玉米酸洗后仍有SiO₂，属于天然残留分用途；烟炱含原生无机组分，材料属性单列用途。都不混入普通生物质碳训练主集。烟炱表3/4吸附数据与传感CV仅作原始响应/上下文，91%/99%不是循环保持率；平均颗粒尺寸的独立测量方法未报告，且数值与6000/SBET一致，保留待查，不当独立SEM直径。

CS-1000 BET表6.6534、正文6.70不是能直接解释的两位四舍五入；两值都保留，BET不进本版输入/目标。CS-600/800按明确表精度与正文粗精度保存，不凭性能挑值。烟炱AP/PS的N表项与EDS谱图/正文不一致，N重量字段冻结；谱图不显峰也不代表0。部分元素总和不足100，空白未知，不补零、不重新归一化。

玉米器件作者称单电极电容，Eq5使用双电极总质量。独立保留作者公式经验用途，不推乘2/4。原候选 `candidate:B20:B2_012:1` 精确关联CS-800自身材料，49个规范循环有材料身份链接，主3E仍17条；循环原值、标签、基线状态与准入完全不改，保留93.75/93.7及原图层级歧义。该候选不属于固定37条，不能抵扣审查待证数。

主三电极仍47/34、双电极31/25；普通三电极比电容208/31与含图386/31仍嵌套；原37待证、15历史字段冻结、苏铁掩码不动。本轮拟合0/新循环准入0，不能声称旧模型误差降低。
