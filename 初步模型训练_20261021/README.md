## 方法与边界

每次整组留出一个来源，来源中的所有样品/终点一起离开训练集；23折后每条记录恰有一次未见来源预测。特征编码、数值缩放仅用训练折；MLP目标中心/标准差也只用该训练折及来源权重。缺少的参比/电解液类别进入UNKNOWN通道，不从验证集学习类别。

三个模型均传入样本权重，同来源总训练权重相同，拟合时归一到样本平均权重1；评分以每来源等权的MAE、RMSE及所有留出预测的加权R²汇总。单条来源折不单独计算R²；训练MAE只作为训练折内回代诊断。参数在训练前固定，没有内层搜索，因此本轮无需用内层选择参数；后续若调参则必须使用内外层来源分组。

MAE/RMSE单位为百分点；标签保留文献原报告工况，含超过100%的保持率。95%区间为2000次来源组重采样、固定种子20261021的描述性区间，未重新拟合模型，不能当作完整算法泛化区间。没有做全数据最终重训或导出/上传拟合模型权重；本轮交付的是可审计的初步验证结果。

采用项目已有Python环境：`循环稳定性数据库_v0.2_20261017/.venv/Scripts/python.exe`，依赖与既有锁一致，见[runtime.json](runtime.json)。复用运行环境，没有安装或修改共享依赖。实际拟合耗时约9秒；面板筹备与人工审查时间不计入该训练运行耗时。
