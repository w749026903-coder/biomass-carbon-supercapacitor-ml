## 质量修正与适用边界

旧v1字段筛选遗漏了 `author_plusminus` 后缀，将5个AC样品的BET/孔体积“±”误差列当作独立属性。v2移出10项数值、撤回10条误差目标行，保存原行、原字段和每条撤回回执。旧v1仅是准备层，没有因本次修正重写任何已训练模型；旧权重和成绩保留。详见 `quality_corrections.json` 与数据库的 `v2_withdrawn_rows` / `v2_withdrawn_features`。

315项谱峰位置、拟合参数或“±”数值接入测量元数据索引，保留原值与出处，不给它们预测输入/目标接入率加分。另6项EDX作者Error或DFT拟合误差沿用原质量元数据分类；不把它们列为必须强行准入的科学缺口。剩余逐项去向见 `unconnected_numeric_queue.csv`、`remaining_work.json`。

水接触角与运行电解液湿润性分开；5μL/5min/5位置均值只绑定原文明示的来源。吸液量保留每行未明示电解液种类/浸泡时长的事实。压片、PVP薄膜、纳米纤维导电率分别保存，未换算混成统一口径。作者按孔体积和假定骨架密度计算的密度不冒充实测密度。孔面积比不是孔体积比；XPS峰内比例不是全材料原子百分比。未赋予化学意义的peak1/peak2序号不作为跨论文相同组分。

材料属性任务屏蔽目标同测量块；密度、导电率和密度归一化指标按共同块防止代数泄漏。前驱体任务只用自身已绑定表征，不获得后续成品配方、成品属性或最终循环标签。原37条循环待补证、15项历史字段冻结、苏铁N/O掩码和未封版批次27均不改变。

## 高效调用与来源隔离

```python
from data.training_current import open_training_datasets

with open_training_datasets() as db:
    main = db.matrix('cycle:reported_3e')
    coverage = db.feature_coverage('cycle:reported_3e')
    split = db.source_split_bundle(
        'cycle:reported_3e',
        heldout_sources=['10.3390/molecules31132329'],
        minimum_sources=3,
        minimum_fraction=0.2,
    )
    # split['primary']: 同列顺序的train/test矩阵，未插补
    # split['auxiliary_training']: 所有辅助任务也排除了该整组来源
    receipt = db.fact_usage(1324)
    metadata = db.measurement_metadata()
```

全数据主集122个候选字段中，30列满足“至少3来源、20%非空”的覆盖示例条件。该示例不是模型效果保证，也不是正式实验选列结果。`source_split` 实际只依照训练来源选列，不读取留出来源覆盖或目标；34个来源留出检查通过。`source_split_bundle` 同时隔离全部辅助任务，防止先在整库学习了留出论文。插补、类别编码、模型选参仍须在训练折内完成。

`main3e_feature_coverage.csv` 显示每字段非空行、来源数和最大来源占比。`source_utilization.csv` 对65个已登记来源逐项对账，无材料数值分母的来源不写成0%已提取。保持率目标仍只有47/34和2E31/25；普通BET辅助253/47、普通3E比电容208/31及含图386/31嵌套保持。数据量和方法兼容性仍限制可靠预测，本版没有证明模型误差降低。
