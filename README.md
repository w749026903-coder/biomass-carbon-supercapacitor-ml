## 跨电脑使用

仓库使用Git LFS保存论文、压缩包、Word、工作簿和SQLite等资料。克隆后执行：

```bash
git lfs install --local
git lfs pull
```

若克隆时已正常下载LFS对象，第二条只补缺件。离线或无法访问LFS时，文件可能仍是指针文本，不能按真实PDF/SQLite使用。

历史脚本和JSON含 `D:/机器学习-超级电容器`、`D:/文献` 等本机路径。这些作为原始证据保留，**不要为了迁移而批量改写**。仓库根目录用相对路径定位；外部原文的可移植查找方式和压缩包副本见 [资料与路径说明](docs/DATA_AND_PATHS.md)。外部文件夹不会被Git自动上传。

`.venv`、`node_modules`、Python缓存、临时锁及凭据文件不纳入版本库；环境可按各版本requirements或package文件重建。一份含过期签名下载链接的原始网页响应仅留本地，仓库提供去除临时访问参数的副本，详情见[处理记录](docs/git_sync/sanitization.json)。其它原项目资料保持原位，历史压缩备份也纳入LFS。未给第三方论文重新声明开源许可。
