另8条明确工况GCD报告进入普通三电极辅助用途。当前普通216行/32来源，含图394行/32来源，前者是后者子集；不能相加为610条独立实验。新材料属性32行和循环各敏感性视图均共享材料与DOI，必须整组留出。

- 600°C/3h是共同煅烧/KOH活化事件，不拆为独立碳化和活化。原非空热处理值保留；未明确“过夜”的时长不填数字。
