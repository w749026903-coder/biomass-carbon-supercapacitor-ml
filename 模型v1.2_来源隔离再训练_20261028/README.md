# 模型v1.2：现有文献数据的来源隔离再训练

本次训练已完成，预设性能门槛未通过。模型的MAE与来源等权均值基本持平；RMSE较低，但仍不能作为可靠设计预测。入口：[可视化结果](模型v1.2训练结果.html)、[冻结计划](training_plan.json)、[逐记录预测](outer_predictions.csv)、[逐来源误差](source_errors.csv)。

## 数据与评估

使用已封版循环v0.29的reported_3e：47条测试、34个来源组。三电极GCD、普通水系生物质衍生多孔碳，输出指定圈数和作者报告工况下的保持率。双电极31条单列，未混合训练。文献v26的208条普通比电容辅助输入与386条含图输入相互嵌套；本轮没有将它们当循环标签，也没有使用辅助学习或未封版批次27。

50项候选输入来自现有方法限定材料矩阵、已审查分阶段制备参数和既有语义分类；逐记录证据见[field_evidence.json](field_evidence.json)。不猜材料别名，不按DOI直接继承同篇其它样品属性。XPS原子/质量百分比分通道，不借EDS或未指明基准值补齐。原37条待证、15历史字段冻结及苏铁N/O掩码保持。

外层逐一留出34个来源组；内层3折来源选模，只比较5个预先固定候选：核心去电流Ridge、材料去电流Ridge、材料含电流Ridge、材料含电流RBF核岭回归、材料含电流ExtraTrees。所有数值填补、尺度、类别词表、支持筛选及核参数仅使用训练来源。可选数值至少有5个训练来源、类别至少3个来源；同篇多样品和工况整组留出，来源总权重各为1。

计划冻结后实际完成560次模型拟合，约23秒，0条训练警告。模型内部每棵树不另计一次拟合。来源留出预测覆盖47条，最终权重另外在全47条上重训；其训练集不能被视为独立验证。

## 同口径结果

| 方案 | 来源等权MAE／百分点 | RMSE／百分点 | R² |
|---|---:|---:|---:|
| 内层选模、外层来源留出 | 5.1509 | 6.9087 | 0.0955 |
| 训练来源等权均值 | 5.1490 | 7.4707 | -0.0576 |
| 训练来源等权中位数 | 5.2237 | 7.4443 | -0.0502 |

相对均值的ΔMAE为+0.0019个百分点；5000次配对来源重采样描述性95%范围为[-0.4519,+0.4476]。模型MAE范围为[3.8682,6.6523]。这些范围描述本批来源的评估不确定性，不是单个未来样品的预测区间。预设要求同时超过两个简单参照且ΔMAE范围上界小于0，本轮没有通过。

最终研究权重选择material_I_ridge100。34个外层训练折中，19折选择材料含电流Ridge、3折材料去电流Ridge、12折材料含电流核岭；最终编码器启用25个数值字段和6个类别字段，19个稀疏数值字段未启用。因此材料信息确实进入了选模与预测，但本次没有单独证明某一材料参数的因果作用或独立收益。

旧v1.1的42条、30来源全部包含在本批中，另外增加5条、4来源。新旧集合不同，不能用5.15与旧4.75直接比较得出退步或改善；本轮是探索性来源隔离验证，没有预先保留的新外部测试。

## 主要局限

- 预测明显向中间值收缩。AC-700C实测62.2%，留出预测91.64%；CCL实测109.2%，预测96.36%；NPC实测106.3%，预测94.18%。真实增长数据没有裁剪，预测也没有100%上限。
- 木粉、CCL和NPC三个来源合计约占51.4%的来源加权平方误差。保留这些困难来源和原始证据，不能为提高分数删掉。
- BET与核心工况完整；孔容38/47、Raman28/47、负载17/47，方法限定XPS氮12/47、氧15/47。炭化温度9/47、预炭化温度19/47。增加填充值不等于增加实测证据，34个来源仍限制了复杂模型的稳定性。
- 当前分组验证和正值目标不能证明跨体系或真实实验设计的可靠性；报告电流保留未知物理质量分母，保持率参照精确圈号仍可未知，不因此改变现行用途准入。


输出同时给出百分数、比例、输入支持警告与reliable_for_design=false，不提供未经校准的预测区间。只读核验：项目环境运行tools/verify_model_v12.py。不要重跑prepare或train来追分；完整评估记录在evaluation.sqlite，冻结计划和代码指纹在frozen_run_hashes.json。

26259项核验通过；533个保护文件及46组已选原文/证据文件SHA核对，保存权重重载、逐折分组与处理、来源等权指标、配对重采样和输入原值均通过。桌面/手机实际页面截图在output/playwright，四张独立科学SVG在figures；筛选、排序、数据计数及页面溢出检查通过。未安装或修改共享依赖，没有发布推理服务。

跨版本来源统计最初只做lower()，遗漏旧裸DOI与新doi:前缀的等价关系；已用统一来源函数纠正为30个重合来源，并在[历史来源统计更正回执](historical_overlap_audit.json)保留原计数、前后哈希及未变的计划/输入/评估/权重SHA。该更正仅针对描述性统计，实际训练始终使用当前规范来源组，未增加拟合。
