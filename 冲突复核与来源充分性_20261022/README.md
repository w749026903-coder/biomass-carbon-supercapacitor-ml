| 指标 | v0.12 | 本轮v0.13 |

本轮材料单元增量来自新增四个样品已核属性进入训练视图，不能说成新增20次独立实验。当前可选单元覆盖27.25%；8个核心字段完整。单篇最多5条，占原始行11.90%；按来源等权后每篇合计1/30，不是单篇权重垄断。

KOH有34条/23来源；NaOH、Na2SO4各只有1条/1来源。Raman有30条/19来源，质量负载仅8条/4来源，已结构化活化温度仅3条/3来源。后两项**也是仍有提取欠账的信号，不证明其它论文没有报告**。优先继续核读已有方法、SI和自身样品表，再针对剩余缺口找新独立论文。

全部审查池仍保留277条观察、178来源组；其中3E有120条，现行用途待补/争议41条（含年份待核），全部未准入3E为69条，后者还含年度外、方法或范围不符资料。文献文件、独立论文、样品与测试数量不能互换。2E主集26条/21来源，与3E分开；嵌套敏感性集合见数据库说明，不能相加充数。

旧模型仍基于v0.10的31条/23来源。**本轮拟合0次，因此不能声称误差已下降。** 下一轮实验应先冻结候选和评估方案，采用来源分组、折内变换，并保留新独立来源检验。是否还需更多论文应结合来源分组学习曲线和误差不确定性判断，没有“总共下载N份就必然够”的阈值。

优先补独立的低保持率和长循环来源、同一工况下更丰富的材料差异，以及制备/孔结构/成分/负载字段。增加同一论文样品有价值，但不能代替独立来源。尚缺作者澄清的项目列出可执行问题，不伪造通过；本轮未联系作者或向其它聊天发送消息。
