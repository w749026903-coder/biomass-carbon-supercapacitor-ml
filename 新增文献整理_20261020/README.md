## 文件用途

- `文献分类入口.html`、`文献分类索引.csv`：按类别、题名、DOI与样品搜索，直接链接原文。
- `input_manifest.json`、`intake_index.json`：原始33个文件、ZIP成员与80份PDF的对应关系、路径、大小、SHA256；`intake_summary.json`仅为接收阶段历史快照。
- `batch.sqlite`：接收阶段逐页原文与FTS缓存；完整审查数据集中在v0.8 SQLite的`incoming_*_v08`表。
- `source_reviews.json`、`reviewed_tests.json`：人工审查输入；`normalized_tests.json`为可查询标准记录，包含缺字段、原值、替代说法与用途状态。未准入值属于工作观察，不是已解决科学结论。
- `curation_decisions.json`：本轮字段补充时的前值与处置理由；后续终审以最终逐测试记录的页码、review_notes和extra_observations为准。
- `逐测试数据.csv`、`待补证据清单.md`：可读数据与下一轮证据任务，空值没有填0；未知电流质量分母未单独否定报告工况用途。
- `evidence_images/`：保留被引用的原PDF渲染页，供复查图形符号和协议；正文中的页码均为PDF页码，可能与印刷页码不同。
