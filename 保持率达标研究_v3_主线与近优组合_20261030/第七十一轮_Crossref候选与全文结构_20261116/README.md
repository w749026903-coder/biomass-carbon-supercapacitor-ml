# 第 71 轮　Crossref 检索与出版社正文核查

2026 年 11 月 16 日。沿用第 70 轮冻结的三电极 KOH 2–6 M 保持率盲测方案。先从 Crossref 取题名、DOI 与书目信息，再按两套现行库及项目历史查重。四组检索合并取得 192 个不同 DOI，85 个通过题名初筛，16 个暂未发现同 DOI 或同题名的历史记录。按预定检索顺序对前 14 个查询 PMC 开放全文，本批没有匹配。书目去重后还须核实实验谱系和终点使用史。

从中选了六篇原料明确的候选，经 DOI 解析直接查出版社。查到两份可核题名的公开正文 PDF，另有三篇期刊页面和一篇解析失败。两份 PDF 都保留原字节和 SHA-256，正文只输出词项命中的页码，不显示原图或保持率数值。
