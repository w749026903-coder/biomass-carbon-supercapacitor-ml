# 第77轮｜两篇正文能为保持率模型提供什么

2026年11月18日。两篇均为可读的期刊正文。绿茶碳提供一条与主线匹配的高 BET 曲线；水黄皮油渣提供一条双电极器件循环记录。本轮将新增资料用于预测诊断和分用途索引，没有将新终点喂入模型。

|样品|证据|可用于什么|
|---|---|---|
|绿茶 GKN8|表1、2；第9页图9黑色方点；第10页循环段。三电极、6 M KOH、10 A/g、1,000圈，BET 1,680 m²/g。|早期辅助保持率预测诊断，输入六个可分辨的早期黑色方点，约19–100圈。|
|水黄皮油渣 PRC8|第11–12页，3.9节、图10f。对称双电极、Na₂SO₄、10 A/g、5,000圈，作者报告约93.01%。22.52→20.95 F/g，按展示精度回算为93.03%。|器件循环对照；同文三电极表征另算。作者电流质量分母不推定，倍率测试的45.82 F/g不作这条曲线的起点。|

**绿茶这条曲线测出了什么。** 图9纵轴是 F/g。用同一黑色曲线的首个标记作参照，六个早期点的变化约0.38个百分点。200圈附近标记的横坐标误差上界越过了前20%界限，未用；连线没有当成更多测点。第64、67轮模型在1,000圈使用同一配方，两个结果只算一次。预测和三个简单对照均先提交并核验远端版本 `6afdc9e28984e46b64ba3b2f74b3bc30e832502f`，再读取终点百分数。文献报告 **99.4%**，末端黑点图读约 **99.42%**（上下各放宽3像素时约99.07%–99.77%，不是统计置信区间）。

|---|---:|---:|
|第64／67轮模型|96.08%|3.32|
|沿用最后的早期测点|99.39%|约0.01|
|按早期斜率直线外推|95.07%|4.33|
|取训练来源均值|92.01%|7.39|

**为什么不增加正式盲测篇数。** 核对样品身份时，准确终点百分数和右侧曲线都未展示，但作者对稳定性的描述及约67.1 F/g已可见。这会间接提示终点，因此本例只作额外诊断；不能用它和芥菜壳两点算独立R²。冻结模型只用原来的23条、18个开发来源；两份正文在两个既有数据库均未命中。绿茶论文与18篇开发论文、此前一篇已评分来源的作者姓氏均未见重合，这只是书目检查。未重训、未调参、未更换模型；只按冻结配方复现两个旧估计器以作预测。

**不能混样品。** 图9另两条为参照碳 CKN8（正文100.5%）和 CZN8（101.6%）；保留超过100%的结果。综述比较表和结论中的约99%属于绿茶 GZN8，没有对应同名早期线。即使活化剂相同，也不能挪用 CZN8 曲线；比较表的 1 A/g 不自动代表长循环电流。表4的倍率比电容与循环比电容分开；其CV列没有逐行确认扫速，只保留原表行位。两文共整理132条表格及正文数值（绿茶78条、水黄皮54条，含单列器件循环记录），按DOI、样品、用途、条件和页码查询，不能当132个保持率训练样本。

**下一步最值得检验的分歧。** 绿茶曲线在早期轻微下降后趋于平坦，模型多估了后续衰减。但旧20条同范围开发记录里，同为1,000圈的两条均出自同一篇：冻结模型的平均绝对误差3.72个百分点，沿用早期末值为7.03。相反结果足以排除“现在就全换简单方法”，还不足以证明应按材料种类切换方法。优先收集以前未用的、同工况、终点约1,000圈且标记清楚的多篇曲线，不按终点筛选。对每篇分别锁定模型和末值基线后再比较。若有绿茶图9的原始圈数—比电容表，可校准本例读图，但本例已揭示的终点不会重新变成盲测。持续优化目标保持暂停。原同批开发R² 0.8959（距0.95差0.0541）、MAE 1.873、RMSE 2.369个百分点；严格独立已评分1篇，独立R²仍不可估。
