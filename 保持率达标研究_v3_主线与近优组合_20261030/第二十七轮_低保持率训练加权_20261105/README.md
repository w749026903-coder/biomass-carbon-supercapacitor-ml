# 低保持率训练加权对照

把训练折内终点保持率不高于 80% 的记录权重乘以 2，再把全折权重归一到原有总量。三电极沿用第 17 轮的原目标和第 19 轮按剩余圈数变换的目标，双电极沿用第 21 轮。所有对照均使用前 20% 观测，按论文整组留出，保留 RF、GPR、XGBoost、Ridge、ExtraTrees 及原静态特征组合。训练计划在拟合前锁定于 `1ec9e46`。折内特征编码和目标中心、尺度与相应旧配置一致。评估沿用原来的来源与曲线权重。

600 次实际拟合，0 失败、0 警告。逐项配对使用存档的 600 折对照和 744 条端点预测。程序完成 1,566 项核验，另做 170 项独立算术和冻结核验。24 组均未同时达到项目数值门槛，也没有一组同时降低低保持率与其余样本的 MAE。三电极 32 条／26 来源，双电极 29 条／23 来源，两边各只有 4 条低保持率记录，来自各自的 3 个来源。

| 预定主 GPR | R² 加权前 → 后 | MAE（pp） | RMSE（pp） |
| --- | ---: | ---: | ---: |
| 三电极，原目标 | 0.6142 → 0.6141 | 4.1182 → 4.1208 | 7.1369 → 7.1380 |
| 三电极，按剩余圈数变换的目标 | 0.5202 → 0.5202 | 4.9479 → 4.9503 | 7.9584 → 7.9592 |
| 双电极，原目标 | 0.6088 → 0.6087 | 6.4619 → 6.4629 | 8.7242 → 8.7249 |

三个主配置的配对 MAE 区间均跨过零。三电极原目标 GPR 的盐地碱蓬高估仍约 28.47 pp，双电极 GPR 的 DDHPC 两条平均绝对误差仍约 20.49 pp。

| 低保持率改善的对照 | ≤80% MAE（pp） | >80% MAE（pp） | 难来源 MAE（pp） |
| --- | ---: | ---: | ---: |
| 三电极 Ridge，按剩余圈数变换的目标 | 6.43 → 5.99 | 3.51 → 3.68 | 盐地碱蓬 10.77 → 10.17 |
| 双电极 RF，仅早期特征 | 16.02 → 15.20 | 6.77 → 6.92 | DDHPC 14.00 → 13.11 |
| 双电极 XGBoost，仅早期特征 | 15.32 → 12.00 | 6.02 → 6.55 | DDHPC 16.97 → 13.64 |

这批结果支持保留原权重作为主对照，Ridge、RF 和 XGBoost 的尾部改善留作后续比较。一次固定倍数对照只能判断本批加权方式，且各体系只有三个低保持率来源。下一步优先补齐丝瓜络 PACs 和大豆秸秆 SSC-700 的早期证据，继续积累真正独立的外部来源。材料工况直接预测路线和前 10% 路线另行维护。本轮外部独立验收仍为 0。
