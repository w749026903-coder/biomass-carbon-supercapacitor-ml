# 50篇文献与66条三电极循环记录

名单于2026-11-19整理，2026-11-20在本次新算法计算前锁定。每个DOI只占一篇，每个样品和循环工况有自己的记录。纳入依据是已有的三电极碳电极循环证据、可追溯的终点和测试条件，不使用历史预测残差排序。本清单是从项目已有证据中有目的地整理的研究队列，不是对领域的系统抽样。含部分跨年份来源及混纺或残留材料；这些材料保留原用途标记。不得用对称器件的结果给单电极补数。

|可用范围|论文|记录|
|---|---:|---:|
|全部有循环终点和基本工况|50|66|
|跨年份、材料和工况八项齐全（A）|37|51|
|原近期A基线（已含在跨年份A中）|34|47|
|前20%曲线六项输入（B）|31|37|
|A或B至少满足一项，按DOI去重|43|58|
|其余：仅用于敏感性比较|6|7|
|其余：只有终点、未进上述训练用途|1|1|

50篇中38篇有KOH电解液测试，29篇有工况落在1–6 M KOH、1–10 A/g、1,000–10,000圈的记录，22篇有同工况且可用的早期曲线。此处不再加“早期变化温和”的条件。这些数字并非模型得分，也不能相加。

- [逐篇清单](50篇文献清单.csv)：题名、DOI、样品、工况、终点、用途、证据键及后续核图优先级。清单前后按DOI排序，不代表研究价值排名。
- [SQLite数据库](retention50.sqlite)：`direct_recent`、`direct_cross_year`、`curve_early20`可分别读取；`direct_sensitivity`为历史敏感性视图，含与主集重叠的记录；`protocol_inventory`仅用于盘点。输入列不含DOI、样品或证据键。是否属于同一模型的样本要按同一视图统计。论文在交叉验证中整篇留出。
- [食物废弃物碳读图依据](FWCA-4_fig7c.json)：三电极FWCA-4有三个确定在前20%以内的图读点，可做B。第10000圈94.1%为作者终点；参比电极未知，A仍冻结。高粱碳SAC-2的98.4%来自三电极图2f；摘要97.5%对应双电极图4f。保留终点，循环电位窗与早期读数待核。
