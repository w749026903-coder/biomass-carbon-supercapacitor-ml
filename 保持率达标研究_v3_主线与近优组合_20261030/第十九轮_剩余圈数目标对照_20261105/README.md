2026-11-05。三电极前 20% 的 32 条记录、26 个来源全部保留。冻结 8 组模型和所有来源留出划分后运行 208 次新拟合，并逐折复用第十七轮的 208 次对照预测。没有失败或警告，2,510 项复核通过。8 组均未同时通过数值门槛，新增独立验收来源为 0。

## 用剩余圈数表达后期变化

原方案直接学习终点保持率减去早期末值的差值。本轮把同一个差值除以 `log1p((目标圈数−最后观测圈数)/1000)`，预测后乘回该因子并加上早期末值。这样可以检验用一个缓慢增长的圈数因子表达剩余变化，是否更适合长短周期混合的文献数据。这个因子是事先固定的对照假设，没有用留出成绩选择；输入、标签、百分点评价和其他参数都与同折对照一致。正负变化都保留。

| 固定配置 | MAE，原 → 新（pp） | RMSE，原 → 新（pp） | R²，原 → 新 |
| --- | ---: | ---: | ---: |
| 预定主方案 GPR | 4.118 → 4.948 | 7.137 → 7.958 | 0.614 → 0.520 |
| Ridge 早期曲线 | 4.234 → 3.844 | 7.130 → 4.820 | 0.615 → 0.824 |
| RF 早期曲线 | 3.575 → 3.980 | 6.333 → 6.168 | 0.696 → 0.712 |
| RF 含静态 | 3.727 → 4.039 | 6.276 → 6.238 | 0.702 → 0.705 |
| XGBoost 早期曲线 | 3.636 → 4.442 | 6.429 → 7.415 | 0.687 → 0.584 |

8 组中只有 Ridge 的 MAE 点估计下降，来源配对的新减旧区间为 −2.43 至 +1.31 个百分点，跨过零。Ridge 把咖啡渣碳误差从 18.81 降至 3.21 pp、盐地碱蓬误差从 24.49 降至 10.77 pp。对其余 24 个来源按来源平均，误差增加 0.80 pp。这个拆分只用于理解总体变化，所有记录均保留在正式对照中。主 GPR 的 90% 绝对误差分位从 12.66 升至 14.73 pp，现有结果不支持将归一化设为主方案。RF、GPR、XGBoost、含静态模型及直接预测路线继续保留。完整 8 组和简单基线见结果 JSON。

## 早期相似度检查

按预先约定，只在其他论文且目标圈数相差不超过比例 1.10 的记录里，用早期末值、均值、斜率对应的变化量、范围和已观测比例找邻居。终点只在选出邻居后用于计算差值。29 条找到候选，按事先冻结的距离尺度，16 条有距离不超过 1 的近邻，对应 9 对不同配对。其中只有 1 对的终点相差超过 5 pp（OAC623 与 NCHU20，差 5.58 pp）。

盐地碱蓬 JPC 的最近候选距离为 2.75，咖啡渣碳 CGBC 为 7.72，二者均在这个近邻范围外。这两个误差很大的案例更符合早期输入在现有样本中缺少相近参照。距离只是事先设定的描述性尺度，未传播读图误差，也不能证明早期输入的不可预测性。优先继续获取 SSC-700 原图和其他独立长周期低保持率来源，补充相似工况下的实际曲线，再验证 Ridge 的局部收益。
