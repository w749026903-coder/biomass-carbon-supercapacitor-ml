# 第 67 轮　中间圈数训练与 10,000 圈限域对照

2026 年 11 月 11 日。以第 64 轮三电极温和早期范围为基准，比较改变训练数据和缩小适用范围的效果。目标是指定圈数的电容保持率。全组固定 23 条、18 篇，10,000 圈对照固定其中 14 条、11 篇。各对照沿用前 20% 早期输入及原终点，整篇留出。

## 三种训练方法

1. **中间圈数辅助训练。** 从原目标圈数 40%–60% 内每条曲线取至多一个可确认的原图标记。中间目标前 20% 至少有三个符合坐标误差上界的早期点，且通过同一工况与早期幅度筛查。核到 15 条、12 篇。每条补充曲线原终点与中间点分配原曲线权重的 75% 和 25%。编码器只用原训练记录拟合，留出论文的中间点从该折训练中排除。
2. **仅用 10,000 圈训练。** 训练和评估均限定在 10,000 圈组。对照为第 64 轮在完整 23 条范围训练、在同一 14 条上评分的存档结果。
3. **训练保留各圈数，增加近目标记录的权重。** 用各记录的目标圈数除以 10,000，对原训练权重缩放后重新归一化。仍在上述相同 14 条上评分。

第 64 轮的高斯过程与随机森林配置各自复用，等权组合。每个新组合另做与原预测各占一半的对照。训练计划和中间点证据在拟合前冻结于 `49c3c79`。共 80 次拟合，失败和警告均为 0。

中间点训练是最接近升级条件的预定路线。该方法在同一 10,000 圈组的 MAE 为 1.915 个百分点，较基准低 0.144 个百分点。但全组最大高估仍在 AC-600C，并由 6.858 升到 7.303 个百分点。整体配对 MAE 变化为 −0.008 个百分点，95% 区间 [−0.171，+0.143]。六个预定候选均未通过本轮回归要求。仅用 10,000 圈重训和加权重训的同组平均误差均上升。

## 根据结果找到的优化候选

看到上述结果后，诊断了一个只按目标圈数决定的规则：10,000 圈采用中间点训练组合，其他目标圈数使用第 64 轮组合。固定原 23 条的 R² 为 **0.9007**、MAE 为 **1.662**、RMSE 为 **2.187**、P90 为 **3.443** 个百分点，最大高估为 **6.858** 个百分点。改善主要来自 YZPC-3 和 RMAC-800，10,000 圈组 8 条绝对误差下降、6 条上升。按论文配对的 MAE 变化为 −0.088 个百分点，描述性 95% 区间 [−0.220，+0.019]。

这条规则来自本轮结果，列为下一轮独立盲测的优先候选。正式基准仍采用第 64 轮组合，独立验收为 0 篇。按当前 23 条目标值的分布，达到 R² > 0.95 需要 RMSE 低于 1.552 个百分点。下一步优先取得同工况的未见 10,000 圈曲线，覆盖前期平稳、后期明显衰减的材料。对同一来源先锁定第 64 轮与本候选预测，再核对终点、平均误差和最大高估。
