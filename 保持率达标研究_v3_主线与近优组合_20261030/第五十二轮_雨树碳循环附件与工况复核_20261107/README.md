## 暂缓条件

接受稿中的 0.5–10 A/g 归 Fig. 8(b,c) 的倍率测试，0.5 A/g 绑定器件比电容，Fig. S5 为循环后 CV。Fig. 8(d) 的实际循环电流未核实，器件 CV 电位窗也未绑定到该循环试验。作者结论中未明确绑定 5,000 圈的数值继续与上述终点分列。刊本 DOI 路由本次返回 403；工况核对以接受稿正文和仓储图为依据。

该来源的终点已知。等取得可核的逐圈表或明确的原始试验记录后再重开。新增可用早期输入、预测锁定、拟合、准入和独立验收均为 0。后续优先找可取得原表且有足够早期点的来源，三电极重点补长循环重衰减；暂缓同批调参。
