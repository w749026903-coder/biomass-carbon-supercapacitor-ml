## 更正与替补

- CACNF-ZnCl2-20%的5,000圈、92%在第7页图7d，第7图整体为双电极。前一张三电极图不能作为该终点的体系证明。旧清单保留，新版将这一器件记录移出三电极名额。[论文](https://doi.org/10.1039/c8ra07587e)
- 同一名额补入2021年柚子籽碳研究。PSAC-3在三电极、1 M KOH、10 A/g下循环10,000圈，作者给出93.8%。选用依据是材料、工况和原图证据齐全。该论文此前已评过模型，只用于历史对照。期刊PDF已与受保护的本地原件逐字节核对。[论文](https://doi.org/10.1039/d0na00778a)
- DC-900的图3g写90.3%，正文写92.4%。两值分别保存在记录里。其余4条图线末点与论文文字存在可见差异，保留原值、暂停配对；涉及AHPC-850的疑点仅标在该样品上。两篇以比电容作纵轴的论文另列待核。[变更与原文指纹](归属与争议.json)
- 盐地碱蓬JPC-800-0.5的55%保留。论文分别报道三电极材料10,000圈保持55%和对称器件保持91.6%，两项出自不同测试。原文第三节、图13及结论均可交叉核对。[期刊原文](https://www.mdpi.com/2079-4991/16/21/1412)

## 调用与评估

数据库视图 `early_development` 提供31条开发记录、文献DOI、保持率和六项输入。读取后按整篇论文分组，同一DOI的多条样品记录进入同一折。完整记录在 `endpoints`，其中 `relation`、`label_review` 和 `early20_use` 分别保留作者表述、标签审查状态和早期输入用途。[核验清单](核验.json)

本轮按先整合文献的要求未训练。上一套早期曲线队列（31篇）的整篇留出组合模型预测R²为0.663，MAE为3.89、RMSE为6.22个百分点，距本阶段0.90门槛约0.237。两次队列组成不同，新26篇开发集尚无同范围成绩。下一步按原图是否能分辨早期点补其余来源；优先核清混合电解液图例和比电容的初始参照，在新的开发集上比较模型前锁定来源分组。[第81轮原始成绩](../第八十一轮_固定50篇多输出预测_20261120/README.md)
