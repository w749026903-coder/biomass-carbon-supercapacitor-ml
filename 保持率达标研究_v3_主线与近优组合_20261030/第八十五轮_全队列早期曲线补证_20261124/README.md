## 可以直接使用的数据

[SQLite数据库](retention50.sqlite)的 `early_development` 视图可取出39条主开发记录。六项输入沿用原定义，同一DOI的材料、不同终点及衍生特征必须进入同一折。`endpoints`保留全部作者终点、原值表述和用途；`early_inputs`含各准备用途，做训练时应按视图取数。`marker_points`只存本轮新增或补核的图上观测。读图近似值附有像素换算区间，不能代替原始仪器测量误差。[逐点读图与标定](逐点读图.json) · [逐终点出处](逐测试证据.json) · [完整输入及用途](早期输入及用途.json)

新增开发集的8篇对应DAC-700、CDAP800-350、700-3、ACST-2、CF-HPC-2、BSPC、NSOC-800、CMC-ZnK-800。CDAP800-350的作者明确报告初始250 F/g与末端231 F/g，初始值可用作分母。CMC-ZnK-800直接读取图8d的保持率右轴。CF-HPC-2取图8f下半部红色的6 M KOH曲线。NSOC-800的参比电极争议仍保留，六项早期曲线输入不使用参比电极。BSPC作者报告94%，粗读末点约95%，保留整数报告与像素分辨率的差异。

液化木正式图6f标明10 A/g，K-LWCA3与H-LWCA各有9个可分离早期点；完整实验方法仍依赖预印本。壳聚糖碳AF-MMTC的6个同系列样品都保留了终点；4种可分色的早期曲线只作敏感性分析。ECNFs-6的归一化起点约217 F/g，换算出的2000圈保持率约88.8%，与作者表述相符。1000圈92%另存，前200圈仅有2个可用内部点。APVPC-2的勘误涉及引文及文本重合，已保留来源限制。[Springer正式图6](https://link.springer.com/article/10.1007/s00226-023-01515-0/figures/6) · [APVPC-2勘误](https://doi.org/10.1039/d4na90015d)
