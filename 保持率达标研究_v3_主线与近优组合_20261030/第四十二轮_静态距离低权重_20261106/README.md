低权重缓解了静态项拉大距离的现象。原始表达的最近核相似度中位数在零权重、1/16 和全权重下分别为 0.575、0.354、0.037。延续表达对应为 0.435、0.289、0.041。误差最大的低保持率来源仍缺少相近的训练参照。盐地碱蓬实测 55%，八组预测都在约 83.25%–83.39%。八组的 90% 绝对误差分位约 12.57 个百分点，门槛为 5。整体数值通过 0，新增正式准入与独立验收 0。
