## 雨树碳的两个体系

三电极硫酸体系的 Fig. 6(e) 比较不同电流下的比电容。10 A/g 时，NSAC8 的 77.6% 和 NSAC7 的 66% 属倍率保持。没有独立循环圈数可绑定这两项。〔1〕

对称双电极 NSAC8||NSAC8 的 Fig. 8(d) 才是 5,000 圈循环。正文给出硫酸 91.3%、硫酸钠 94.3%。结论另报 99.6% 和 99.8%，未在该处绑定相同圈数，分别保留。正文给了相邻 GCD 倍率扫描的电流范围，Fig. 8(d) 实际循环电流仍待核实。原生图在两条曲线上首个正圈数标记都位于约 1,000 圈，也就是前 20% 的边界。前 10% 为 0 个，前 20% 每条至多 1 个，达不到至少 3 点的要求。两个电解液工况仍属一篇论文。〔1〕
