## 盲态诊断失效

首次排查原生图件的轴线时，程序把三电极后段的深色数据线当作黑色直线，输出了后段像素位置。虽未取得精确终点，该位置能结合刻度推知后段比电容，因此这篇论文的两种体系一并退出盲验。修正后的工具只从预先指定的绘图区外短条验证坐标轴，并断言所有曲线计算区域位于前 20% 内。 [冻结计划](screen_plan.json) · [复算脚本](../../tools/retention_mango_early_v45.py)

与第 31 轮双电极训练池的另一篇芒果核论文 `10.1039/d5ra02129d` 对比。两篇作者无重合，机构字段也不同，尚无证据将它们视为同一实验。当前论文 DOI 在两份正式来源目录均为零匹配，仍按整篇只计一篇。上述结果不恢复盲验资格。 [来源核验](early_evidence.json)

原 GPR、RF、XGBoost、静态组合与材料工况直推均保留。下一轮优先筛选此前已封存且未接触晚期结果的论文，先证明坐标轴输出与后段像素彻底隔离，再检查可用早期输入。NPCA 的逐圈数据仍是三电极长循环开发的优先缺项。 [第 45 轮阶段图表](../阶段可视化报告_至第45轮_20261106.html)
