# 第五十八轮 · 木源碳来源隔离与历史暴露

在预留候选前的 Git 快照 `cf0607d` 中，同一 DOI 命中三份题录文件。三份均已保存作者摘要，程序在同一句检测到保持率表述、10,000 圈和百分数。核验只输出路径和句号位置，未输出终点数值。现存摘要足以造成事前暴露风险，因此这一来源簇转为开发候选。
