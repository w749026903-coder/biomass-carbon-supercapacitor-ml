# 第四十七轮 · 海藻碳循环证据核验

海藻碳（`10.3390/ma15165748`）确认是三电极长期循环。归一化参照由作者描述为初始电容。原图和补充材料未能提供可分离的早期实测点，仍封存，暂缓预测锁定。新增拟合、正式准入与独立验收为 0。

## 确认到的实验条件

§2.4 的方法给出三电极、1 M Na₂SO₄ 和饱和甘汞参比电极（SCE）。§3.4 在对应 Fig. 9 的段落里把 1 A/g 与 10,000 圈充放电绑定。Fig. 9 的横轴为循环圈数，纵轴为比电容 F/g。初始参照的实测数值和确切圈数仍待原始数据。
