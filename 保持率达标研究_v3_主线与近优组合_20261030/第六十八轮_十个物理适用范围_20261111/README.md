- **5,000–10,000 圈**是唯一在同批记录上通过限域重训降低 MAE 的范围，1.823→1.791 个百分点。R² 0.7687→0.7545，最大高估 3.645→4.182 个百分点。MAE 的来源配对 95% 区间为 [−0.280，+0.238] 个百分点。
