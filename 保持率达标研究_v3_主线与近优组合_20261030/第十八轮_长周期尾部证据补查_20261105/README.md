## 三电极优先追查 SSC-700

Jiao 等的原论文摘要把大豆秸秆碳 SSC-700 的 **10,000 圈、73.97%** 放在三电极结果中。同一材料另有双电极对称器件数据，摘要报告 5,000 圈容量损失 0.5%。摘要中的 0.5 A/g 用于比电容测量，实际循环电流需核正文或图注。题录检索未定位开放正文或原图。本条终点已查看，暂列开发候选，下一步优先取得可查原图与 SI，核前 2,000 圈实际标记及循环工况。另两篇同作者的大豆秸秆研究先查制备和测试关系，分组独立性仍待核。 [原论文摘要](https://www.sciencedirect.com/science/article/abs/pii/S0926669022003892)

本地筛查读取了 526 个 `main.xml`、`main.txt` 和全文摘录文件，按 SHA256 去重为 497 个文件，筛出 57 个文字片段供人工定位。片段会命中倍率保持率、引用结果和器件测试。甘蔗渣 C-4 的本地 PDF 第 11 页给出 138.5 和 36.45 F/g，换算约 26.32%，第 13 页结论写 40%，两项继续保留并冻结。WHAC150 仍待 Fig. 8(a) 的实际循环电流。NPCA 的近似文值与图读继续分列。
