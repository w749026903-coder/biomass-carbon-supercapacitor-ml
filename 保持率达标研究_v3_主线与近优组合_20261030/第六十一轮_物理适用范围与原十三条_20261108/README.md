两个物理范围均从第 59 轮三电极快照按电解液浓度和目标圈数选择，范围内保留全部记录，不按保持率和误差筛选。每个范围用 4 个固定模型及 2 个等权组合，128 次新拟合无失败或警告。两组均无配置同时过线。第一个范围的早期随机森林在相同 26 条留出记录上的 R² 从宽范围训练的 0.710 提至 0.752，MAE 3.134→2.810，P90 4.540→4.755。第二个范围上各固定模型在相同测试行上均未同时改善 R² 和 MAE。
