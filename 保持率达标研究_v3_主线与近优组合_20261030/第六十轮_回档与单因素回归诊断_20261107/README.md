# 第六十轮 · 回档与单因素回归诊断

## 恢复对照

将第 31 轮选为可复现的开发基准。三电极 33 条／27 篇采用早期随机森林，R² 0.697、MAE 3.497、RMSE 6.220、P90 绝对误差 6.619 个百分点。它和早期 XGBoost 的平均误差接近，记录级 P90 更低。双电极 31 条／25 篇采用早期高斯过程，R² 0.623、MAE 6.538、RMSE 8.650、P90 14.476。第 59 轮双电极高斯过程在同批旧记录的 MAE 6.538→6.310，但 P90 14.476→15.441，继续作为对照。恢复的是开发评估入口，模型均未通过最终验收。[当前基准入口](../../data/current_retention_model_benchmarks.json)

## 哪条新数据触发退步

同一批 33 条、27 篇整篇留出，分别只加稻草、只加草莓，以及同时加入后固定原训练折的特征缩放。共 135 次拟合，无失败或警告。实测 A-NSC8 的 10,000 圈保持率是 99.20%。

| 三电极高斯过程训练方式 | A-NSC8 预测 | 固定 33 条 R² | 固定 33 条 MAE（pp） |
| --- | ---: | ---: | ---: |
| 第 31 轮原训练集 | 97.32% | 0.618 | 4.023 |
| 只加入稻草活性炭 | 85.68% | 0.564 | 4.636 |
| 只加入草莓秸秆 | 97.35% | 0.618 | 3.991 |
| 两条都加入 | 85.70% | 0.565 | 4.599 |
| 两条都加入，固定原缩放 | 85.71% | 0.564 | 4.620 |

稻草单独加入便复现这次退步。固定原缩放仍复现，说明仅更改缩放无法解决。稻草是一个真实的迟发衰减案例，保持率标签与原文证据留作难例。上述诊断只对本配置和本批数据成立。

三电极早期随机森林只加草莓时，原 33 条 R² 0.697→0.707、MAE 3.497→3.456、P90 6.619→6.129。来源配对 MAE 差的描述性 95% 区间为 −0.232 至 +0.130 pp。两个新增样本的独立测试没有包含在这组 33 条指标里。该配置作为下一步验证候选，当前基准仍取第 31 轮。稻草单独加入时，随机森林对 A-NSC8 预测 96.17%，比高斯过程受影响小，整体 MAE 仍升到 3.719。

## 固定组合

等权合并三电极早期随机森林和早期 XGBoost 的整篇留出预测。第 31 轮 MAE 3.497→3.443，P90 6.619→7.100。第 59 轮 MAE 3.948→3.947，改善不足 0.002 pp。双电极高斯过程＋随机森林的第 31 轮 MAE 6.538→6.870，第 59 轮 6.393→6.404。两体系均不以本次组合替换回档基准。

以后新候选首先在同一批论文、同一标签上对比 R²、MAE、RMSE 和两个 P90，并列出最差回归记录。先做有假设的单因素对照，再决定是否扩参数。可用固定组合筛选，若拟合组合权重，权重只由每个外层留出折内的来源分组验证选出。另用未见论文检查泛化。 [模型选择偏差的原始研究](https://link.springer.com/article/10.1186/1471-2105-7-91) · [交叉验证组合方法的原始研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC2473869/)
