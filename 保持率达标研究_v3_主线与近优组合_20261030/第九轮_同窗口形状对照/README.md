## 核验与诊断

- `independent_verification.json`：412536项独立核验、465份保护SHA；完整内层预测、来源隔离、训练内字段选择/填补/标准化、目标缩放、选模、控制复现、指标和全部门槛重算，核验不重训。
- `shape_schema_usage`区分可计算与实际使用：3E10%有368次内层拟合因训练覆盖不足未保留形状字段；2E10%全部400次形状拟合均未保留形状字段，两视图实质等价。
- `shape_precision_plan/results.json`：另行冻结的0拟合读图敏感性分析，260项解析界限/极端向量核对。固定圈数坐标时，18条3E20%形状记录中仅3条前段斜率、1条后段斜率、1条曲率在原纵向读图界限内符号稳健，峰位置均不能唯一确定。这提示微小形状对读图扰动敏感。
- 这些敏感性集合是逐点纵向盒界限；未传播横向或校准误差，也没有把界限当SD/置信区间。极端逐点扰动未必构成物理可实现曲线，不能据此证明唯一误差原因、伪造噪声分布或删除来源。

复核命令：项目ML环境执行`python -B tools/verify_retention_shape_v4.py`。训练脚本禁止再次执行已开始/已完成轮次。论文原件、P1～P7、v7/3b保持；滚动首页/进度/预览允许任务完成后更新，其冻结前/发布后SHA单列`post_fit_publication_receipt.json`，科研输入不在该例外内。
