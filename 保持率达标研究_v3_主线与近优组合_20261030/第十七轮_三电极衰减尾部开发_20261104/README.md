# 第十七轮三电极衰减尾部开发

这一轮只改变三电极开发数据。前 20% 观测窗、八组配置、来源和曲线权重、三个基线与验收标准均沿用已有规则。用相同的 30 个旧作者终点比较前后结果，同时对扩充后的 32 个终点完整留出来源。第十六轮盐地碱蓬已揭盲，本轮仅作为开发来源，先前锁定的外部单篇结果继续保留。

咖啡渣碳 CGBC 的 64.8% 来自原论文 Fig. 11(a) 与正文的 1,000 圈、1 A/g 循环。按红色左轴读保持率，前 10%/20% 分别确认 3/7 个点。蓝线是库仑效率。一枚被蓝线部分遮住的方块不估算中心。复合样品的 55.9% 维持独立。自己的 BET、实际循环电位窗和电流质量口径没有可靠来源，保留缺失。[论文原文](https://doi.org/10.1016/j.solidstatesciences.2025.108046)

主 GPR 在扩充的 32 条、26 来源上得到 R² 0.614、MAE 4.118、RMSE 7.137 个百分点，8 个配置无同时达标。相同的旧 30 条中，MAE 2.571→2.748，来源配对差值的描述性 95% 区间为 −0.231 至 +0.603 个百分点。90% 绝对误差分位从 7.473 降到 5.773 个百分点。误差变化在来源之间不一致。

分别留出两条新增曲线，CGBC 预测 77.46%、作者 64.8%，误差 12.66 个百分点。盐地碱蓬预测 83.47%、作者 55%，误差 28.47 个百分点。当前 ≥5,000 圈的 24 个终点只有一条保持率 ≤80%，旧快照的 23 个中没有。下一轮优先找有足够早期点的长周期、大衰减三电极来源。分层阈值用于检查样本覆盖，验收仍覆盖完整数据。

NPCA 正文约 80%，Fig. 7(i) 蓝线近末中心约 76.83%，像素带约 73.90%～79.76%，不把近似文字替作精确终点。WHAC 67.03% 的前 20% 最多两枚可辨标记，OPC 同样不足三点。LCNC 的图注与正文样品不一致。H-LWCA 仅核到预印本，LC-67% 的木质素/PAN 共前驱体另列待审。其他模型路线与原数据保留。
