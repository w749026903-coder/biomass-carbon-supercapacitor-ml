三电极正文明确为 3 M KOH，方法段写 Hg/HgO，而 Fig. 6(a,c) 横纵轴使用 SCE，循环参比保留未知。双电极段和 Table S2 未单独指明电解液浓度，按缺失处理。两项的实际循环电位窗和 A/g 质量分母也保留缺项。该材料的 BET 为 621 m²/g，可按相同材料对应到两项。两项都可以作为另行冻结的报告工况开发候选，双电极保留近似标签限制。两项终点均已查看。 [原文 §2.3、§3.2–3.3](https://pmc.ncbi.nlm.nih.gov/articles/PMC8912637/)

另核了三条出版社原图线索。甘蔗渣和牛骨粉共衍生碳有两个 20,000 圈面板，引用中的 63.7% 仍需与原文的样品、测试条件和初始参照对应。小麦壳 AC-800 的图可见约 82%／5,000 圈，实际循环体系和电流待核。镍泡沫器件的 51.4% 来自 PVA/KOH 固态器件，以 5.0 mA/cm² 测试，单列体系。 [相关图件与判定](related_sources.json)
