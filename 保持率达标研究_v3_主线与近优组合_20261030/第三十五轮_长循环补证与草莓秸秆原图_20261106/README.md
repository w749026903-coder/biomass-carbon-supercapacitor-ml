# 第三十五轮 · 长循环补证与草莓秸秆原图

核查 SSC-700、丝瓜络 PACs 和草莓秸秆 SPC₃。三电极长循环重衰减仍只有一个已进入开发快照的来源。本轮新增两个可审查的草莓秸秆开发候选，来自同一篇论文。终点已见，正式准入、拟合和独立验收均为 0。

刊本第 8、10 页的原生嵌图分别校准。每个早期标记用两档阈值核中心，圈数不确定上界超出窗口的点剔除，作者归一化起点单列。两个体系同用 SPC₃ 的 2746.5 m²/g，后续分别建模并保留同一论文来源家族。80.6% 属于草莓秸秆双电极的倍率比较。竹秆碳另有 75%／10,000 圈，论文明确是 CV 循环，另列测试方式。 [竹秆碳原文](https://onlinelibrary.wiley.com/doi/10.1002/est2.70178)

用第 19 轮的固定早期距离尺度复查可比性。草莓三电极和既有最接近样本的距离为 0.56，两者的报告电流、电解液、浓度、电位窗和目标圈数一致，作者终点仍差 5.29 个百分点。双电极草莓和咖啡的早期距离为 0.68，但一个是 6 M KOH、10 A/g，另一个是 1 M 硫酸、2 A/g，按不同工况保留。当前证据支持继续补可比论文，仍不足以判断哪种工况或材料因素解释差距。
