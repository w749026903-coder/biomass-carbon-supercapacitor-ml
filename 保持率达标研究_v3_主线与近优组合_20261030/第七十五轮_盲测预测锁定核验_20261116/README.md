# 第 75 轮　芥菜壳碳独立单例

2026 年 11 月 16 日。首次在本轮目标范围内完成新来源的预测锁定与揭盲。PSCN 来源为 Pramanik 等的芥菜壳碳论文。原文第 3、5、8 页及 Fig. 7(d) 对应三电极、3 M KOH、2 A/g、10,000 圈。比表面积为 618 m²/g，计入当前主范围。本轮没有 BET ≥1,500 m²/g 的独立样本。[作者刊本存档](https://hdl.handle.net/10023/24153)

## 锁定输入与揭盲顺序

- Fig. 7(d) 的纵轴为比电容。依据正文所述初始电容，采用同曲线的起始标记作图读参照。前 20% 取得 9 个正圈数标记。末个约 1,786 圈，加上横坐标误差仍在 2,000 圈以内。输入变幅约 3.05 个百分点。
- 核对两套数据库、6 个旧题录或引文命中及全部 18 个开发来源的作者资料，未发现共同来源或已存的相同终点。把输入清单与文件指纹提交后运行第 64 轮及第 67 轮冻结配方。预测提交 `13ee6da` 推送至 GitHub 并核对远程 SHA 后才读取作者终点。
- 锁定程序以两篇历史留出记录复算模型和简单基线，2 条记录的 5 列预测都与存档一致。另通过 16 项输入检查，包括终点字段、过窗测点、已有终点和工况不符的拒绝检查。

## 10,000 圈结果

作者报告约 **93%** 电容保持率。右端原图读数约 92.35%，考虑图读误差与作者近似表述相容。评价采用作者报告值。

| 已锁定方案 | 预测保持率 | 绝对误差（百分点） |
| --- | ---: | ---: |
| 第 64 轮基准 | 93.207% | 0.207 |
| 第 67 轮中间圈数候选 | 93.193% | 0.193 |
| 训练来源均值 | 92.013% | 0.987 |
| 沿用早期末值 | 96.762% | 3.762 |
| 早期线性外推 | 81.208% | 11.792 |

两套模型在这个单例均优于三条简单基线。两者相差约 0.013 个百分点，远小于图读取精度和作者数值的报告精度。当前新来源已评分 **1 篇**，R² 无法估计，正式独立验收仍为 **0**。下一步继续纳入同范围独立论文，优先补高 BET 及前段平缓、后段衰减的样品。

红麻活性炭 Fig. 5(f) 的 5,000 圈记录归双电极纽扣器件。绿茶碳作者发表记录入口返回 403。两者未进入本轮评分。
