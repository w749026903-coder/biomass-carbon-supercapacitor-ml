# 第二十五轮三电极重衰减证据复核

现有三电极前 20% 开发快照的 32 条记录里，24 条到达至少 5,000 圈，其中只有盐地碱蓬一条的保持率不高于 80%。本轮针对可能补足这个缺口的论文核了体系、数据角色和原图。44 项核验通过，新增训练准入、拟合和独立验收均为 0。

| 来源 | 核对结果与待补证项 |
| --- | --- |
| 棕榈种子 GS-PSDC | 原文方法与 Fig. 5(iii–iv) 对应三电极，在 0.5 M H₂SO₄、10 A/g、−0.2 至 1 V 下循环 500 圈，作者保持率 63.1%。刊本 PDF 文字可查，原图下载本次返回 403，截图也未取得。方法写甘汞参比，CV 段写 Ag/AgCl，实际循环参比保留未知。先列短程开发候选，前 10%／20% 可读点仍待核。 [原论文](https://journals.aijr.org/index.php/anr/article/download/4789/549) |
| 纤维素 KOH 活化系列 | 三电极结果段报告 10 A/g、5,000 圈。刊本 Fig. 8(a) 的七条线没有可辨认的独立早期标记。五条可分色曲线的首末可见线段筛查范围均高于 80%，另外两条线末端接近，暂不单独定量。KOH-0.5 正文为 94%，用可见首末线段换算约 97.67%，读图范围 95.72%–99.66%。作者初始参照未核实，两种证据分别保留。 [UCL 刊本](https://discovery.ucl.ac.uk/10051070/1/C7SE00519A.pdf) |
| 大豆秸秆 SSC-700 与小麦壳 AC-800 | SSC-700 的三电极 73.97%／10,000 圈仍是优先补图项。小麦壳摘要报告 82%／5,000 圈，实际循环配置和早期曲线待全文。此次开放题录未列二者的公开 PDF。 [SSC-700](https://www.sciencedirect.com/science/article/abs/pii/S0926669022003892) · [AC-800](https://www.sciencedirect.com/science/article/abs/pii/S0961953420304438) |
| 椰壳 AC1 与棕榈空果串 | 椰壳 AC1 的 70%／5,000 圈来自有机电解液的双电极器件。棕榈空果串的方法段明确 CV 用三电极，GCD 用双电极，因此 Fig. 8 的循环归入双电极候选，原图仍缺可确认的实测标记。 [椰壳刊本](https://cusat.ac.in/naac/criteria3/3.7.1/dop/collaboration455.pdf) · [棕榈空果串原文](https://doi.org/10.1016/j.nxmate.2026.101640) |
| 食物废料碳/MXene | Fig. 9 测的是 MXAC2 复合电极。该图正文给出 82.15% 保持率、92.45% 库仑效率；另有一段将 92.4% 写为保持率。两个说法分列保存，未找到同篇纯碳对照的长循环曲线。 [原文](https://pmc.ncbi.nlm.nih.gov/articles/PMC13029227/) |
