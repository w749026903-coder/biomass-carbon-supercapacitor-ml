- 山药废料碳 YPC-4 属于 2E 对称器件。用于核协议的摘录只遮蔽了百分数，仍露出 10,000 圈前后的比电容 280 与 270 F/g，足以推算约 96.43%。已把这条转到已见开发候选。推算值与作者直接报告的保持率分开存储。后续文本只导出事先允许的工况、样品和证据位置，也遮蔽可反推终点的绝对电容、差量与区间。
