# 论文覆盖与保持率预测表现

2026年11月19日。18篇、23条的1–6 M KOH温和早期开发组，来源等权 Pearson r＝0.9526、R²＝0.9007、MAE＝1.662、RMSE＝2.187个百分点。30篇、36条的宽范围初探 r＝0.8622、R²＝0.7271、MAE＝3.443、RMSE＝5.683；同一30篇统一随机森林 R²＝0.6789。两种规模均未达到 R²＞0.95。

文献篇数按实际被整篇留出并评分的不同DOI计数；一篇中的多材料、多条曲线不增加篇数。先对每篇等权，同篇内部按曲线等权。r 衡量趋势是否同向，R²反映预测相对实测均值能减少多少平方误差；r不能代替R²。MAE和RMSE均以保持率百分点计。不同范围的R²不能作学习曲线；不能推出增加论文会导致精度下降。

12条不属温和工况的记录来自11篇，仍全部计分；它们占30篇总来源加权平方误差的90.8%。30篇结果按论文成组重抽样，R²描述性95%区间0.505–0.899，不能代替独立验证。18篇组逐篇暂去（不重训）R²为0.794–0.915。

已有34篇直接预测来源与30篇早期曲线来源重合25篇，合计39篇；9篇只在前者出现，9篇均能定位本地原文。按现有终点的已报工况，只有2篇有记录满足当前2–6 M KOH、电流及目标圈数筛选：海藻碳 AHPC-850 的图4d（红色保持率，黑色效率）、CMC-ZnK-800 的图8d（图10d是器件）。先复核归一化基准、读图精度、前20%测点和幅度后再决定是否接入；即使两篇均通过，15篇主范围也只到17篇，30篇宽范围最多到32篇。这两篇是已知终点的开发来源，不能当独立盲测。若老师真正要求30篇同工况，以现行15篇计还缺15篇；即使这两篇均通过仍缺13篇。后续优先按同一测试协议补近三年新来源，评价前锁定范围与模型，按来源保留新盲测。
