# 第78轮：万圈相似曲线试验，未通过，保留原模型

本轮只比较一个方案。测试论文的全部样品一起留出；预测只看目标前20%的曲线与已知工况。用500、1,000、1,500圈作为对齐坐标，只在实测点之间插值，不外推。要求至少两个坐标读图半宽不超过2个百分点，末点也足够清楚。对不同论文先按早期保持率、电流和KOH浓度匹配，再从最多三篇参照的万圈实测中借用后续变化量；少于两篇则沿用原预测。模型的输出仍是指定圈数的电容保持率。预测计划在计算分数前以提交 a7a82d4 冻结；该开发集的既往误差已知，此次不是新盲测。

12条万圈曲线核对145个原始早期读数（含作者标记和已标注的密集曲线取样，均非独立训练样本），各读数的横纵坐标上下界保留。7条实际调用参照，1条改善、6条退步；其余5条万圈记录照常计分，没有删掉难例。其余8条非万圈预测逐条不变。整体P90绝对误差3.443→4.916个百分点，最差绝对误差6.858→7.148。按论文配对重抽样，平均误差变化为+0.657个百分点，描述性95%区间约−0.045至+1.512。样本小，不能断言所有类似方法在新来源上都会变差；但本方案没有满足预先规定的升级条件。

KAC-5 与 SPC3 同为三电极、6 M KOH、10 A/g，电位窗为−1至0 V，参比均为Hg/HgO。在三个比较位置，插值保持率的均方根差只有0.48个百分点，三个读图区间均重叠；实际万圈保持率为90.31%与95.60%，相差5.29个百分点。比表面积分别为1,441.3与2,746.5 m²/g，这一对不能证明BET是差异原因。区间反映图读精度，不代表测量置信区间。能辨别的早期轨迹相近，不足以保证后段衰减相近。SD-AC是本次退步最大的样品：实测87.03%，原模型89.33%，相似曲线94.18%；其电位窗缺失，已标明，并非由相邻样品补填。

**回档与下一步。** P64/P67仍是原参照，当前训练指针、数据库、旧预测与外部样品记录未改。本轮结果单独留档；不在这些结果上继续改距离或筛掉SD-AC。原开发分数距0.95还差0.0541；独立已评分仍1篇，独立R²不可估，正式验收0。总体持续目标仍暂停。下次优先查 KAC-5、SPC3 两篇已有正文是否对各自样品共同报告孔径分布或微孔占比、表面化学和相同的循环协议，再到其他论文检查该描述符的覆盖和可区分性；若多数缺失，优先补原始曲线、SI或独立来源。新变量进入模型前另议、另冻方案。千圈继续锁定原模型与早期末值对照，不在已知绿茶终点上改权重。
