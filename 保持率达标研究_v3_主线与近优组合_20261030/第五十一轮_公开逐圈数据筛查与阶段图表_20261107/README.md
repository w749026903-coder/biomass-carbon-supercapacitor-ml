# 第五十一轮 · 公开逐圈数据筛查

按冻结计划下载两份公开研究原包，均与仓库公布的大小和 SHA-256 一致。一个候选缺可机读的循环表与试验绑定，另一个候选属于钠离子电池。新增可用早期输入、预测锁定、拟合、正式准入和独立验收均为 0。
