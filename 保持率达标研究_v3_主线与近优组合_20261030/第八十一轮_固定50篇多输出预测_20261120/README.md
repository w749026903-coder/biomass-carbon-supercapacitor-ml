岭回归、随机森林、稳健梯度提升，以及在看分数前固定的岭回归与随机森林各半组合。每篇作为整体留出、每篇等权。50篇先锁定，再锁定算法；所有结果均是开发比较。看过多个模型后的最高值只能用于提出下一步假设。表格主列统一报告预设组合。模型输入从未使用论文编号、样品名或未来测量。BET预测排除同次吸附实验衍生的面积和孔容。倍率比电容的1 A/g实测值是合法的额外输入，不是长期循环起点。

在同一批有两套输入的24篇、30条终点上，固定组合的材料工况预测 r＝0.372、MAE＝4.82 个百分点；早期曲线预测 r＝0.888、MAE＝2.95 个百分点。两者各自训练所用的论文范围不同，这证明在共同测试记录上后者表现更好，仍不能单独量化增加早期输入的因果贡献。

50篇基本工况压力测试中，37篇可提供拟合数据，每次预测一篇时排除该篇全部记录。其余论文只接受预测。单列的敏感性记录含读图约186%的保持率，固定组合对这一条预测约96%，这会显著影响RMSE。此记录不训练、不裁到100%，也不因误差大而剔除。

历史上，较窄的18篇温和早期曲线组曾有 r＝0.9526、R²＝0.9007、MAE＝1.66个百分点。它说明这个小范围值得继续，不代表50篇已达标。没有一篇新盲测用于本轮。不同目标的MAE单位不同，不能横向排大小。
