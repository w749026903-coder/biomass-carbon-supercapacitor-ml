# 第三十四轮 · 阶段诊断与研究转向

暂停原定的咖啡碳拟合。第 29 轮和第 31 轮都扩大了可用数据，但用同一批旧记录比较，预定主模型的改善很小。第 29 轮双电极下降 0.039 个百分点，第 31 轮三电极和双电极分别下降 0.013 和 0.131 个百分点。三次按来源配对的描述性区间均跨零。目前有可靠的数据进展，缺乏模型精度持续向门槛靠近的证据。第 31 轮 16 个配置无同时达标，正式独立验收为 0。

**三电极缺少长循环重衰减参照。** 盐地碱蓬是该范围唯一的开发来源，占主模型加权平方误差的 61.0%。按第 19 轮冻结尺度在其他论文找早期近邻，距离最小仍为 2.75，高于近邻门槛 1。即使把平方误差最大的三个来源预测设为完全正确，并保持其他预测和样本原样，仍过不了 R² 与 RMSE 两道门槛，至少要修正四篇。优先核清 SSC-700 的实际循环电流和丝瓜络 PACs 的 Fig. 9e、实际工况。两篇终点已见，只作为开发补证。同时另建未见来源的验证队列。

**双电极的误差分布更广。** 最大误差来源占 21.7%，前三占 53.4%。同样的乐观复算至少要完全修正十篇才能通过 R² 和 RMSE，尾部误差仍未通过。咖啡 AC-CSS 的最近早期参照距离为 1.49，高于门槛 1。两者同为 10,000 圈、1 M 硫酸、0–1 V，报告电流却为 2 与 5 A/g，正文终点相差 15.9 个百分点。咖啡数据适合补工况覆盖和做开发对照，当前先保留两种终点证据。等能加入跨论文、相近工况的可比样本后，再冻结一次整来源对照；常规样本和重衰减样本的误差分开看。

上述修正来源数只用于计算现有预测的误差预算。近邻结果也只反映冻结尺度下的覆盖，尚未传播图读不确定性。现阶段保留已批准的前 10%／20% 窗口、双／三电极分轨、RF、GPR、XGBoost、静态组合及 A 路线。后续若相近且条件可比的来源仍出现远超测量误差的终点分歧，再讨论新增观测或调整适用范围。正式验收继续使用预测先锁定、终点后揭示的多篇独立来源。研究目标保持进行中，本轮新增拟合与正式准入均为 0。
