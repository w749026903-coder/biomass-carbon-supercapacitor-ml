## 从原论文补出了什么

**壳聚糖碳 AF-MMTC3。** 原始图4e中，橙色空心三角能和附近的其他样品区分。前1000圈中可辨认出约第48、96、248、496、747圈五个内部点，读得保持率约97.95%、96.12%、97.95%、96.12%、98.09%。第5000圈图读约96.82%，与作者报告的96.9%相符。早期特征仅由五个内部点计算，正文终点单独保存。该论文六条曲线重叠，沿用原队列的敏感性分析用途，同文可用样品由4种增至5种。另一个样品AF-MMTC0仍只有两个可区分标记。[原论文图4e](https://pubs.rsc.org/en/content/articlehtml/2025/ra/d4ra08818b) · [像素坐标、标定及读图区间](逐图证据.json)

**烟秆碳 TCZn-800。** 图7a的两个小图能分辨起始和末期各4个充放电循环。测量每个循环在−0.8至−0.2 V内两个方向的历时，起始约14.57至16.19秒，末期约14.63至15.04秒。小图未逐条标明绝对圈数和主图使用的归一化参照。16个时间读数单独存入 `waveform_diagnostics`，只能核查波形。主曲线前600圈内仍只有约第200圈与400圈两个可定位内部点。[原论文图7a](https://doi.org/10.3390/ma15030924)

## 最值得取得的外部资料

8篇均已核查正文及可得补充材料。5篇需要化解保持率数值冲突，3篇需要更密的早期观测。Figshare、Zenodo、DataCite此次检索未发现能直接补齐缺口的原始序列。柳木碳在ACS Figshare的补充PDF与此前核过的文件逐字节相同。8份正文PDF均无内嵌附件。检索范围、未返回的请求、原件指纹和数据库记录保存在[检索记录](公开资料检索记录.json)。

- **优先要藻源碳 AHPC 的原始循环表。** 同一张表若包含五种材料、圈数、容量或保持率、库仑效率及初始参照，可一次复核五种材料，并核清AHPC-850的图文差异。它们仍只算一篇独立论文。论文说明可向通讯作者索取额外电化学数据。[AHPC原文](https://doi.org/10.3390/molecules31132329)
- **最小补证是烟秆碳的一条观测。** 需要原始表中严格介于0与600之间、区别于已读两点的一条可定位保持率，附归一化参照和对应工况，便可重新核定该样品。论文也说明可向通讯作者索取数据。[TCZn-800原文](https://doi.org/10.3390/ma15030924)
- **DC-900优先要初始与末端电容。** 图3g标90.3%，文字为92.4%；若取得同一工况使用的初始电容和第10000圈电容，便可直接复算。其余各篇所需原件、图号、样品和圈数均已列明。[8篇原始数据需求及DOI](8篇原始数据需求_DOI.csv)

继续反复读取相同图片无法恢复作者未画出的点。取得新序列后，先核样品、工况、归一化起点及终点，再按同一合同判断用途。
