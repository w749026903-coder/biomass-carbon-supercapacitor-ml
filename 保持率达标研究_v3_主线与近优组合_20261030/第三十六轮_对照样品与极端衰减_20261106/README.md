# 第三十六轮 · 对照样品与极端衰减

在项目已有的正文 XML 中扫描到 162 篇带三电极方法线索的独立 DOI，按长循环与保持率词组挑出优先核图对象。跳过两批盲验候选。逐篇核验蜂蜜衍生碳和稻草纯活性炭，取两篇刊本和原图，不把筛查词组视为实验证据。

| 来源 | 核实结果 | 用途 |
| --- | --- | --- |
| 蜂蜜衍生 HD-GNS，Fig. 16(b) | 同图黑色比电容由约 101.05 F/g 降至约 1.01 F/g，10,000 圈图读保持率约 **1.00%**，像素传播范围 0.30%–1.70%。红色约 80% 是库仑效率。作者报告 1.1 A/g、0.5 M Na₂SO₄，电极方法为三电极。 | 长循环极端衰减候选。原文将 0.9 F/g 写在 1,000 圈句中，Fig. 14 还被误引为循环图。精确终点、循环样品干燥条件和载量口径继续待核。图读值进入证据台账。 [刊本 Fig. 16](https://www.nature.com/articles/s41598-026-62039-8#Fig16) |

两条曲线前 20% 各有 3 个可用标记，前 10% 各只有 1 个，后一窗口不能形成现行特征。蜂蜜的早期重叠点和窗口边界点未纳入。蜂蜜读图保持率约在 1,500 圈就降至 16.8%，主要补早期急衰减形态。三电极模型仍缺少前段看起来稳定、后段大幅衰减的跨论文参照。正式准入、拟合和独立验收均为 0。

追溯到一条误引。后续论文将纤维素碳 76.55% 放进长循环叙述，但 Shan 等人的原始论文把它归为电流从 1 A/g 升到 20 A/g 的倍率保持率，已从长循环候选排除。 [Shan 等原文](https://pubs.acs.org/doi/10.1021/acssuschemeng.0c05520)

优先续查已有全文中有明确对照样品、前段点和同图终点的论文。蜂蜜和稻草均已看终点，只能用于开发。保留未见来源的盲验队列和 SSC-700、PACs 的原始缺项。
