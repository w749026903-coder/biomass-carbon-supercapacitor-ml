# 第十三轮 · MK9纠错复验

输出仍为指定圈数和条件下的电容保持率。第十二轮把MK9的绿色库仑效率曲线误作保持率，旧前20%结果作历史保留。第十三轮使用纠正后的蓝色曲线和65%保持率。前20%共27条、22个来源，依原来的16组配置、六项和形状表达及按论文留出的规则完成3,520次新拟合。前10%共23条、18个来源，2,880次拟合的输入、划分和预测记录逐项核对后原样引用。

前20%主方案 R² 0.477670，MAE 6.665814 个百分点，RMSE 8.896983 个百分点，90%绝对误差分位 15.641306 个百分点。直接沿用早期末值的 MAE 为 6.249555 个百分点，主方案比它高 0.416 个百分点。68个方法的数值门槛通过数为0，独立外部来源为0。相同数据与权重下，R² 严格大于0.95需要 RMSE 低于 2.7527 个百分点，同时满足其余门槛。

MK9是主方案误差最大的留出来源，预测 87.840%，原图65%。MMC、HPCS以及PC_NaCl的高保持率工况也是主要难例。按来源等权评估，最大单来源权重1/22，前5个来源贡献 53.0% 的绝对误差。MMC读图和共享参照限制仍存在。留出误差能定位难例，单凭误差不能判断某条原始记录错误。

198,304 项独立核验覆盖79个冻结对象、当前SQL准入、内外层来源隔离、折内编码、选模、预测汇总及门槛。审计通过预测归档核对结果，模型权重未独立重拟合。拟合失败与警告均为0。

中段监督候选由当前SQL准入的57条曲线生成，共1,273个按窗口计的候选读图位置，通过5,519项核验。早期点的圈数上界需在目标圈数下界乘以窗口比例以内。每曲线每窗口最多16个目标，按圈数挑选。保留读图区间及共享参照不确定性，下一轮可仅在训练来源中使用这些候选，模型选择和最终验收仍用原作者端点。本次候选盘点新增独立来源0、作者端点0、拟合0。
