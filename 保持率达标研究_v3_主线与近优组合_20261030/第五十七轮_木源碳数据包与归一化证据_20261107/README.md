# 第五十七轮 · 木源碳数据包与早期曲线绑定

每条轨迹比较同表五个样品列。匹配同时要求圈数和保持率落在已冻结的读图区间内，且配对圈数严格递增。同表其余列均无法匹配完整标记序列。三条轨迹来自同一篇木源碳论文，AWC 3-600 分别在两种电解液下测试。两份表合计 10 个样品条件列与 200 个早期数值，其中以上 3 个列已和刊本轨迹核对。其余列保留为来源数据，不计入可准备盲测的三条曲线。

每列在 100、200、…、2,000 圈各有一条记录。100 圈是归档最早记录，十列均为 100%，表头保留逐列“除以该列常数再乘 100”的公式。作者的物理基准圈数继续留空。把 100 圈基准记录单列后，前 10%／20% 分别有 9／19 个正圈数观测。设备为双电极，方法给出 10 mA 绝对电流、1.2 V 上限及 10,000 圈目标，质量归一化电流保留为空。

目前可准备 3 条早期输入，仍需核对同团队前作的试验谱系、旧项目是否曾见过本篇终点及拟合合同是否适用。关联论文暂按一个候选来源簇。终点暴露、预测锁定、新拟合、规范库准入、独立验收均为 0。通过来源核查后，再冻结有限盲测。该双电极证据无法填补三电极的重衰减数据缺口。
