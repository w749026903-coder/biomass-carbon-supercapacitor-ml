# 第三十三轮 · 刊本原图复核与咖啡副产物碳补证

咖啡副产物碳 AC-CSS 取得一条可供后续开发对照的双电极曲线。正文 Fig. 6(b) 的比电容纵轴有断轴，实际提取改用 SI 第 3 页 Fig. S3 的保持率矢量图。正文方法明确 1 M H₂SO₄、0–1 V、2 A/g、10,000 圈。电流按单个电极内的活性碳质量归一，SI 表 S1 中两个电极各有 2.93 mg 活性碳。BET 与 QSDFT 面积继续分列，本条 BET 暂空。

| 核查项 | 结果 |
| --- | --- |
| 前 10% | 6 个独立矢量标记，最后一个约 750 圈、89.01%。 |
| 前 20% | 8 个独立矢量标记，最后一个约 1,501 圈、86.94%。 |
| 初始参照 | SI 显示作者归一到 100% 的图上起点。保留该锚点，计算早期特征时剔除。实际参照圈的精确编号未推定。 |
| 终点 | 正文为 75%，SI 末点约 74.05%，图形读数范围约 73.59%–74.51%。两种证据分别保存。后续如采用，拟合前冻结口径并检验敏感性。 |
| 同论文其他曲线 | 五条加醌电解液、一条商用 YP-80F 对照单列。7 条曲线共 126 个矢量标记，整篇只计一个来源家族。 |

在检查咖啡补充图的 PDF 对象时，诊断输出带出了早期窗外的图形坐标，足以构成终点可反推风险。已先记录暴露并冻结开发用途，再核读正文和 SI 的实际结果。咖啡来源按已见处理，从盲验候选移除。本次暴露只涉及咖啡。柚子籽碳两个面板在原生图上仍以连续色迹为主，尚未确认分离的实测标记，终点继续封存。

两套现行数据库查无本论文 DOI；新增正式准入、拟合与独立验收均为 0。已核对 3 个原始文件指纹、正文断轴、SI 矢量轴和 126 个标记。单独栅格化的彩图核对了 AC-CSS 图例、部分早期重叠点与终点，早期特征另用直线回归复算。后续先锁定双电极来源留出和 75%／74.05% 两种标签的敏感性，再评估这条低保持率曲线的开发价值。
