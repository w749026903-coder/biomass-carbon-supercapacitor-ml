# 第十四轮中段监督对照

两电极和三电极分别建模。每种体系使用相同的前20%观测、整来源留出、8组固定配置和折内选模规则。每个配置一组只用作者端点，另一组把每曲线的25%训练权重分给该曲线的中段读图点。预处理只使用本折的训练作者端点。GPR通过逐点观测权重控制训练，两组用同一权重定义，本轮应按配对对照解读。读图值及误差盒保存在输入快照内，盒宽不解释为独立随机噪声。

当前目标继续active。第十四轮按双/三电极分别比较前20%窗口，只在训练论文中加入中段读图点，曲线内中段总权重25%。3680次固定拟合、0失败和警告、798214项检查及87个冻结对象。双电极主对照MAE从5.769490升至6.347201pp，R²从0.591199降至0.573045。三电极MAE从3.087814降至3.021428pp，R²从0.675768升至0.683879，按来源配对的95%区间跨0，尚无稳定收益。42个方法0同时过数值门槛，独立外部验收来源0。双电极377、三电极402个读图位置仅作折内监督，作者端点继续用于内外层评价。3条仅题名和DOI的外部预留已查当前库与项目文本，实验及前作关系待核。2条终点已曝光的线索单列开发。下一步推进外部证据核验与训练来源可辨识性，不以本轮轻微变化替换旧主线。A、10%窗口、近优及稳健路线保留，当前A/B入口仍为v7r1/3h。

按来源等权比较，双电极的MAE变化为+0.578个百分点，描述性配对95%区间为−0.061到+1.246。三电极变化为−0.066个百分点，区间为−0.431到+0.305。两者均跨0。双电极7/22来源误差下降，三电极14/24来源误差下降。两电极加入中段后超过了沿用末值的6.250pp基线误差，三电极对沿用末值3.408pp的改善不足20%。

核验重算折内来源和曲线权重、成对预处理、作者端点选择与指标，估计器权重未独立重拟合。三个外部预留只做题名、DOI和已有来源排查，待核实验和家族关系。作者终点公开摘要已出现的两条开发线索不计入盲测候选。
