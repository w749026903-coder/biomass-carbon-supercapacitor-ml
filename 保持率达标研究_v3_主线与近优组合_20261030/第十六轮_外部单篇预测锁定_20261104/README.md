# 第十六轮外部单篇检验

盐地碱蓬 JPC-800-0.5 的双电极和三电极使用前 20% 观测预测第 10,000 圈的保持率。按公开图的圆弧重新核对贴边与重叠点。三电极前 10%/20% 使用 7/14 点，双电极为 9/10 点。双电极靠 2,000 圈的标记保留在图中，因圈数误差上界可能越窗而未进入特征。接近图原点的读数和高于 100% 的读数按作者轴原样保留。

两体系分别使用第十四轮的训练作者端点拟合 8 个已冻结模型。按既有来源留出 MAE、RMSE 和配置 ID 排序，GPR 预先定为两体系主模型。静态可选字段缺失继续按原规则处理。16 次拟合无失败和警告，主 GPR 用矩阵求解独立重算，52 项检查通过。预测提交 `4e7d5a4` 经远程 SHA 确认后才揭示终点。

| 体系 | 锁定主预测 | 作者终点 | 绝对误差 |
| --- | ---: | ---: | ---: |
| 双电极 | 93.94% | 91.6% | 2.34 个百分点 |
| 三电极 | 84.06% | 55% | 29.06 个百分点 |

双电极作者值来自 §3.3 及表 4 本文行，图读约 91.54%。三电极作者值来自 §3.2 的 10,000 圈段落，图读约 55.36%。55% 的整百分位舍入区间与读图盒相交。原文另有近似比电容 95 和 54 F/g，保留原报道及其近似算术，不将近似比值替代保持率终点。两幅原图的证据在预测锁定后才公开至本轮记录。

双电极同组三种其他模型在这个单例中误差低于 1 个百分点，完整结果保留，主配置不改。三电极 8 个模型全部高估，预测范围约 79.67% 至 84.06%，而训练作者终点范围为 62.2% 至 109.2%。沿用早期末值的三电极绝对误差 31.72 个百分点，线性外推误差 23.15 个百分点。该例给出了严重衰减外推失败的直接证据，无法由单篇推断整体泛化或 R²。该论文已揭盲，正式独立外部验收仍为 0。
