2026-10-18，接续用户“继续，直到全部达到准入标准”的要求。本版继续补提取和核查，但没有把不能满足研究范围或缺少证据的记录写成合格。

## 本轮实际核查

新增35条均重新定位作者自己的实验段落，包括同样品不同配置、电解液及CV/GCD测试。QSC系列同篇多样品、CEPAC两种电解液、Longan三电极CV与对称器件GCD均分别记载，仍保留同篇来源分组。EC-10%和牛仔布AC800的损失补数标为推算关系；约117%的LCF-AW保留大于100及近似属性。

81篇文献的处置为：23篇有自有数值端点待协议核对，10篇有冲突，11篇须图形或定性结果复核，6篇在原生文本中尚未定位数值标签，3篇预印本/身份问题，25篇旁系，1篇综述，2篇短测试。综述、锌离子容量、库仑效率、倍率表现和比较引用不能混入目标。所有判断都保留原文文档哈希与片段ID，旧分类未覆盖。

AF-MMTC六样品补24个方法字段：参比电极、表征窗口和载量。SI三页没有定位到BET数值表，不能把一个样品的表征分配给六个样品。另补44条参比定义、BSPC自己的表格BET425m²/g、AO-PC实际循环窗口−0.1至0.6V，共47个字段选择事件。ALPC的ORR参比Hg/HgO与电容测试Ag/AgCl明确分开。

补4条出版行年份并处理已有出版社日期对象的编码差异，再补14条年份，共18条元数据变更。只使用出版日期，未从DOI、收到或录用日期猜测。LC/rGO和BBC预印本的正式出版年仍未确定。

## 仍未达到准入的原因

所有168条相应用途记录的物理电流质量分母仍未得到终审认可。原文有A/g或电容公式不等于明确了循环电流分母；不能凭一般习惯补值。基线定义、材料/电解液范围、前作或共享数据关系和逐记录终审也仍有工作。125条缺少已绑定的实际循环窗口，83条缺少可用的自身BET。缺口是否“原文未报告”需要区别于“尚未定位/尚未终审”；本版没有把它们混称为未报告。

2018–2022年、短于1000圈、CV及不适用主体系的结果，即使补齐其它字段也不能全部进入当前主队列。它们保留在审查数据中。要实现“全部合格”，只能把它理解为最终逐条得到可靠处置，不能让所有原始资料都变成主队列训练样本。

## 调用

项目稳定入口仍为`data/cycling_db.py`，指针切换到本版后：

```python
from data.cycling_db import open_database

with open_database() as db:
    print(db.review_summary())
    data = db.fetch('review_3e_all')  # 90条，仅审查用途
    row = db.by_alias('V05', 'V05_004')
    gates = db.admission_checks(row['endpoint_id'], 'canonical_2e')
    observations = db.evidence(row['endpoint_id'], 'reported_current_A_g')
    holds = db.holds(row['endpoint_id'])
    reviewed_papers = db.paper_reviews(disposition='own_conflict')
    original_and_review = db.claims(doi='10.1039/d5ra01262g')
```

`review_3e`仍是原53条优先记录，`review_3e_all`为全部90条标为3E的记录，`all_review`为191条混合审查记录。`strict_2e`、`strict_3e`当前为空，调用训练矩阵会明确拒绝，不回退到待审数据。`proposal_2e`沿用旧8条报告工况提议，不能当作严格准入。

API只读、默认校验数据库哈希，逐字段可回到原值与证据。`queue()`中的`status`沿用父版任务状态；新增`current_disposition`、`current_review_reason`、`remaining_work`反映本轮核读，不改写旧队列。

直接核查见[逐条准入缺口CSV](exports/逐条准入缺口.csv)、[完整检查单元](exports/record_admission_checks.csv)、[逐篇处置](exports/paper_source_reviews.csv)、[冲突与排除说明](冲突与排除说明.md)和[下一步证据队列](下一步证据队列.md)。

## 版本与核验

v0.4及更早版本和原论文/SI保留原位；本版为SQLite备份后的独立副本。原观察、变更链、冻结、来源分组与旧表保留，新增选择、出版更正及用途状态均有历史记录。

核验覆盖完整性、外键、父版逐行保留、旧文件哈希、变更链、选择证据、缓存一致、原始线索隔离、逐项门槛、来源分组和模型调用预检查。核验数量与哈希以[核验报告](核验报告.json)、[清单](merge_manifest.json)为准；技术通过不代表科学准入。没有训练、上传到第三方模型服务或移动原文库。
