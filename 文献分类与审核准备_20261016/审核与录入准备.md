# 审核与录入准备

当前研究对象是生物质衍生碳超级电容器，文献发表范围为2023年至今。预测的输出性质尚未确定。本轮分类用于安排阅读，不代表论文数据已通过审核。

## 下一步先做什么

先从已有全文中审核少量原始实验，建立字段完整性的真实样例，再决定扩展顺序。暂不运行模型，也不要求把剩余63篇全部找齐才能继续。

第一批建议阅读R078、R091、R093、R103、R105、R106、R108、R111、R112、R117。这些论文覆盖原料、活化和热处理条件，已有全文且不属于本轮已明确冻结的来源。选择它们是为了核对记录格式与条件差异，不是因为性能更高；未确认每篇都有完整补充材料或足够训练样本。

方法阅读另排R002、R005和额外资料SRC087，重点看数据从哪里来、同一材料是否在不同电流下重复出现、如何按来源分组验证。SRC087是接受稿，需要核对正式信息和数据。综述用于找原文和理解机制，不抄成新的独立实验记录。

## 每篇的审核顺序

1. 核题名、DOI、正式发表日期与PDF版本。正文自己的DOI应与题名对应，不能只命中参考文献中的DOI。2022年预印本不能直接替代登记为2023年的正式论文。
2. 核材料前驱体和成品：原料种类及部位、是否碳化、是否负载金属/金属氧化物/聚合物、商业活性炭来源是否明确。活化时用金属盐不自动等于最终材料含金属，必须查洗涤与成分表征。
3. 建立样品编号。论文中的每个制备配方对应一个material_id。同一样品的不同电流点、不同电解液和两/三电极测试共用该material_id，分别建立测试记录。
4. 核测试条件与分母：两/三电极、对称/非对称、电解液、浓度、电压范围、活性物质质量、质量负载、质量/面积/体积归一化，以及单电极或器件口径。没有这些条件时保留缺失，不强行换算。
5. 按表格、正文、图像数字化分别摘录。每条保留PDF页码、表图编号、单位、原始值、提取方式及核验状态。计算得到的值另存，原值不覆盖。
6. 检查公式与量纲。倍率保持率要有高/低电流端点，循环保持率要有循环次数和参照记录；两者不能合并。存在关键单位矛盾时暂停相关数据导入，不凭常识改数值。
7. 为具体记录作准入决定。先确认来源、对象、口径和出处，再检查缺失、重复与一致性；不得因性能高低、降低模型分数或不符合预期趋势而删记录。

## 四张表及对应关系

`数据库录入准备`内只有表头，没有虚构示例值。

| 表 | 一行代表什么 | 关键联系 |
|---|---|---|
| 文献表 | 一篇原始论文或一份明确标注用途的背景文献 | paper_id、DOI |
| 材料样品表 | 一个有来源的制备样品 | material_id关联paper_id |
| 测试记录表 | 同一样品在一套条件下的一个报告指标 | test_id关联material_id和paper_id |
| 问题日志 | 一个具体字段或来源问题 | 可关联paper_id、material_id、test_id |

一篇论文可有多个材料，一个材料可有多条测试。综述引用原文、机器学习汇总数据、预印本与正式版共享底层样品时，要追溯至同一原始来源，不能重复计作独立材料。

## 字段解释与单位

| 字段或字段组 | 意义与记录规则 |
|---|---|
| precursor_species / precursor_part | 原料种类与部位，例如同一植物的叶、壳、茎分开。不要把原料元素含量当成品碳元素含量。 |
| route | 干法热解、水热碳化等工艺分别记录。不能把水热温度直接当普通碳化温度。 |
| carbonization_temperature_C / activation_temperature_C | 温度单位为°C，碳化与活化各自记录。原文明确为同一步时注明，不虚构另一步。 |
| carbonization_time_h / activation_time_h | 时间统一到h，原始单位与换算过程留在出处记录；未知留空。 |
| activation_mass_ratio_basis | 明确“活化剂/原料”还是“原料/活化剂”、原料是生物质还是预碳化产物。 |
| composite_components / residual_metal_status | 区分非金属掺杂、金属/氧化物、聚合物、石墨烯/MXene等。金属辅助制备后成品是否残留必须另核。 |
| SSA_m2_g | 比表面积m²/g；原文单位冲突时保持问题状态，不直接换算。 |
| pore_volume_cm3_g / micropore_volume_cm3_g / mesopore_volume_cm3_g | 总孔、微孔、介孔体积，单位cm³/g，方法不同也要记录。 |
| pore_size_nm | 孔径nm；均值、主峰、分布区间不混为同一字段。 |
| element_content_stage / element_measurement_method | 原料还是成品，以及XPS表面原子百分比、元素分析质量百分比等测量口径。 |
| active_mass_mg / mass_loading_mg_cm2 | 活性物质质量mg与面积负载mg/cm²分开；两电极总质量和单电极质量也要区分。 |
| metric_name / metric_value / metric_unit | 指标名、数值、单位分开，可保留比电容、倍率、循环、能量、功率等候选，尚未选定模型标签。 |
| normalization_basis / mass_basis | 质量、面积、体积；单电极、两极总量、活性组分或整电极等口径。 |
| current_density_value / current_density_unit | A/g与mA/cm²分别存单位，没有对应质量负载时不互换。 |
| voltage_window_V / scan_rate_mV_s | 电压跨度V和扫描速率mV/s；保留参比电极和起止电位出处。 |
| cycle_number / retention_reference_test_id / retention_endpoint_test_id | 循环次数及保持率参照、终点；倍率保持也必须明确两端条件。 |
| reported_or_derived | 原文报告、依据明确公式推算或图像数字化，不能混写。 |
| source_pdf_page / source_table_figure | 使用PDF页序，并注明正文印刷页码如不同；写清表/图/面板号。 |
| extraction_method / verification_status | 正文、表格、图像数字化等；区分待核、已核与冻结。 |

CSV空白表示尚缺，不能当0；不编造缺失值。不对图像提取结果伪造精度，也不把文献中最佳样品自动当唯一可录入样品。

## 当前必须单独处理的问题

R001的二手训练表S1禁止整体导入。R088的关键单位已出现疑点，暂停数据录入。R024含Ti，按金属参与的材料分层。R115是未碳化木质素与活性炭的复合，活性炭前驱体需另核。原5个冻结/排除来源继续生效。详细证据见`问题登记.csv`。

取得PDF、自动检索到指标关键词、被分进原始实验类，都不等于可训练。后续确认真实样品数、条件完整性和输出指标可比性后，再确定预测问题、分组留出和模型比较。
