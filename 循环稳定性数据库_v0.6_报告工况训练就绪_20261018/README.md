# v0.6 报告工况训练数据

本版已提供能直接读取的特征、标签、来源分组、权重和验证折。研究目标是给定循环次数与论文报告条件下的电容保持率。实际模型拟合尚未执行。

| 调用名称 | 记录 | 来源组 | 输入列 | 用途 |
|---|---:|---:|---:|---|
| reported_3e（默认） | 14 | 9 | 8 | 三电极主集 |
| reported_2e | 11 | 11 | 7 | 对称双电极主集 |
| reported_2e_residue | 13 | 12 | 7 | 加入残留物争议记录的敏感性分析 |
| reported_2e_approx | 14 | 13 | 7 | 再加入近似标签的敏感性分析 |

双电极三集合是嵌套关系，不能相加或拼接。三电极与双电极分别建模；同论文跨配置也沿用同一来源组。来源组来自既有文献/复用关系审查，不代表已证明不存在所有潜在相关性。

## 读取与导出

在项目根目录运行：

```python
from data.cycling_db import open_database

with open_database() as db:
    dataset = db.fetch()  # reported_3e
    matrix = dataset.feature_matrix()
    X, y = matrix['X'], matrix['y']
    groups, weights = matrix['groups'], matrix['sample_weight']
    folds = dataset.source_folds(len(set(groups)))
```

也可读取本目录 [training_inputs](training_inputs/cohort_summary.json) 中的 JSON/CSV，JSON包含逐条复核依据和留一来源验证索引。CSV中的端点ID、来源组和标签关系是元数据，**不属于特征列**；应按JSON的feature_names取列。所有类别变量保持原始字符串，数值没有用0补缺。

需要重新导出时用 `python tools/prepare_training_inputs_v06.py --output 项目内全新目录`；工具拒绝覆盖已有目录。[preprocessing.py](preprocessing.py)只构造预处理器，不运行fit。编码、缩放及后续调参须在按来源划分之后、仅用训练折学习。原始电解液/参比类别未出现于训练折时，应记录域外类别；不能先在全数据上训练编码器再交叉验证。

数据调用与导出只需Python标准库。可选模型预处理使用本项目既有v0.2环境；依赖版本见[锁定文件](requirements-model-lock.txt)，本次没有安装软件。以该环境运行 `python -B tools/precheck_model_inputs_v06.py` 可以只构造RF、XGBoost、MLP和预处理器，验证接口而不拟合；结果见[模型预检查](模型预检查.json)。

## 准入口径

七项双电极输入：循环次数、报告A/g电流、电解液、浓度、循环窗口上下界、BET。三电极增加参比电极类别，电位不擅自换算到统一参比。标签是电容保持率，不混入容量保持率。主集只用论文点值；超过100%的活化现象不裁剪到100%。

未知电流质量分母保留为元数据。这里的电流是作者报告的协议描述量，不能解释为已校准、物理应力完全相同的电流。没有从电容公式推定电流分母，也没有进行虚构的单双电极倍数换算。作者初始值或图中归一化起点可作为报告保持率的基线；原文没有明确起始圈号时，数值圈号继续为空。详见[知识与依据](../docs/KNOWLEDGE_BASE.md)及[机器可读契约](data_contract.json)。

本轮逐条核查17个新增主集记录（14条三电极、3条双电极），窗口证据区分实际循环波形、明确循环段落和同样品/配置/电解液的GCD程序。后者不冒充单独标注的循环波形，相关适用性与局限记录在[逐条复核](逐记录报告工况复核.json)。继承的8/10/11条沿用第四轮已经复核的有效快照，避免用旧全局投影覆盖R112等已审修订。

CA-AA三电极标签由102%更正为101.35%：原文Fig7a及三电极段落明确101.35%，102%对应Fig7b双电极。旧102%观察值、来源和变更链保留。松木样品的孔体积单位疑点继续冻结；孔体积不进入本次核心矩阵。

## 已处理与待处理

191条结构端点全部有报告工况用途状态，并非191条全部准入。其它配置、年份范围外、短测试、近似或推算主标签、真实字段缺失及未完成原文复核分别保留。TE011的循环GCD插图电位轴与CV范围疑似不一致，仍待核图；HPC-P8已补640 m²/g及实际0–2 V循环波形，但电极配对活性质量依据仍待核。未为了增加样本数把它们写成通过。

这里的规模适合搭建小样本基线与检验调用流程，尚不足以支持可靠的大规模泛化结论或从头训练大模型。9个三电极来源组与11个双电极来源组使验证方差较大；后续扩充应以独立来源、条件覆盖和逐条证据为重点。不得将技术核验通过等同于科学结论可靠。
