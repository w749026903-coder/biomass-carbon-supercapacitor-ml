# 文献v22：林业多前驱体、松木与参考体系

本批在v21上追加四篇已有论文的全样品主表、正文与25个可得原图的范围核读。数据库为 `literature_material_pool_v22.sqlite`；238条材料事实含235数值、3项未报告，28条电容报告，66条测试或过程响应，38项分阶段登记。登记包含预炭化物、无活化对照、动力学前驱体和另批氢存储样品，不能当38种独立最终材料。旧库、原件和旧值不变。

14张原生主表候选完成指定范围核读，累计228触及、731未触及；56个已声明来源均未标为全文提取完毕。林业论文SI及另外10个主图未取得，现有图的连续波形、未转录柱值与其余资料继续在队列中。

- 林业论文：六种最终碳及其预炭化物、QSDFT总/微孔容、原BET与作者去灰折算、TGA空气燃尽代理碳分数分别保存。主表3/4用压片电极；含SiO₂/GO的涂布配方属于未取得SI，不能混用。水系窗口0～1 V有实际Fig8依据；有机窗口未取得。三条水系循环关联既有B2_004端点，三条有机记录仅新增文献候选，均未新增循环准入。
- 松木论文：五样品的一步600 ℃碳化活化、XPS整体原子百分比与C1s内比例、各孔结构测法分开。实际Fig4b是ID/IG，Fig5e为DRY-2，图注异文保留。总孔容仅DRY-1/WET-1由正文明确cm³/g补证；原表m³/g与未解微孔容量纲均保留。WET-1在0.1 A/g的正文/表247与倍率图低于220不符，该工况不作准入输入；DRY-1的146@0.1、59@15及WET-1的64@15 F/g三条GCD报告可调用。既有TE033/034循环端点保持。
- 尿布碳：SAP为主的混合废物参考，不因含少量纤维素就进入普通生物质集。两样品BET正文/表竞争冻结，元素分析百分比基准未明，NAPC-650-4不能继承650-2成分。Raman六个原图印字与XPS图/文峰位分存。87.65%是循环报告，不能替代250/353的倍率保持率。原图2E公式两倍系数及能量公式缺C均保留，不凭物理常识改写原文。
- 木质素/锰：八条是10 mV/s的CV电容；作者明确GCD、EIS和寿命为后续工作。F127及Mn名义投料不当最终成分，SEM-EDX百分比基准未知。MnO/Mn₃O₄复合与无锰碳分用途；动力学A/Ea/R²是制备过程响应。字面10 liters、0.3 mm和A的s⁻¹/min⁻¹异文不擅改。制备引用作者2021年硕士论文，未取得且不当另一独立实验。

调用稳定入口 `data.literature_current.open_literature_database()`；固定版本入口 `data.literature_v22`。`batch22_inputs(target)` / `batch22_matrix(target)` 需选择九个显式用途，行数依次3/3/3/3/3/3/1/5/3，共27个表达行。原/去灰两种表达共享物理测试组，不能合并扩样；每个用途内来源权重合计1。`batch22_decisions()`、`batch22_cycle_identity_links()`、`facts()`可检查所有原值和排除原因。九个CSV与`model_inputs_preflight.json`提供相同输入，不插补、不拟合。

普通3E辅助输入现192条/26 DOI，四个旧辅助用途合计208条/27 DOI；显式含旧图值扩展361条/26 DOI，前者嵌套在后者内，不能相加。循环仍v0.26、286观察，原固定39中2解决、37待证；完整历史审查视图41条不等于固定目标39条。

核验包括5756项原表/单元/SHA/原行/API/用途检查，以及9931个表示载荷、220标识、217来源家族隔离。载荷不是独立实验数，与不同范围的旧链不比较增长。所有旧检查链、冻结与循环状态保留。封版后只运行 `python -B tools/verify_four_sources_v22.py verify`；不要再运行curate/build/prepare/seal。
