## 数据质量和去重

所有测量使用原始JPEG像素，放大图仅用于观察。四面板分别校准线性刻度，按指定颜色、局部ROI和最宽标记跨度定位中心；不做曲线拟合、插值、强制单调或按性能择值。每个读数保留全部候选像素、标定、标记位置和上下界，叠图见evidence。

原图纵向±4像素界限对应：花椒皮约±2.15 F/g、花椒籽约±3.82 F/g；椰枣低电流约±2.98 F/g、高电流约±1.65 F/g。这是读图界限，不是SD/SEM/实验置信区间。低电容SAC1000的相对读图界限较大，不能据微小差值判优。十九个作者锚点均落在对应图界限内；作者的约数状态仍保留，`author_exact`不表示物理测量无误差。

椰枣6 A/g双捕获区间相交。选高电流面板f作为标称工况主表达，依据其单位F/g对应更多纵向像素；两份原始读数均保留，没有按数值大小或模型分数选取。正文/SI复述、原图捕获、材料多电流、同论文多个样品都不能拆成独立来源。
