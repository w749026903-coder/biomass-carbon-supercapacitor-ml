## 合并内容

以第四轮数据库为审查历史底座，原表每一行、每个单元格均与父库核对一致：231审查事件、285变更、134材料观测以及全部问题、冻结、来源关系和原值继续保留。只新增统一索引和合并规则，调整公共训练就绪视图，不改父库文件。

文献任务原20篇、新增50篇、用户26份PDF核验、217身份分类和53端点全部通过别名与DOI/原文件哈希关联。无DOI记录保持为空，使用文件哈希连接相同文件；未凭题名相近擅自合并。新增文献仍在候选层，不写入旧papers/materials/cycling_tests正式表，不移动D:/文献原库。

来源文件保持原位，通过merge_input_files、literature_observations、literature_aliases、literature_availability和unified_source_groups追溯。225个分组是当前索引的分组表示；新来源分组为暂定，不代表完成跨论文材料和前作独立性终审。

正文可用性索引识别148个有仓库直接文件的身份、69个当前只列外部文件的身份、9个尚未在该索引定位完整正文的身份。此索引未穷举压缩包成员；“未定位”不等于论文没有正文。历史批次的13篇正文、9项SI待补清单仍需按DOI逐项使用，不与这个索引口径混算。
