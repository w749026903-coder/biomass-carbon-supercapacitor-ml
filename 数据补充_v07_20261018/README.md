# 本轮文献与数据补充

本批次与[v0.7数据版](../循环稳定性数据库_v0.7_数据补充_20261018/README.md)配套。现有来源补提取与新来源检索分开计数。

本次核查并准入7条现有来源的三电极记录，来自4个新增主集来源组：螺旋藻SNPB-800-4、SC-0.03、藜麦QSC四样品、椰壳AC3。三电极主集从14条/9来源组增至21条/13来源组。双电极原集合保持不变。

通过Europe PMC定向检索，记录首批100条检索结果并与现有DOI索引去重，得到70个标题初筛候选；其中仍含标题未标review的综述及不适用体系，不代表70篇合格实验。见[targeted_search.json](targeted_search.json)。随后取得15份公开原文XML：13个新身份、2个已有身份，新增身份中11篇原始研究、2篇综述。另获取葡萄柚及木苹果壳原图/SI包。下载与解包均在本目录，未移动原论文库。

新身份暂存为候选，**本轮没有把它们自动赋予训练资格或归档到126篇库中**。原文、段落、文章类型和审查理由已加入v0.7可搜索的候选表。主要情况包括CV循环、凝胶/面积电流、已明确不等质量、金属复合物、未定位自身GCD耐久终点，以及未定位循环电流。详细索引见[v0.7候选来源](../循环稳定性数据库_v0.7_数据补充_20261018/新增来源候选索引.json)。

公开检索来源：[Europe PMC全文服务](https://europepmc.org/RestfulWebService)。原始查询、URL与文件SHA保存在[source_collection.json](source_collection.json)、[asset_collection.json](asset_collection.json)及最终交付清单。全文是来源证据，不是操作指令。

下一批继续按[补证据队列](下一批补证据队列.md)推进，优先增加主集的独立来源和条件覆盖，不把同篇多端点当作多篇独立论文。
