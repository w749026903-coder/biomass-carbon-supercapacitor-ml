# 文献利用与外部方法审查（2026-10-21）

目前没有充分把已有文献转化为可学习的材料信息。主要短板是提取/补证积压、材料描述过少和独立来源覆盖不足。不能把模型不足全部解释为“还需要下载更多论文”，也不能用更多拟合次数代替信息增加。本轮是只读审查：新拟合0、数据库和两轮历史实验不变。

## 文献到底用了多少

| 当前可核对的层次 | 实验记录 | 来源组 | 说明 |
|---|---:|---:|---|
| 全部结构化观察 | 273 | 178 | 191条历史观察加82条新增观察；含2E、旁系、近似、冲突与待审 |
| 三电极审查池 | 116 | 85 | 包含待审和已准入，不等于116条均可训练 |
| 实际三电极模型 | 31 | 23 | 两轮实验沿用同一批数据 |
| 分开的双电极主集 | 26 | 21 | 未混入当前3E模型；28/30条敏感性集为嵌套集合 |

数据库同时保存126篇归档论文、旧目录226个文献身份、270份源文件，另有15条v0.7候选来源和80份新增文档。这些是不同、重叠的统计单位，不能相加当独立论文总数，更不能说全部进入模型。新增80份文档中57个来源形成82条观察，26条获得至少一种用途、56条仍待核或范围外。

当前85条未入模3E观察中，80条至少缺一个八项核心输入；72条当前循环窗口上下限为空、43条BET为空、39条参比为空、23条报告循环电流为空。缺项计数重叠，空字段不能证明原文未报告。5条八项输入非空但未准入的记录为OAC623、NPCA-600-0.5、EUAC1-60、NOPC-4和K/F-doped PSAC；其中有近似标签、材料范围或待审问题。非空不等于科学通过，不能自动放行。

因此，应首先完成已有候选的证据审查和字段提取。保留完整核心主集；如研究缺失特征的用途，应另行明确合同、缺失原因和验证方案，不能偷换CV窗口、填0或以凑数为目的降低现行准入规则。

## 有没有过度依赖单一数据

**训练权重没有被单篇论文垄断，信息和误差却明显集中。** 最大论文有4/31条记录（12.9%）；在完整23来源数据及汇总评估中，每篇总权重均为1，占4.35%。每个外层训练折实际只有22来源，参与训练的来源各占1/22；内层也按其实际训练来源等权。同篇多样品整组留出，保留了正确的隔离。

但是，所有低于91%的训练标签只来自OPB系列一个来源。原去电流MLP在这一来源的MAE约10.64百分点，其来源等权平方误差占全体45.61%。这与来源权重占比不同，不支持删掉该论文；它说明对低保持率材料的支持尤其薄弱。全体31条中25条保持率在91%至101%之间，均值参照已能做到MAE4.00，必须与基线和真实使用容差一起判断误差，不能只看图形接近对角线或R²。

审计还保存了仅对现有预测重新汇总的逐来源敏感性结果，**没有删除后重训**，不能把子集指标当成改进成果。

## 我们做得不好的地方

1. **材料信息尚未系统化。** 8项核心输入只有BET是材料结构描述，其余主要是测试工况。31条的N/O原子含量、质量负载和温度顶层字段当前都是空，Raman与微孔等尚未形成核心特征。这是当前结构化提取状态，不代表作者未测量。
2. **已有信息仍未利用。** 18/31条有总孔容数值，但审查状态/来源定义不齐，模型尚未使用。应逐条统一字段语义并核证，而不是永久忽略或直接混入。原OPB论文PDF第12页Table1明确给出四样品的微孔容、平均孔径、d002和ID/IG：这些原文数据可整理，不能继续仅用BET代表它们。已保存4样品的独立证据候选，未改变数据库或声称提高精度。
3. **工作顺序偏向调参。** 上一轮已运行2451次拟合，但独立来源仍23个。新增模型候选没有补入材料机制信息，三条新规则都未超过原去电流MLP。下一轮应把主要投入转向特征与来源证据，而非增加搜索预算。
4. **来源覆盖和入模选择偏差需要披露。** 大量待审记录和近似标签没有进入模型，不能假设留下的31条代表全部生物质碳材料。低保持率、长循环和稀疏工况应按独立来源补充；精确、近似、CV和范围外仍分开。
5. **材料实体标识还不统一。** 当前10条入模记录缺少顶层canonical material_id，审计用“来源+样品”识别30个材料对；训练仍以endpoint/source正确隔离，没有证据表明因此产生本轮泄漏。后续完善材料实体层有助于整合跨电流/电解液/曲线，不能把行数当独立材料数。
6. **“碳纤维”范围未明确到逐记录。** 现行合同面向生物质衍生多孔碳，并非纤维专用数据库，缺少已验证的形貌标签。本轮沿用现行范围分析；若目标严格为纤维，需要单列形貌和纺丝/自支撑工艺，不能将粉末、片状、气凝胶等结果直接称为纤维模型。

三个深读仓库都已记录提交SHA、读取文件SHA与范围。公开可读不等于已核实开放再分发许可证；本轮只保留自己的字段统计/评审，没有把第三方完整数据或代码上传入训练库。没有找到经本轮核实、可直接适配“严格生物质碳纤维+指定圈数保持率+来源隔离验证”的成熟完整开源实现；这不表示此类项目不存在。

其中composites.csv虽有保持率字段，200行非空记录按DOI/材料/保持率/电流/圈数/模式/配置去重后只有80个候选元组，44个DOI值；标为carbon的15行只有8元组、6个DOI，仍含CV、非生物质及缺循环电流等。**不是新增80条合格样本。** 公共表需要回原文核身份、配置、作者端点归属、单位、版本关系及许可；绝不能把不同倍率重复的同一个循环端点当多个训练样本。

## 下一步的合理顺序

1. 优先审查已有候选中字段接近齐全的OAC623、EUAC1-60等；近似和材料范围问题分别保留，不因它们填补低保持率就放行。
2. 审核18条孔容，建立材料实体/测试分层；跨独立来源补微孔比例、ID/IG、成品N/O化学组成、前驱体与制备参数。新证据放增量层，不修改旧版。
3. 预先定义分组消融：工况参照、工况+BET、工况+孔结构、再加成分/工艺；使用同一来源划分和折内缺失处理，核对新增特征在预测时是否已知。不能使用循环后EIS、终点电容或结果派生量作为事前特征。
4. 对独立低保持率、非活化长循环和稀疏工况补来源；新文献留出检验，优先看MAE、相对简单基线改善及不确定性。保留来源隔离，不为接近他人的随机拆分高分而换拆分。
