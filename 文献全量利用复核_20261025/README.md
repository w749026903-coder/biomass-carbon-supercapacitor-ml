# 现有文献全量利用复核与首批材料库

2026-10-25用户明确指出：应设计适合现有文献的路线，不能把当前已提取的43条反过来当作文献利用边界。本批据此恢复全库提取，先做可调用的文献证据层，再据审查后的信息量设计实验。尚未完成全部文献利用，没有运行新模型。

## 已落实的数据

- 从四篇已有完整XML的原文中核定7张自身材料表，整理15种材料、88项数值；13种为最终材料，2种为中间体。保留BET/微孔与介孔面积、孔容、XPS原子百分比、Raman强度比、XRD间距及各自测法，不混同未明确的孔宽/孔径。
- 从同四篇论文整理6条自身循环候选：PC-700双电极CV、CF-HTC-AC三电极CV、WhB/BS/WhS双电极有机电解液GCD、AC grain双电极HEC/KOH凝胶GCD。CV扫描速率不是A/g；倍率保持率不是循环保持率；同篇三样品仍是一个来源。
- 当前277条循环观察中没有这四个DOI的结构记录。因此本批不是重复复制既有277条。新材料事实与新循环候选仍需用途审查，训练资格均为0；没有凭表格齐全宣布新增6条训练样本。
- 保存5项明确科学问题：PC-800的XPS合计99.7%；玉米壳微/介孔面积之和超过总面积；玉米芯正文1705与表1770的面积竞争、孔容比例不符；玉米粒多处面积精度表述不同。原值保留，不静默归一化、换列或择优。

已有目录480个身份条目、464个不同DOI值；178条身份能精确匹配现有观察，254条有原生内容但尚未匹配当前观察，48条仍需元数据/身份审查。它们包含综述、旧年度、旁系、SI与版本，不能称为480篇已下载合格论文，也不能将254条直接当254个新训练来源。
