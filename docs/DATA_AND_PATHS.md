## 原文库在项目外

归档原文库的本机位置是 `D:/文献`，其权威路径索引为 `文献整理_20261017/当前唯一文献位置.json`。该绝对路径在云端或其它电脑通常不可用；目录不存在不表示论文没取得或没有实验数据。

`data/source_locations_portable.json`按来源SHA256，列出能在项目普通文件或历史压缩包找到的同内容副本；没有匹配的条目明确保持外部依赖。它只是定位索引，不改变原始路径或归档状态。已按SHA256匹配原137份来源，137份均可在仓库文件或历史压缩包中定位（没有仅依赖外部目录的条目）；第三轮新增SI在其 `external_sources/` 内，另按该目录manifest定位。

需要某份归档来源时：

1. 从权威索引/数据库确定来源ID、格式和SHA256。
2. 在可移植索引查相同SHA对应的仓库相对路径，或压缩包与成员名。
3. 若在压缩包，先列出/选中确切成员，再只提取该成员到项目内新缓存目录，复核内容SHA。不自动完整解压到原文库，不覆盖现有文件。
4. 确认身份后再读正文、SI及冻结记录；不得拿另一篇题名相近的文件替代。

历史绝对路径、manifest和数据库证据作为原始记录保留。不要批量替换D盘路径以制造“可移植”，也不要重跑旧整理程序恢复已经归档或回收的副本。

## 环境

模型依赖见各版本 `modeling/requirements-lock.txt`，Notebook和科学审核说明在各版本目录。以自己的Python环境运行只读核验；不要假设用户本机缓存Python路径在其它agent环境存在。

数据库第三轮、文献扩展和旧版本目录是并行/历史交付，不是可以随意互相覆盖的同一输出。是否合并及如何解除冻结，按任务归属和科学证据决定。
