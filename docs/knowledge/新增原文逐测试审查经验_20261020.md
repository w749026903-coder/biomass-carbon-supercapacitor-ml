# 新增原文的逐测试审查经验（2026-10-20）

本记录来自[本批80份原文](../../新增文献整理_20261020/文献分类入口.html)的正文核读和引用页原图；具体原值、页码和未决处置见[v0.8冲突台账](../../循环稳定性数据库_v0.8_新增文献整理_20261020/冲突处置.md)。它记录本项目经验，不建立无来源的新准入门槛。

1. CV窗口不能自动充当循环GCD窗口。ADD_034 NOPC-4的CV上限0.5V，自己的GCD上限0.4V；ADD_027三电极实际GCD为−0.2到0.8V，不能按常见碳负极习惯写−1到0V。文本丢失负号时回看原图。
2. 原图坐标也有排版错误。ADD_006、010和043的对称器件图仍带参比轴字样；应将装配、实际方法、图注和波形共同核对，不能只凭vsHg/HgO就当三电极。ADD_069的示意图和实际器件结果又提示相反风险，仍留待核。
3. 同篇特殊体系也可能有可保留的普通测试。ADD_052水系/有机分别记录，但水系配置冲突继续冻结；ADD_078纯碳对照与染料复合物分别记录，窗口不能相互复制。反过来，ADD_032实际循环用PVA/KOH gel，不能因为同文3E是6 M KOH就当普通水系循环。
4. 对称配对保留作者证据原话。similar mass/weight、identical electrodes和明确same active mass分别记录；不能将前两种改写成精确已知质量。没有配对证据的记录继续待核，与电流质量分母政策分开。
5. 可解决冲突依实际证据而非写入先后或性能高低。ADD_006自身表/结果支持1774.8而引言漏首位；ADD_074实际测试段和自身GCD图注明确1 M而比较表印11 M。所有替代值保留，不能宣称作者已正式勘误。ADD_025、045、052、059等无法唯一绑定者继续冻结。
6. 去重键须包含测试条件。历史ALPC-800两个相同圈数/电流/100%端点分别属于H2SO4与Na2SO4，不能只按样品名与标签删除。相同研究组仍要合并留出，不能当两篇独立论文。
7. 正文和SI任务按组件对账。旧95项中44项正文找到本批主文，另4项SI任务仅对应主文；没有提供独立SI就不关闭SI。预印本与正式期刊pre-proof不同，综述不能沿用检索阶段的实验分类。
8. 原文易调用不必增加多层副本。新内容直接保存PDF一次，以哈希复用旧PDF；分类HTML与SQLite使用仓库相对路径。原ZIP保留用户目录并记录哈希，无需再上传一份同内容230MB包。接收SQLite缓存与正式版本各有用途，临时未引用预览才可清理。
