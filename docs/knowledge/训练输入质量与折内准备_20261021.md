# 训练输入质量与折内准备（2026-10-21）

本轮依据：本项目已决报告工况合同、ADD_005/019/026/030/052/064原文，以及两份经题名作者核对的官方SI。原值、字段变化与定位见[补证台账](../../数据质量优化_20261021/curation_delta.json)，运行结果见[v0.9核验](../../循环稳定性数据库_v0.9_训练质量准备_20261021/最终核验.json)。不把本项目选择写成所有材料模型的通用标准。

1. “能开始训练”应分开数据输入质量与统计覆盖。完整字段、证据、有效标签、去重、来源分组和防泄漏准备可以达标；二十余来源仍不足以保证泛化、训练大模型或估计稀疏类别效应。不能因为样本有限就反复把已通过的输入降成全部不可用。
2. SI应先按精确DOI定位出版社PII，再核题名和作者。仅200、ZIP文件头或类似文件名不构成身份通过。MF/LYS的SSA2773/2721及孔容1.54/1.52来自自身TableS2，LYS自身窗口必须核FigS7，不借MF图。SI方法中偶见复制的样品称呼也不应自动用于本研究核心字段。
3. 元数据接口不可访问不代表出版信息缺失。RLAC的年份可由自己期刊页脚明确为2025；API失败状态和科学身份字段分别记录，不能错误增加年份阻碍。
4. 配对证据保留作者原话及推断边界，不将same quality直接翻译成实测等质量，不把同一负载与几何程序写成已测双电极总活性质量。本用途的作者报告A/g继续作为描述变量；物理口径不伪造。
5. 图中GCD窗口允许按已审查同样品/配置的轴读取，并保存分辨率。NCHU20自身循环插图按0.1V轴精度读−0.9至0V，不能改用CV−1.1至0V或另一材料图。它不等同取得原始程序日志。
6. 留一来源外层评估和训练来源内的内层选择应同时隔离来源。数值均值/标准差及类别字典只取当前训练折，未知验证类别进入明确UNKNOWN列；外层数据不参与内层预处理。改变验证值、类别、标签后训练编码必须不变。所有这些操作仍是数据准备，研究估计器拟合数为0。
7. 超100%的作者保持率保留，例如本轮PC_NaCl-3的142.22/116.33，不因像离群值就裁到100、删除或改标签。后续须做来源权重和敏感性披露，不能按模型成绩择值。近似标签只进入已声明近似敏感性用途。
8. 训练快照可物化在小SQLite中，历史证据通过只读、哈希验证的父库复用，避免每次只补几条字段就复制完整历史数据库。原文、旧冻结和旧交付仍原位保留；直接SQL和稳定Python接口均须核对同一快照。
