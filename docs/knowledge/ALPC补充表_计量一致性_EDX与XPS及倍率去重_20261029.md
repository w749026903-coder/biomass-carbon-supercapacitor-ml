# ALPC补充表、方法通道和倍率数据经验

来源：10.1021/acssusresmgt.3c00028，本地U024正文与SUP_139 SI；SHA及逐页定位见v6/source_receipts.json、new_facts.json与extraction_coverage.json。

表S1虽能找到数值，也需要量纲、方法和对应总量复核。ALPC-800的S_micro757/S_BET718、V_micro0.382/V_total0.35，以及700的S_micro37/S_BET25，方法未厘清。原值保留并冻结对应字段，不擅自换列或归一化。表中不同面积模型可能产生差别，不能仅凭大于BET直接认定排版错误；训练用途仍需可靠解释，本批不解除冻结。

EDX原子组成与XPS表面原子组成是不同测量通道。ALPC-800 EDX的N11.23/O8.54可用作明确EDX字段；XPS N4.64/O7.44保持原通道，不能以摘要用过11.23便替换已核定XPS。ORR负载0.35mg/cm²、超级电容器1.2mg/1cm²同样分测试用途。

酸性GCD正文421F/g、SI比较表409F/g都留证。正文值有自身倍率图锚点包络支持，当前用途选择421，不把较高性能当选择依据，不称已取得作者勘误。七个酸性CV电容与反序扫描速率没有足够证据逐一映射时，先保留未配对序列。保持率、倍率保持与ORR电流耐久不可混用。

一个倍率图的30个标记中，3个明报1A/g锚点只用于读图标定核验，净新增27个条件。同一条件用同一row_id，普通明报GCD视图包含于含图视图。本批220⊂425，不相加为645独立实验；同一论文的三个材料、不同电流、不同电解液以及辅助任务一起按来源留出。±8F/g读取包络不是作者SD/CI，不强制曲线单调来提高表现。

表S1为嵌入图像，pypdf提取到标题不代表提取到了数值。保存21格视觉转录、原页及图像SHA，并明确没有独立OCR验证；正文/SI文本数值用新鲜PDF解析另查。二手比较28行和DFT10数值格保存至独立表，不伪装新实验或材料训练事实。

主集两行实际新增38单元、16旧单元补证，标签/工况/旧非空值不改；其中共同条件与几何信息相关，不称38独立参数。当前统一可更新入口data.training_latest；v5及以前路由钉住历史，未来批次更新latest指针，封版清单只包含该批entrypoint_snapshot而不固定可变路由。全量目标active，无新拟合、无新循环准入。
