# 补数据时的证据检查

本次适用于“报告工况、普通水系、生物质碳、GCD循环”的现有合同，不将它写成所有超级电容器研究的统一标准。逐条处置见v0.7数据库的record_expansion_reviews_v07与候选索引。

1. **论文数不等于训练样本数。** 新全文可能是综述、CV循环、凝胶器件、金属复合物，或缺必要循环电流。检索命中、已下载、结构化、用途准入分别计数。综述用于追溯原文，不能再生成独立实验数据。
2. **“symmetric”不能替代质量配对证据。** [N-TAC原文](https://doi.org/10.1039/d6ra02137a)同材料器件明确给出负/正质量比约1.2。它可作为独立候选保留，但不自动符合本项目当前等活性质量对称主集；这也不否定论文对器件的命名。
3. **图中参比须与方法核对。** [葡萄柚碳](https://doi.org/10.3390/ma16134577)方法写calomel，Fig3轴标Hg/HgO，暂不替它选择。AC3的通用方法电位符号与多处自身GCD/结果图文相反，则记录双方，以同样品实际GCD坐标及一致结果证据裁定报告窗口，并明确适用性局限。不能按性能高低或写入时间取值。
4. **循环电流不能借倍率测试电流。** YPAC-1、EUO和WAS的现有核读已定位保持率/部分条件，但未定位明确的耐久循环电流时继续待审。孔体积为可选项；未知质量分母仍只是报告工况用途的元数据，不把已解决的问题重新当阻碍。
5. **损失补数保留计算身份。** Heliyon 2024 e25628正文报告损失9.7%、23.6%、40.8%，对应90.3%、76.4%、59.2%是补数，不能保留为直接报告的精确保持率。旧数值/关系及出处保留，新版本追加派生关系。
6. **检查前驱体与残留相。** 尿布来源可能实际取合成吸水聚合物；鹅毛/松木的M-3-25出现Cu/CuO/Cu₂O；竹碳循环可能属于MnO₂复合样品。材料标题含biomass不够，必须绑定实际被循环的样品和组成。
7. **进度也要基于核验。** 本轮曾把待核浓度误称为已发现的旧值错误；回查后确认藜麦原记录已是3 M，没有执行重复更正。今后先查询当前选择与历史，再报告“发现错误”。

具体来源、段落号、原图、保留值与处置理由随版本和Git提交保存。真实模型拟合未执行。
