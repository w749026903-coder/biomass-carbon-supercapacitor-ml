# 多样品系列、图表冲突与前向冻结

依据：第九批藻类DOI10.3390/molecules31132329、杜仲DOI10.3390/polym15030663的本地原文、原图和匹配SI；范围分类另读综述10.3390/nano16090524及煤基研究10.3390/molecules31172997。来源SHA/单元/行列随文献v9；当前循环特征选择随v0.21，旧版和模型不覆写。

1. 多因素系列确实包含最佳样品以外的数据。完整读取杜仲20行孔结构、16×4 CV及16×4 GCD可提高转化率，但不同名称可能是同一对照配方；藻类R3/t1.5明确为850℃、1:3、1.5h同条件。每次报告保留出处，重复条件不增加物理样品或独立来源数；配方看似一致但原值不同也不能直接覆盖或合并。
2. 表图必须互相核对。藻类Table4的850氮2.91at%、ID/IG1.13与自身Fig3e/d的8.3at%、1.01不同，其它四个主样品也有差异。不能只选文本表、最新值或使模型更好的值。本批原表/图均存事实层，相关特征选值null，其它BET/孔容和有效测试继续利用。发现已被当前循环输入采用的有争议值，还须通过新版本向稳定API传递冻结，不能只写一份问题说明。
3. 一条物理成分可有兼容字段。N_at_pct和XPS_N_reported_pct两字段各冻结并不表示多做一次独立实验。N1s中42.6/25.8/22.1/9.5是包络内比例，不是样品总原子%；总N有冲突时不把包络分量乘成伪精确总浓度。前驱体CHNS/O、近似分析和最终碳XPS分开。
4. 循环标签和材料特征分开审查。五条藻类循环标签仍有自身Table7/共同实际协议支持；原始特征冲突不自动删除标签或材料。v0.21只冻结15格，278观察、成员、43/31三电极及27/22双电极、来源权重保持。旧模型指标属于旧输入，不据冻结宣称误差下降；本批没有新拟合。
5. CV倍率、GCD倍率和长期循环保持率不能相互替代。杜仲252F/g的CV@5mV/s、257.8F/g的GCD@0.2A/g及比较表252@0.2各自保存。比较表表征电流不能借给未报告的循环电流。藻类Table8“retained95.2%”属于器件循环百分数，不是95.2F/g；器件功率不倒算成报告A/g，三电极10A/g也不移给它。
6. 算术核验按原印精度进行。37项倍率比值比较原电容的四舍五入区间和作者百分比；不相容者记录，不能悄悄重算覆盖。杜仲Table5成本SUM1.54与分项约15.4不同，保留作者合计、分项、派生和原单位；资源/经济输出不当电化学材料特征。XML的10上标要检查原sup，再解析为科学计数法，不能把10¹当101或10^101。
7. 图中样品名不能随意纠错。杜仲Raman最终图例写EC550，正文/表系列写EC500；350比值图0.623/正文0.648、6h BET表2033.87/正文2300.87和温度系列2h/6h也须记录。不借总体趋势判作者意图，更不根据性能高低择值。
8. 全库目录应包含二手与参考体系的真实处置。综述七表都有引用及概括区间，不能当七套新实验；白石湖/翼城煤的三张自身表也不是生物质实验。分类依据来自原生类型、摘要、方法和表内引用，而不是仅用题名关键词。分类完成不等于全部正文数据已提取。
9. 跨任务来源隔离扩大时，要同时隔离同DOI全部材料、工况、曲线、循环标签和辅助响应。新18条藻类GCD与旧五个循环端点来自一篇论文，不能一边训练辅助任务、一边把同来源循环端点称独立检验。原119辅助行保持，新的137行仍只是9个DOI组。
