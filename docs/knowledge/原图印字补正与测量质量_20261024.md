# 原图印字、文本下限与原始测量质量

2026-10-24。本项目证据见[CMC补正报告](../../持续补正_v017_20261024/release_report.md)及[原图定位](../../持续补正_v017_20261024/CMC_Fig4i_provenance.json)。仅适用于已逐测试核对的本项目材料与文献报告工况，不设通用放行规则。

CMC正式论文10.1039/d6nj00244g的p5 Fig4(i)作者直接标注96.7%，终点15000圈；p2与p6还有点值表述。旧审查只抓到over96.7%而漏核印字，把可用圆整点值作为纯下限拦住。本轮据新增的直接证据更正gt→eq，保持原值和旧冻结链。不能由此泛化成所有over均可改eq；没有明确点值时仍保持下限。

图中电容保持率与CE共轴时，绑定样品、颜色、左右轴、终点、图注与自身GCD插图；这里红色CMC保持率96.7，不是CE。印字转录与无印字的像素读图分别标识，后者须另有轴校准和误差界限，不把两种证据混成作者精确数字。

摘要10000圈后的下限与图中15000圈点值分别保存，不强称作者笔误，也不把摘要下限伪造为精确10000圈观察。同篇不同位置仍算同一来源。旧审查字段留历史，但当前接口应返回当前准入和缺口，防止CMC已获准却仍显示旧缺失BET/窗口的矛盾状态。

材料范围按最终被测试材料核定：CMC使用Co催化后酸洗，正式正文明确ICP-MS残余Co<0.05wt%。记录界限与实际证据版本，不能写成Co=0，也不能声称读到了未取得的SI；中间Co/CoO不自动代表最终金属复合物。此处没有引入统一含量阈值，不能据此替Fe-SN的未决化学态放行。

DSAC公开原始吸附报告可核实负C，13个给定吸附点的78个连续区间未同时满足所核查的BET条件。方法依据来自RSC作者文章[10.1039/D1TA08021K](https://pubs.rsc.org/en/content/articlehtml/2022/ta/d1ta08021k)列出的四项条件；课程汇编未读到对应条文，不冒称IUPAC原文独立核证。该诊断是质量注记；保留作者面积，不挑新范围求放行，不推测未提供低压数据。已知负C疑点与未报告C常数的正常资料不同，不新增一律必须有C的门槛。

核验经验：新增只读层调用父层holds时，父方法可能动态调用子层by_endpoint，从而把新成员投影进旧冻结历史。必须在读取父历史时隔离当前投影，并比较旧holds完整相等；仅保留父SQLite字节不变不足以保证API历史语义不变。本次发现并修正这一调用问题，最终核验包含该回归。

封版复核另发现检查名称遍历集合导致跨进程顺序变化；保留原封版脚本/报告，使用tools/verify_original_label_release_v017.py逐项执行检查，再以完整名称多重集合比较顺序字段，其余精确比较并核对49项SHA。不能用集合去重掩盖检查缺项或重复项，也不能因此忽略科学值差异。
