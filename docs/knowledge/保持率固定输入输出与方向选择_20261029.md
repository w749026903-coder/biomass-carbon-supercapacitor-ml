# 保持率固定输入输出与小样本路线

2026-10-29用户连续强调：主项目目标是电容保持率，原约定输入输出固定。live reported_3e.feature_matrix与v0.6合同核定8输入：cycle_count、reported_current_A_g、electrolyte、concentration_mol_L、cycle_voltage_lower_V、cycle_voltage_upper_V、BET_m2_g、reference_electrode。输出为规定循环次数与工况下的capacitance_retention_pct。

## 什么能调整

科学理由事先限定材料/工况；原输入的数值变换与交互；RF/XGB/BP/GPR/岭回归及有限固定组合。材料/组成/制备元数据可用于规定适用范围和核查同体系，但不能偷偷编码成新增外部输入。原目标要扩展或加早期实测保持率，须用户另改合同。比电容、BET、RUL、分类准确率及其它体系高分均不计达标。

## 试验与局限

小样本方向预研_20261029/保持率固定输入输出冻结251次新拟合：6M KOH+10000圈14/7；再固定10A/g10/6；植物残余物+6M KOH13/9；原47/34的每圈对数保持率变换；13材料/3已知家族的留材料检验；两类等权融合不另拟合。全部外部输入恰为8项，RF等主要模型按整来源留出；家族内检验不称未见来源泛化。1次BP预测无效，保留失败和覆盖不足，不能用其10条部分成绩与全14条结果竞争。

预定RF在前三范围的R²分别−.523/−.546/−.482，MAE5.156/4.121/4.130pp；每圈RF−1.359，MAE7.646pp；已知家族GPR R².220，MAE3.286pp。无候选过全部线，不按外层最高分选新主模型，不继续本计划追加调参。初期偏离目标的986次比电容/BET等方法试验保留作审查历史，其三点倍率插值高分不算项目成功。

原八项中七项相同的OPBNP/OPNP，BET1774.8/1894.9，保持率93.6/83.5，说明相似BET和工况未必能表达掺杂组成差异。它不构成“固定输入永不可能预测”的证明，但提示缩小材料化学范围比只固定电解液更重要。范围过窄还会减少来源/目标方差：R²>.95要求RMSE<sqrt(.05)×测试目标标准差；当前窄范围约需1.0–1.2pp，而非只有RMSE≤3就能过。

## 文献与开源学习

## 仍符合固定接口的重点

1. 从现有原图/SI提取完整R(N)作训练监督，N已在输入中；同材料/试验/来源整体隔离，新材料预测不借用其早期或终点保持率。图读值保留分辨率/读数界限，不能用密集插值伪造新独立材料或更高精度。
2. 在同前驱体、同掺杂体系、同活化路线及测试协议的范围建局部模型；范围靠元数据核查，模型仍8输入。当前4–5材料的小系列不足以证明泛化。
3. 用训练材料曲线拟合活化/衰减参数，再由原8输入预测参数，还原R(N)，允许实测>100。严格核对训练曲线与未见材料/来源；不能先拟合测试曲线参数再称零实测预测。
4. 新库准备后另立核方法与固定融合计划，训练来源内部选型，报告适用域、拒答覆盖与误差区间；不能只在筛出的容易点上称全体达标。
5. 对外部保持率候选先核材料范围、8字段、标签、原文和DOI来源，合格后才训练/迁移。
