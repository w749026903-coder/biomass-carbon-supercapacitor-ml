# 提取数值必须接续到实际训练输入

2026-10-28用户要求：提取的数值应立即寻找合法用途，接入能训练调用的数据库，不能只展示提取总数。以后每批提取同时交付材料/阶段/方法/测试关联、可调用输入与未接入原因；不能把只有索引的数字算已经使用。

本轮建立独立训练数据层，原文献v26与循环v029只读不改。4,469项数值中2,823项已有实际任务输入/目标回执，63.17%是唯一数值fact_id接入率，不是独立样本比例或已完成拟合比例；201项非点值/空值与余1,646项数值逐项保留。当前三电极47条中17条有明确文献材料链接，新增82个非空单元；总48条规范循环有身份关联。不能把4000项材料属性直接当4000个循环标签，但也不能以此为由不做样品关联和适当辅助用途。

具体用途包括：47/34三电极循环、31/25双电极循环、208/31普通三电极比电容与嵌套386/31含图扩展；普通材料BET辅助任务253个材料/47来源；24组明确的前驱体到成品BET配对。材料多属性任务共享样品，不按任务行数虚增独立样本。目标测量块整块排除以避免代数泄漏；前驱体明确标识，比较基准和因子变体不冒充物理前驱体。

材料名关联依据是已有物理身份回执、精确材料键，或同源唯一名称/测试前阶段与自身BET证据；不对缩写做模糊猜测。同一文献/前作家族必须在所有监督与辅助任务同时排除。新增库稳定入口data.training_datasets，提供矩阵/缺失掩码/来源权重与fact_usage回执。

本轮没有追加拟合或新准入，原37待证、15字段冻结及苏铁掩码均保留。新候选列多，不代表应全部纳入模型；必须按训练折内独立来源支持筛选，并审查比值/孔结构/成分测法重复。计数时从SQL实际非空回执按fact_id去重，不能把defaultdict中已访问但没有使用的空键当作已用。
