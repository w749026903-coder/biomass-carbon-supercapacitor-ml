# 电化学与数据定义

核对日期：2026-10-18。以下内容用于数据整理及模型用途定义，不是对每篇论文作者操作的推定。

## 质量归一化电流

质量归一化电流以A/g表示，单位本身不指定单片还是双片总质量。Stoller与Ruoff的方法论文给出两片各10mg、40mA对应4A/g的例子，说明按单片质量报告是存在的方法口径；不能强制把双片总质量当成唯一行业标准。比电容定义中的质量与系数也不能自动决定循环电流的分母。

来源：[RSC正式论文，DOI10.1039/C0EE00074D](https://pubs.rsc.org/en/content/articlelanding/2010/ee/c0ee00074d)，[作者稿](https://arxiv.org/pdf/1005.0805)。本次复核作者稿第3页的配置区别及第6–7页的计算与速率说明。上述知识支持“不同口径应区分”，不证明所有作者采用其中一种。

## 保持率与分母

本项目的目标是同一测试在给定圈数N的电容相对于作者参照的百分比。如果前后使用相同、固定的质量归一化因子，该因子在比值中抵消。这是比值的代数性质，不是证明不同论文的测试应力相同。

因此保存三个不同对象：作者报告电流、质量分母状态、已证实的物理归一化电流。未知状态不改成已核实；经验模型可以使用前者，并披露其不确定性。缺少作者自己的循环电流、跨配置借值或互相矛盾的A/g仍是实质问题。

基线保存作者的初始电容/归一化起点及证据。原文未指明参照的具体圈号时，圈号为空；不猜第1圈，也不因该下标未知而一律否定作者报告的保持率。若作者使用激活峰值或其它参照须单独标注；不能自行混合或换算不同基线。

## 配置、窗口与参比

3E测试测量工作电极相对参比电极的电位；2E器件测量两端电压。上述方法论文明确区分两种配置。不能把3E表征的电解液、电压或电流自动赋给器件循环，也不能把两种配置混成同一主训练集。

3E路线保留报告的电位上下限及参比身份，参比作为该路线的必要描述。若要换算到共同标尺，还需参比条件等独立证据；本项目当前不做无依据换算。

窗口可以来自明确覆盖该循环测试的方法陈述或实际长循环GCD波形；需要记录其适用范围。只属于CV、短程倍率曲线或另一个器件的窗口不够。

## 标签及结构字段

电容保持率、容量保持率、库仑效率和倍率保持率分别存。精确值、约值、不等号、损失补数和数字化估计分别标注。大于100%的作者报告值不截断。BET绑定循环前实际样品；比表面积方法、孔容种类及单位不能互换。可选孔容疑点不自动阻断不使用孔容的主路线。
