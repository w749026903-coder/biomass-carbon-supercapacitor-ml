# 全样品、图文异文与原样品/去灰口径

本条由四篇现有原文的完整正文、14张主表和25个可得原图的指定范围核读形成。证据SHA、表单元、图的印刷label/href及文件路径在本批curation_spec、protected_inputs和merge_manifest中；知识不能替代逐测试准入。林业SI与其它10个主图未取得，不声称全篇完成。

## 经验与处理

1. BET和比电容的去灰折算是同一实验的另一表达。林业论文六种碳的BET原值、作者按TGA燃尽质量折算值分别保存；TGA空气燃尽代理碳分数不等于元素分析C质量分数。水系/有机主表为8:1:1压片电极，含SiO₂/GO涂布配方只在未取得SI，不能按全篇一种配方继承。
2. 逐条件核查可避免把一个争议冻结扩大到全论文。松木WET-1的0.1 A/g正文、比较表写247 F/g，实际Fig7e红色首点低于220，当前不作精确训练输入；DRY-1的146@0.1、59@15及WET-1的64@15均有自身方法/正文与原图支持。其循环94.4/97.8标签没有因此改变。不能按高性能择值。
3. 图注不是唯一权威。松木实际Fig4b纵轴ID/IG、Fig5e印DRY-2，保留与图注IG/ID、DRY-1的异文；不按图顺序猜样品，不把概述0.86/0.89复制给五根未转录柱。He密度不当体积堆积密度。Table2原孔容m³/g保留，DRY-1/WET-1总孔容由正文明确cm³/g补到工作字段；未解微孔容量纲继续掩码，不直接乘一百万。
4. 元素百分比的方法和基准需要分别确认。尿布碳Table2仅称元素分析，未给质量/原子基准，不能自动叫EA wt%或XPS at%；没有NAPC-650-4行，不能继承650-2。木质素/锰Table2方法能确认为SEM-EDX，但百分比基准仍未知。松木C1s子峰约合100，是包络内比例，不能当整体材料的原子百分比。
5. 倍率和循环保持率分别检查。尿布碳250/353约70.8%，正文另称87.65%倍率保持率；后者有明确10k圈、10 A/g循环报告，只保留倍率声称的竞争，不把它复制为倍率真值。实际Fig7/9分别给3E −1～0 V、2E 0～1 V，不用较宽CV方法搜索窗口替换GCD实测。
6. 原图公式也可能有缺项。尿布碳2E原式为2IΔt/(mΔV)，2E的m范围未重新明确；能量图式缺少C。保存字面原式与源图，不自行补成正确公式再称作者报告，也不由能量倒推窗口或质量分母。
7. 含锰木质素的八条电容来自CV 10 mV/s，作者明确GCD、EIS和寿命是未来工作。不能把345.3 F/g补成GCD@1 A/g或生成循环端点。名义F127/Mn投料、实际MnO/Mn₃O₄相及EDX含量分别记录；动力学A/Ea/R²是制备过程响应，不是寿命圈数或本项目模型成绩。字面10 liters、0.3 mm和A的s⁻¹/min⁻¹冲突留存，不猜修正。制备细节引用作者2021年UGM硕士论文，尚未取得，不能当另一独立数据源。
8. 检查接口分母。`reviewed_pending_batch(True)`包含41条历史审查范围，固定持续目标是39条，当前2解决/37待证；不能直接把True视图长度断言为39。此次更正的是新核验脚本的计数假设，未更改任何科学记录。
