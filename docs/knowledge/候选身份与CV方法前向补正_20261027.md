# 候选身份和CV方法的前向补正

依据：[文献v21原值及核验](../../文献全量利用复核_20261027/批次21_候选身份对账与咖啡稻壳工况复核/README.md)、不可变v20数据库、循环v0.26既有端点和`source_relationships`。本批无新循环端点、准入或模型拟合。

## 先查当前审查历史，避免漏连或重复学习

文献层新增候选不等于新实验。v20准备核查直接比较DOI字符串，漏掉旧库不带`doi:`前缀的R104、SRC123记录。当前按规范DOI查找，保留原字符串；相同DOI只产生身份候选，仍须逐材料、配置、端点、循环次数和电流审查。新独立模块`data/cycling_identity.py`在查询时统一前缀和DOI URL；多个字段相互矛盾时拒绝自动选值。历史封版引用的共享函数保留原SHA，不为改进新工具破坏旧验证。

本轮83个文献候选均得到检索审查：32个存在直接DOI命中，51个未命中不视为新实验；6个旧观察的直接字段无可规范化DOI，单独列明。三个LP20候选已核定对应既有端点：Coffee至legacy:R104_CY01、RHC质量比1至legacy:SRC123_CY02、比2至legacy:SRC123_CY03。Coffee98.4%早已通过报告工况用途准入，未知物理电流分母没有撤销该用途。原审查和原始值均未覆写。

稻壳的前作问题早已记录为`references_authors_2016_RHC_study / sample_overlap_pending`。先读此项，再查外部资料。2016[出版社预览](https://www.sciencedirect.com/science/article/abs/pii/S0927775716308627)与2025文的配方相似、BET及孔容不同；这些信息与旧审查一致，既不能证明也不能排除批次/曲线复用。本轮公开检索未得到能够比较原曲线的完整前作证据，没有把重复确认旧摘要当成解决独立性。因此RHC继续冻结，质量比2也没有混入普通对称主集；原固定37条待证不能靠新增候选或改名抵扣。

## 具体图注决定方法，邻图相似数值不能代替证据

2025稻壳论文[原文](https://pubs.rsc.org/en/content/articlehtml/2025/ra/d5ra03028e)Fig6(b)明确为5 mV/s扫描速率。155/167/141 F/g三条旧报告现选定CV、5 mV/s，电流保持未知。新版本用附加决策表绑定，旧SQL空方法及旧条件保留；当前API先应用决策再按方法筛选，否则筛选CV时会漏掉原方法为空的记录。

Fig6(c)是不同电流的GCD倍率，与Fig6(b)分开。即使两个面板的首值接近，也不能将三条CV值当作GCD锚点。四个正负极质量比属于同一材料的测试配置；循环后XPS与电极电位是响应，不能继承为新鲜碳预测特征。

## 读图利用与准入分别处理

咖啡/污泥Fig7(d)三系列12图工况，由3个旧作者均值锚点与9个新近似工况组成。作者SD保留在原报告，图上±4y像素/±2x像素读取界限不解释为SD或统计置信区间。其C/Cg符号仍未统一，只作来源内作者容量用途。RHC另24个GCD点可检查和检索，不能因为获得数值就越过既有样品重叠冻结；矩阵接口明确拒绝该用途。

这说明模型路线要记录测试设计。作者同一RHC在不同正负极质量比下报告不同保持率；若未来使用这类器件资料，质量比及材料/方法/电解液等配置应显式建模或限定研究范围。未报告的质量比不能补1，也不能据此宣称已找到或消除旧模型误差。当前仅完成整理及输入检查，没有重新拟合或泛化改善结论。
