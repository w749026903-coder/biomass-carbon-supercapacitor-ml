# 图号、图例与重叠标记的证据检查

依据文献v18淀粉、稻壳和混合碳三来源，具体SHA、源图、刻度和单点位置见该批curation_spec及核验记录。

1. 图号必须用XML原文`label`和`graphic href`交叉绑定，不能用`.findall(fig)`的排列序号。淀粉论文10.3390/molecules29112532把Scheme1排在Figure1之前；v17四份转录引用因此偏移。v18保留旧库，增量更正13事实、16响应和XPS注记的来源，数值不变；当前来源视图和API保留更正前后路径/SHA。
2. 同色图例不是数据。实际Fig5h的青色图例横线位于y239，和第一段数据接近。1A/g原标记在y245—249附近，必须按原像素限定ROI排除图例，而不能把选错图例造成的正文锚点失配解释成实验误差，或扩大误差以通过检查。原图网格和ROI理由留证。
3. 重叠曲线不能相互代填。126捕获中8个无法可靠定位自身标记，数值和数值界限为空；2个可由自身重复面板的可读表达补回，6个标称条件仍空。未读到的点不是0，不将手工定位猜值作为区间，也不拿另一材料的重叠红线当黑线读数。
4. 坐标网格与电流标签核对。淀粉点含1.5A/g，稻壳含7A/g；不能预设常见均匀序列2或8。标称坐标及±2像素读图范围单列，纵向±4像素不是实验SD/CI。连线只用于显示，不能生成训练点。
5. 复述表达与物理重复分开。淀粉两个系列各在两个面板出现，保留全部原图表达；选择可读且界限不冲突、纵向分辨率更高的表达，不按数值高低择值。三个作者锚点保留原ID，不被近似图值覆盖。标称报告组不证明物理重复身份，同DOI所有任务仍一起留出。
6. 循环图轴角色解决后仍要单独审配置。混合碳ABPC4约100保持率/95.08CE有实际轴及正文支持，但图注3E与正文/结论2E语境未消除。没有循环本地GCD就不能用另一个已知3E倍率窗口替代配置判定；当前配置/窗口均未选，不准入。出版社现行内容核查未取得解答，亦不声称已证明不存在勘误。

适用边界：原报工况用途仍允许未知电流质量分母和精确基线下标，不能把这些已决规则重新加成门槛。这里冻结的是实际证据指向矛盾和不可辨认标记。缺可选BET与核心测试冲突分别处理；所有原值、旧库和历史检查保留，新增语义检查补齐之前的覆盖缺口。
