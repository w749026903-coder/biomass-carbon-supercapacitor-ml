# 全库复检与材料特征准入经验

日期：2026-10-21。来源范围：[本轮原文与属性台账](../../全库复检与特征补提取_20261021/README.md)及原件SHA/页表定位。本页记录项目选择和具体证据，不把项目门槛称作所有电化学机器学习的统一标准。

## 文献利用与计数

本轮把已有31条/23来源的材料特征积压实质补入：33条/25来源训练视图新增或补齐186个材料属性单元。另有480条身份线索、565份已检索原生内容、959个自动表格候选、277条结构化测试观察；这些量各有单位，不能相互替换或相加成独立训练样本。完整全文索引还包含1份不足100字的非空内容，仍属专项待核。

此前来源权重均衡并未解决材料描述和标签覆盖。新增OAC623及EUAC1-60的独立85.5%、89.9%来源后，低于91%的标签由1个来源扩至3个来源；没有修改OPC低值或CCL/NPC超过100%的活化值。本轮没有新拟合，不能把输入扩充直接宣称成误差改善。已知旧外层结果及按覆盖补样的选择事实继续披露。

## 事前特征与协议边界

ALPC使用初始碳材料的N11.23atom%、O8.54atom%及Raman0.97；post-ORR XPS（FigS10）不进入事前预测输入。NPC在50000圈后变化的EIS/XPS也不使用。EUAC正文中117.21%为库仑效率，89.90%才是3E电容保持率，器件93.7%另属锌离子混合体系，三者不互换。

EUAC约8mg/cm²及AHPC标准2.4±0.2mg/cm²按已审3E配置关联；绝对质量24.8±3mg、3.5mg不能变成mg/cm²，电极制备质量也不能自动证明循环电流A/g分母。未知物理分母和基线精确圈号继续保留，既有报告工况用途决策保持。

OAC623的3E、SCE、2MNaOH、实际GCD0–1V与循环0.1A/g/1000圈由自身p3/7/8/9/10绑定。Fig10局部caption1A与邻文0.1不同，原冲突保存；本循环电流由p9及Fig12的明确0.1A/g确定。85.5%为正文报告数，图中近似符号的精度限制保留。

AHPC原表7其它四样品的循环列已作为自有候选转录，但暂不拿优化样品AHPC-850的图代替它们的归一化参照。此处待核的是参照适用性，未新增“必须精确第1圈”的要求。补全后逐条决定，不按字段非空自动放行。

## 调用、插补和验证

核心矩阵仍8字段；使用新增材料属性时显式调用`db.material_matrix()`，其None及缺失掩码原样返回。`prepare_material_fold`在训练来源内做来源等权均值/尺度、类别词表和缺失编码；额外数值字段少于2个已观察训练来源时，该折禁用通道。覆盖规则预先固定、按训练折实施，不看验证标签；原数据库不填0。

同论文多样品同折，同材料多工况共享材料键但保留测试身份；新source分组与原值保护单独验证。训练视图33条就绪不代表所有87条待核都能或应当准入。当前未补到的72条循环窗口不能描述成“原文均未报告”。

## 可复用工程经验

全量盘点要覆盖外部原文库、正文/SI、可读网页、Word和压缩包成员，以SHA去重；目录数、文件数、候选身份和测试数分开。本轮112份压缩包的281个PDF和3个Word成员均已覆盖，未新增无用解压副本。自动表格保留原单元/单位/跨度和未审状态，比较表中的他人数据不直接当该论文自有实验。

格式校验应先于文本兼容解码。首次自动派生索引在构建中识别到非文本附件兼容路径，已在科学使用前修正并清理未引用缓存；原件和有效段保留。已完成的科学版本不因派生检索修正而覆写。

SQLite长摘录直接参与UNIQUE键会产生大量重复索引页。改为SHA256短键后，45950条摘录及ID的逻辑SHA完全一致，四组FTS查询计数不变，索引从287027200降至123699200字节；没有删原文。原生全文用内容无副本的FTS及只读上游段映射，查询校验文本SHA。Windows删除SQLite前需显式close连接，`with sqlite3.connect()`本身只管理事务。

以上经验、保护核验和工具随本任务Git同步，不依赖聊天或全局环境改写。
