# 制备阶段与参数提取经验

2026-10-22。依据[本轮30来源审查](../../主集参数精提取_20261022/README.md)及逐样品定位。用于本项目生物质衍生多孔碳的参数整理；不替代作者原始实验记录或独立专家审查。

## 不把样品名、第一段温度或仪器程序当合成参数

KAC-5原文实验章节在PDF p8：800°C/2 h为前一碳化步骤，600°C/2 h为后续KOH活化，两步5°C/min。SS-300的300°C为预碳化，最终KNO3活化600°C。只按样品后缀或引言最高温度填参会反向标注材料制备条件。

预碳化、独立碳化、活化、前处理、水热与后处理分别建字段。NCHU20的200°C/20 min/10°C·min⁻¹仅是前处理，不改称水热；后续700°C/90 min活化的升温速率仍未知。AHPC500°C预碳化速率5°C/min也未自动移给活化。

TGA最大温度/升温程序、BET脱气、干燥和电极烘烤不当成合成参数。OAC623的673 K和623 K分别按步骤换算，保留名义单位和换算意义，不声称增加精度。微波900 W是功率；EUAC1-60的60 min是作用时间，不是已知温度下的等温保温时间。

## 对照样品与同材料传播

QSC对照只经历前一碳化；QSC-2/3/4才有800°C活化。AC-850是无KOH对照，不能套AHPC的活化参数。AO-PC、稻草AC、CA-AA、SC-0.03的独立碳化明确单列；未声明独立活化步骤的字段保留未知/适用性信息，不用0代表温度。

相同材料键的制备参数可用于同材料的不同测试；测试负载、几何、器件配对不能随材料传播。本轮42条主集审查补及6条同材料其它观察，但所有用途成员和冻结保持。模型中仍按来源分组，不把这些条数视为新增独立实验。

## 负载必须闭合量纲与测试归属

作者明确面密度或给出活性物质质量和实际涂布面积，可记录名义mg/cm²并注明依据；不能把收藏基底尺寸、整张泡沫镍尺寸或未知有效面积强作涂布面积。2–3 mg与2–3 mg/cm²不同，范围不取中点当实测值。OAC623的24.8±3 mg仅是电极活性质量，面密度未知。

ALPC的ORR墨水、超级电容器3E电极和器件总负载是不同对象；本轮只把3E自身1.2 mg/明确1 cm²作为其名义负载。SS-300器件2–3 mg和SSC2-0.6器件体积密度没有传给3E。CSKOH墨水库存18 mg不等于实际沉积质量。WET-1/DRY-1明确约10 mg/cm²属于可保留的高名义值，不因罕见而裁剪。
