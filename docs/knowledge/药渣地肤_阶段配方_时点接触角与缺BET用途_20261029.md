# 药渣/地肤文献的阶段、配方与可调用数据经验

原始来源：10.1002/asia.70648（ADD_039.pdf）和10.1002/ente.202201281（U016/main.pdf），原件SHA及页码见训练输入v7/source_receipts.json、new_facts.json、reviewed_extraction_spec.json。

YZ表1必须按原始药渣YZ、预碳化YZC、最终五个YZPC逐阶段保存。原料表中作者实际报告的微孔零值可存0；没有报告的KAC对照BET仍是null。YZPC-3 0.63/1.223与0.37不相容已有2026-10-21决策，本批不反复当新障碍，不解除冻结，不推算介孔体积。

KOH比例的分母为预碳化物：YZC或KC，不能换成原始生物质。地肤KC800→KAC600是两阶段，KC与KC-800在优化段落中是同一样品，184F/g只录一次。不能凭其它KC温度后缀假设SI内完整参数或结果。原料FTIR不能变成最终碳元素含量；原料TGA“损失/残余”语义不明时不推最终收率。

电极原始比16:3:1与8:1:1可通过分量/总份数显式换为0.8/0.15/0.05及0.8/0.1/0.1，保存原比和公式，不双录两套独立事实来增加利用率。配方分量、压片、干燥和负载属于测试电极程序，不作为BET等本征属性的未来输入。药渣两次12h干燥分属成膜与层压之后，不拼成一个24h过程。

地肤58.25°明确是70ms；药渣正文92°未给时点。保留快照条件，不泛化成平衡接触角。负载2–3mg/cm²用边界，不填2.5点值。相关字段可以进入明确报告工况任务，但与独立物理参数数量分开。

KC/KAC4/KAC6缺自身BET，在独立partial-material GCD任务中使用作者结果、配方和Raman，不借KAC5的1441.3，也不混进已有完整材料用途。器件式明确用两电极总活性质量的61.7/41.7F/g可进入总质量器件任务；三电极90.31%与器件88.83%/5A/g保持分开，本批不新增循环准入。

YZPC器件功率式原印以电压作分母，留原式但不据此计算新标签；不能以能量反推电容来提高数据条数。作者报告WarburgΩ模型/量纲未明，响应任务单独命名，不等同通用Warburg系数。Rs/Rct也作为输出，不泄漏到本征物性预测输入。

出版商列出的SI文件名是真实定位信息，但403并不等于SI不存在或原文缺证已解决。本批62个自身表数值格有独立新鲜PDF解析回执；图中原子基准与70ms标记另行视觉检查。连续曲线/未取SI范围继续列队，不能宣称全篇完成。
