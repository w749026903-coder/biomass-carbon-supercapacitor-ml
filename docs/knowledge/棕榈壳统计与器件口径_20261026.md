# 棕榈壳：原始器件、作者统计和归一化边界

证据：[第七批README](../../文献全量利用复核_20261026/批次07_棕榈壳与串并联/README.md)、原文DOI10.3390/nano16040260及其SI。所有数值和引用文件SHA、单元位置在该批数据库/审计与manifest。

- 逐器件SI不是额外独立文献。同22硬币的132工况含1056响应，不能随机拆分证明泛化，也不能把均值和单件叠加为独立训练例。e1 rep须保留重复关系，商业RC单独标记，不纳为生物质材料。
- 均值±不总是SD。本文明确95%CI、另列S；列表算术核查单列派生量。PK700硬币列表n19、均值49.421、SD14.393，主表n18/均值56.6/SD35.5；PK700N列表n7/52.857，作者n8/56.9。PZ700 Swagelok也有均值差别。不能补造未列样品、删除难点或默改平均；其它组近似重现不代表全源统计通过。
- XPS主表明确wt%，SI则是各C1s/O1s/N1s包络峰比例，两者均不是at%。保留峰位和表中未明FWHM单位，不直接按峰序号认定跨论文同一化学物种。
- 读取实际制备图有收益：正文没有700℃保持时间，Figure1给1h，可独立补齐；同图HNO3为65%，正文30%，该浓度仍冲突null。已解决字段与未决字段分开，不让一个冲突冻结全部材料属性。
- 电容方法和公式必须保留。EIS在1mHz用Eq3计算，GCD Eq1是IΔt/(2mΔV)，不能直接拼器件总质量或其它分子系数目标，不能由公式推电流分母。电学表的A、F、能量效率分别不改成A/g、F/g、循环保持率；原印0.00与空值分开。
- 论文中的retention也可能是倍率比值。Figure6按不同电流相对0.125A/g；真正循环是两硬币串联。方法10000圈、结果2100圈57%、图中C2400与电位−1～1V按原角色保存，不改成普通单器件0～1V/10000圈。

6480项工程/输入检查不是6480条科学准入，也不是旧模型误差因果证据；这批新数据还未参与旧训练。四既有辅助119和DES两用途各12逐行保持，新普通水系循环准入/真实拟合均0。继续其它来源的表图利用，原固定38条待证不抵扣。
