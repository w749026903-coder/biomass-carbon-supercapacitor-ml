# 全样提取中的阶段、测法与图文角色

本条依据文献v17五篇原文、原图及两套SI；原件定位、SHA和逐单元转录见本批curation_spec.json。以下工作选择不代表取得作者勘误，所有异文继续保留。

1. **同样品不同吸附气体不是两个材料。** DOI 10.1002/cssc.202200651的LUK4在N₂下3326 m²/g、1.783 cm³/g，在Ar下1955、1.121（SI S5/S6）。按吸附气体分字段，不凭面积高低择值。LMK1主表/S2为2934，S6为3037，不能靠多数票或最新写入认定；继续冻结标准BET。
2. **工艺温度、产物阶段与原料分开。** 同文挤出25—300℃不等于800℃碳化；球磨控制行的表中螺杆参数不是实际球磨条件。LUK4 polymer/crude的XPS不可复制到洗净最终碳；Ceff分母是木质素加氮源，不是含K₂CO₃的总配料。150℃/h可显式换为2.5℃/min并保留换算来源。
3. **比例必须保留分析尺度。** DOI 10.3390/polym15234478的Table1为体相EA wt%，Table2明确为XPS wt%，不是at%。H/C、O/C数值为质量百分比之比；不能因为名字常见就按原子比解释。DOI 10.3390/nano14161368的原料、预炭和活化成分各行独立，不能用最佳样或摘要范围补齐其它样品。
4. **单位疑点只冻结受影响字段。** DOI 10.1021/acsomega.2c07932的面积在表和正文反复印m³/g；当前未取得作者确认的m²/g。保存原数值/单位，不做体积到面积的数值换算，标准BET缺失。已绑定自身样品、GCD电流和配置的78.70 F/g可用于报告工况辅助任务，不能以可选BET缺失否定全部数据。三次实验/均值±SD的声明不等于获得数值SD，不展开为三条独立样本。
5. **先核循环方法，再绑定电流。** 稻壳97.2%/10000圈明确为200 mV/s CV（正文与Fig9d），.5 A/g只绑定新鲜GCD。CV标签不能转为GCD循环任务，也不能套用附近的电流。
6. **图轴角色比摘要简称更具体。** 混合生物质Fig8c左黑轴是保持率约100%，右红轴标95.08 CE，正文P25支持这一角色。摘要/结论的95.08保持率原说法保留，工作标签约100明确为近似；不是通过选高性能值化解冲突。同文273.41绑定1 A/g有Table3/P23/实际倍率图依据，结论30 A/g异文不进入用途输入。
7. **不从能量反算缺失窗口。** 纤维素2E公式虽能和能量数据作代数比较，但没有明确绑定的物理测试电压就仍为空。Cs=2IΔt/(mΔV)、四倍系数、有机/水系、单电极/器件口径分别建用途。TEABF₄/AN是有机盐溶液，不因作者写IL就当成纯离子液体。淀粉2E图的SCE轴和有符号KOH窗口继续待核，不能取绝对值消除争议。
8. **新论文利用与旧端点补正分别对账。** 纤维素AHC-CL-TU已在循环库准入，新增文献层转录只关联TE011；不可计第二次端点，也不能抵扣原38待证。全样材料、倍率、响应、SI与循环按同一DOI/前作家族整组隔离，避免辅助数据泄漏留出来源。
