# 训练输入误差列与跨来源覆盖校验

2026-10-28，应用于生物质衍生多孔碳、已有论文报告工况用途；不改变循环逐测试准入。

1. **误差列不能直接当物性或独立样本。** 文献v26中10.1039/d0ra09182k的5个样品BET与孔体积有10项`author_plusminus`事实。v1按字段前缀判断遗漏该后缀，产生10条误差目标及其它属性输入。v2从预测输入与目标撤回，保留原值、原行和回执；不能为接入率好看继续使用。源PDF/XML及具体fact_id均见新版本`quality_corrections.json`；不猜“±”为SD/SEM。此前模型权重与分数不改。

2. **测量方法是字段含义的一部分。** 10.3390/molecules31132329正文bodyp22、30与Table6：水接触角、吸液量、四探针压片电导；每行实际电解液/时长未报告。10.1021/acsomega.5c06396的正文与已提取方法是5μL水滴、5min、5位置均值。10.1039/d6ra04144b的bodyp25只有水角度与测角仪；时刻未知。它们不能无条件合并成电解液润湿性。

3. **密度与电导不可跨几何和组分混值。** 10.1021/acssuschemeng.6c00388的原SI S7/TableS7、S8/TableS8、S26/TableS18已渲染核查：堆积/骨架密度及四点电导、密度归一化电导不同；五位置不是五材料；S18的15%行重复S7不增独立样本，12%固含为另一配方。PVP薄膜电导不改成纯碳压片电导。10.1039/d2ra02141b的作者密度使用假定2g/cm³和孔体积计算，不是实测堆积密度，也可能与孔结构构成代数泄漏。

4. **稀疏覆盖要在训练来源中决定。** 新主集122候选列，全部来源上仅30列满足3来源/20%非空的示例条件；不能把这个全数据选列直接用作新实验。新`source_split`每次只读取训练来源的非空率/来源支持，不看目标；测试特征和所有目标扰动反例通过。`source_split_bundle`把同一DOI/前作家族从所有辅助任务一起排除。

5. **利用率需要可核对分母。** 本次新增245事实输入连接，移出10个旧错误，净增235，总3,058/4,469=68.43%。它只度量已提取材料数值的唯一fact_id连接，来自61个有材料事实来源；复核登记65来源，均未整篇完成。不是200多份文件的全文利用率，更不是3,058循环样本。315条谱峰或“±”元数据不强凑预测变量；另6条EDX/DFT误差保持质量分类。冻结、原37待证与未封版文献批次不因本版准备输入而解除。
