# 新来源循环准入、追加接口与跨任务隔离

依据[v0.20核验与调用](../../循环稳定性数据库_v0.20_新增来源准入_20261025/README.md)、voltage_decision.json、admission_review.json、原XML及第五批取得的官方SI和原Figure7。

NWJPC-2在6 M KOH双电极对称器件中，5 A/g、10000圈后保持99.8%，自身BET2916 m²/g。正文和实际首次/末次循环插图均为0～1 V；SI−1～0 V异文保留且标未选。具体循环图直接证据与正文一致，可支持该用途的电压选择，不等于作者正式勘误，不是拿CV窗口推循环。SI预处理5圈0.5 A/g与之后10000圈5 A/g另列，精确归一化圈次仍未知。

当前报告工况用途接受作者A/g，不从SI比电容公式的单电极质量反推循环电流分母。约2mg为制成电极片的表述，未推成活性碳质量或负载。NWJPC水热温度仍空；800℃/2h是活化，不复制优化候选180℃。合并介孔+大孔1.48 cm³/g保留独立通道，标准介孔体积仍空；XPS at%和质量通道分开。SI“Morus alba”异文作为作者报告局限保留，未改原文件。

该记录只向reported_2e及其残留/近似嵌套明确准入。双电极27/22、29/23、31/25，三电极43/31、44/32、52/38均不变；严格统一电流不自动获准。全部278条/179来源组/238材料键。新来源不属于原固定39条，所以原固定已解决1条、待证38条/24来源仍不变，不能把此新增再算成固定队列解决1条。

旧v0.19接口只修已有端点；对不存在的端点增加field_changes不会让父级枚举自动收录。v0.20增加规范化source/material/test/endpoint/evidence表与显式profile成员，并在fetch和by_endpoint完整追加；holds、evidence、field_changes、material_properties、source_aliases、search_native、材料矩阵与分组接口同步兼容。新记录的material_key_v11字段只是旧API兼容字段名，值为新v20m键，没有虚构v11时代的材料或准入历史。

文献v5原候选LP5_SSC和原始资格标记保留历史；literature_links_v20映射到正式端点，面板查询当前链接。保持候选与正式记录两个证据层不等于两次实验，不需要覆写封版候选为已准入。17项材料绑定来自既有791文献数值，不能再相加成808。

若该DOI被留出测试，29条已核定辅助输入、33条原始比电容报告及2条文献循环候选必须全部隔离。119条辅助输入的剩余90条只是这个留出情景的可用行，不是已冻结的新训练计划；同来源标签预训练和学习型预处理同样须隔离。来源组核查有文档边界，不冒称统计独立。

988项核验保留277旧行和旧holds逐项相同、旧历史链、材料值、固定38清单、矩阵/权重/来源折与方法通道。临时构造样例检查真实>100保持率无概率上限，没有修改作者99.8标签。没有新拟合或独立性能验证，不声称误差降低。

工程教训：校验报告中的set遍历顺序不稳定，封版前必须跨独立进程复核，检查名称先稳定排序。v0.20原报告顺序缺陷已由独立只读核验修正版解决，原科学文件未改；当前命令tools/verify_new_source_v020.py，原README/脚本verify命令作为有排序缺陷的历史入口保留。旧文献verifier冻结了当时全局循环指针，切换版本后应通过其不可变manifest核验数据，不能为了通过历史全局状态条件去改旧报告。
