# 原始测量数据、计数与正式版本追踪

本条为持续补正目标的在研经验，不是新数据库准入结论。实际原件、分析摘要与未决项见[当前工作目录](../../持续补正_v017_20261024/README.md)。

原文的数据可用性声明应逐项追踪。DSAC原文给出的旧preview地址虽排版有误，对应公开Mendeley数据集确实存在：[10.17632/f7m96z8dgm.1](https://data.mendeley.com/datasets/f7m96z8dgm/1)。不要只检索正文/SI后就认定没有原始测量资料。数据集页面、文件清单、文件SHA和ZIP成员关系共同保存，按需读成员，避免全量解压膨胀。

仪器程序与实测终点分开。DSAC的计划5000、论文2000和文件2256三个数各有含义。CRV第14列反复1/2，不能当循环计数；要同时核对递增列、电流正负和轨迹，并用文件头控制记录数。未标列名的推断仍需导出表格/制造商文档交叉核对，不能因解析代码跑通就宣称语义通过。

归一化起点未知不能猜第1圈。原始早期有时间截止，某固定电位段的时间比诊断并非作者最终保持率，不能替换论文83.3%或反推其参照圈。真实实验程序只能关闭其实际支持的条件缺口，不能自动证实所有标签。

DSAC BET原始报告的1374.73m²/g与C=−63.443并存。记录到数值出处不等于其测量分析质量通过；高相关系数也不能单独证明BET适用。[明确实施Rouquerol准则的原始研究](https://pubs.rsc.org/en/content/articlehtml/2022/ta/d1ta08021k)可检索原文段落列明C为正、区间和单层覆盖等条件。另查的IUPAC方法合集PDF前25页未定位相应段落，不作为本轮已核读的规则证据。这里先保存异常原值和范围，不能自行选择好看的拟合或补造未测低压数据；报告工况用途的处理还须依现行合同明确记录，不能无说明增加全局门槛。

APS原始报告标的是平均孔半径1.1460nm。半径、直径和4V/S派生口径不可混填；源数据中仪器默认/异常温度及日期不直接变实验条件或文献年份。

正式版可能改题名，不能只查原题名。AC700预印本Tocuweang等的研究现有正式DOI [10.1016/j.ultsonch.2026.108104](https://doi.org/10.1016/j.ultsonch.2026.108104)。作者、样品、关键摘要参数匹配可提供版本关联线索，但正式正文仍需逐值比对；不能把优化Au复合物的循环保持率给无Au对照，也不能将预印本和刊本算成独立来源。网上发表、索引和卷期日期分开。

API响应类型必须检查结构。出版社`full-text-retrieval-response`外壳也可能只有`coredata`；没有正文时就是题录。开放许可、是否已进PMC以及本次下载是否成功是三个不同问题。FULL401、正式页403或某附件404都不能证明没有正式文章/附件，也不授权绕过访问控制。

本条不改写旧知识或封版文件，不启动训练；待实际补正和核验后再更新数据库入口。持续目标仍active，39条未因新下载或Git提交而自动完成。
