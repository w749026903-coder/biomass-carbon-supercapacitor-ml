# 碳化系列、DES与实际循环图裁决

依据[第五批核读与来源](../../文献全量利用复核_20261025/批次05_碳化系列与多电解液/README.md)、原XML、官方mmc1.pdf、原Figure7及两份本地既有SI。结论限于已声明单元，不代表整篇文献已提取完成。

锦带花三电极为6 M KOH/HgHgO，碳的Zn离子器件不反推三电极也含Zn。SI中SSC循环写−1～0 V，正文为0～1 V；本次原Figure7G的首次/末次实际循环插图均为0～1 V，构成与循环本身直接相关的证据，因此选择0～1 V并保留SI异文。这个处理有区别于拿CV或另一个诊断GCD窗口代填循环，不称为作者勘误。NWJPC-2的10000圈/5 A/g/99.8%、自身BET2916已进入正式增量准入前候选清单；当前循环库成员尚未改变，后续仍须审查追加接口、旧记录关系与原值/冻结链。

同一来源NWJPC-1的1 A/g正文133与表133.7竞争，不能仅因表数更多就假称已解决；仅冻结这个倍率标签，其余四电流照常按已绑定协议保留。无三聚氰胺对照KOH:前驱体3:1，掺杂组1:1；不把同一方法的对照用量复制给所有材料。WJHC-180与NWJPC-0虽可能有制备关系，自身1 A/g数值146/129不同、名称不同，未并为一个样品；整DOI分组已经防止这些关系跨验证折。

N1s横杠不等于N元素为0：SI的NWJPC-0总N为0.9 at%，组分横杠意味着未给相应分解值。各N1s/C1s/O1s包络归一化组分不是全材料原子百分比。原表“12.6.”格式异常不静默修复；99.64的总元素合计不归一化补满。BJH介孔+大孔体积不当标准介孔体积，使用空缺掩码保持通道区别。

糖原来源为贻贝工业废水，12组温度/时长自身孔结构、首圈比电容与1000圈保持率可一一关联。液态ethaline的ChCl:EG=1:2是摩尔比，不是电解液摩尔浓度；没有把该比例塞进concentration_mol_L。30℃、银丝伪参比、液态DES与固态SSE器件分别保存。作者±范围未注明类型时不猜SD/SEM；均值100±2%也不裁剪。Raman晶粒尺寸由同一ID/IG公式派生，不当成独立实验；表中Å不默认为nm。

木苹果壳同一材料的多浓度、倍率和扫描结果是独立工况报告，不是多个独立论文。原本地ZIP中的SI确认AgAgCl三电极，27个GCD和66个CV数值可入证据层，33个F/cm³与33个F/g不混。循环只报constant current而无数值，不能从2 A/g倍率测试补入。三浓度自身循环96.07/96.8/95.16与结论“全部超过96.8”保留差别，实际逐组值优先用于候选，不用总结覆盖表述。
