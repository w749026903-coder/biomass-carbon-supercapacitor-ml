# 冲突裁决与来源充分性

2026-10-22。本项目生物质衍生多孔碳、报告工况保持率用途的审查经验。属于项目决策和原文判读，不能泛化为所有实验数据的统一准入标准。

## 作者表格与共同方法可以提供逐样品证据

AHPC原文[DOI 10.3390/molecules31132329](https://doi.org/10.3390/molecules31132329)，本地OA001/main.xml；读过电化学方法、Table7自身行、Fig4图注、结果/验证说明，核对出版社版本索引。Table7明确区分倍率保持率、10000圈循环保持率与CE；共同方法指定10 A/g、6 M KOH、Ag/AgCl、−1～0 V。四个非优化样品均有自己的表格数值。

原审查额外要求每个样品有单独归一化曲线，超出了既定报告工况用途。现接受自身循环保持率表格语义和共同协议，保留未知精确参照下标与归一化电容值；不宣称有逐圈仪器数据，不借优化样品曲线。若表格目标含混、没有样品自身行、共同方法不能绑定或另有分母定义矛盾，此处理不适用。规则不是为凑数量放行其它真实冲突。

验证：只增加四条同篇样品；旧字段和标签不动，五样品同一来源组，旧冻结有前后历史，缺基线/错误类型/未明确准入的输入继续被拒绝。

## 冲突必须保留竞争主张，说明优先解释的边界

C-4[DOI 10.1007/s13399-025-06799-9](https://doi.org/10.1007/s13399-025-06799-9)，本地B_R018/main.pdf。读过p11详细段和Fig8b及p13结论。左轴蓝线初末与138.5/36.45 F/g相符，右轴红线为CE。26.32%是可复算的派生候选，不是作者直接报告值；40%仍保存，BET未报/未定位不能插补，因此整条未入模。原文中间100/约1000圈不符也保留，不能因终点可推导便声称论文所有数字已更正。

LCC/LCNC[原文与附件](https://www.sciencedirect.com/science/article/pii/S0926669026010137)，本地ADD_059.pdf及本轮mmc1.docx。读过方法、孔结构/Raman、Fig8d/Fig10d、Table8、结论及SI全文/唯一孔结构表。p5已明示共同电化学条件，之前漏提，应补回，不能归因于用户没提供资料。SI介孔表面积不是t-plot外表面积；1–2 mg、约1 cm²只作范围，不变成单个实测负载。

LCNC图注和段首支持LCNC-1，但末句写LCNC-3；保存优先样品解释而不静默改材料键或移借BET。78.1%与最后图点约80%仍有差异，不能挑选近末点充作5000圈。LCC的88/89%也未伪造成唯一精确值。图形近似、舍入差异、标签身份和原始实验真值必须区分。

DSAC[DOI 10.1038/s41598-026-63280-x](https://doi.org/10.1038/s41598-026-63280-x)，读p3转换、p6/p9图。硬件Hg/HgO和换算RHE可以同时记录；作者给的+0.924 V不是授权猜循环程序。CV的−0.8～0 V不能自动传给GCD，图单位矛盾仍保留。

## 来源不足与提取不足是两个可同时存在的问题

以[本轮覆盖统计](../../冲突复核与来源充分性_20261022/source_coverage.json)为准：42条/30来源主集，低于91%共8条/6来源，低于85%仅3条/2来源，5万圈仅2来源；18项可选字段覆盖27.25%。单篇多样品不能增加独立来源数，等权后每篇1/30。

已结构化活化温度仅3来源、负载4来源，不足既可能是原文缺报，也可能是未完成字段审查。没有逐篇核方法前不能声称文献不存在这些数据。先提高已有文献转化率，再按低保持率、长循环、稀疏工况补独立来源；下载文件总数不是充分性判据。

报告“探索性输入就绪”和“可靠泛化已证明”须分开。本轮零拟合，旧误差来自v0.10，不能用新条数宣称误差下降。下一轮实验应预先固定计划，以来源分组学习曲线、独立留出和误差不确定性判断是否继续补数据，不给没有验证依据的统一论文数量阈值。
