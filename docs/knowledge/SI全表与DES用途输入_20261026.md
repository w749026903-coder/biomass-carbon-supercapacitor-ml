# SI全表、共同协议与DES输入经验

2026-10-26；来源与各数值边界见[第六批README](../../文献全量利用复核_20261026/批次06_剩余SI与DES协议/README.md)、protected_inputs.json及用途合同purpose_contract.json。

1. 全量利用包括不进入普通循环目标的表征、响应、前驱体和独立电解液体系。糖原SI S1～S6的XPS、Raman、XRD、EIS和自身对比行均按用途分层，60 EIS拟合参数不能直接塞进预实验材料X；La与ID/IG有派生关系，不当独立测量。
2. 既有合同允许自身保持率表与共同协议，以及同样品/体系适用的自身GCD程序。糖原Table3每行同时有首圈电容及1000圈保持率，Figure10各样品首圈0～1 V，SI有1 A/g/30℃/银丝伪参比，可审为单独DES作者均值用途。没有新增“1000圈每圈都必须展示电压”门槛。若图工况不同则不能转借：SSE图是10 A/g前8圈，目标是1 A/g1000圈，继续分开。
3. DES的1:2摩尔组分不是2 M。未知作者质量分母不能单独否决报告工况用途，保持原A/g和未知标记；不将DES偷偷当普通水系扩大主集。作者均值±目标和点值任务分开，不猜SD/SEM。
4. 数字冲突先看自身原图、实际列和样品定位。SSE802 F/g的Figure11e明示0.1→10 A/g，图注及另一正文一致，选0.1但保留原0.01。5h d002的自身表3.7 Å/23.9°与Bragg几何相符，选0.37 nm但保留正文3.8 Å。这是带出处的选择，不能假称作者勘误；不按有利性能择值。
5. 一个DOI的12样品×两个目标仍是1来源，不能随机拆行验证泛化。当前des_model_inputs把X、y、作者±、groups、weights分开，空值保留；其它同测试响应、标识和EIS不在特征白名单。跨来源测试时所有同DOI资料与辅助标签一并隔离。
6. 稳定读取入口可按当前指针指定版本模块；新模块继承旧只读API，不改旧封版代码。验证钉住不可变父库、原文和各载荷哈希，不把可正常升级的全局当前指针永远锁为旧版本；verify保持只读，prepare_reports只在未封版阶段运行。
