# 公开图包、图像读取界限与跨年份器件程序

2026-10-28，适用于本项目现有“文献报告工况”用途。来源为DOI 10.3390/nano12213804、已封版v24、文献v25及循环v0.28的manifest、source_review和逐字段证据。没有真实模型拟合。

## 获取失败的适用范围

出版社429或某个OA元数据接口404只能说明该次端点的结果。不能据此断定没有合法公开原图。该文已有XML明确来自Europe PMC，正常公开接口`https://www.ebi.ac.uk/europepmc/webservices/rest/PMC9655081/supplementaryFiles`本轮返回HTTP200、942451字节ZIP，含Scheme1及Figure1—8共9张JPG和GIF预览，没有独立SI。下载限界、文章PMC/DOI身份、包成员和SHA均保存于v25/acquisition.json。

有些JATS的Figure位于floats-group，`body//fig`可能返回零；须核读整个文章的figure节点、label、caption和实际包文件，不因局部XPath漏项就说无图。图包与主文绑定，不能按通用文件名“HPC”替换。以前的HPC_p15.png属于另篇2024年研究，仍不能用于本篇2022麦壳98.59%/30000圈。

## 读图量、工况与实验数

实际Fig7(d)的3材料×5电流、Fig8(b)器件5电流合计20标记。8个是已有作者正文值对应点，净12个额外标称工况；两用途的author_exact、point_mixed、figure_only是嵌套选择。3E6/15/15、2E2/5/5不能相加，更不是多篇独立文献。

本批采用实际颜色像素、校准轴、局部读取框和±4y/±2x像素包络；三个3E系列y范围约±15.6F/g，2E系列约±7F/g。它们是图像读取界限，不能解释为作者SD、仪器精度或统计置信区间。保存手工定位用猜值与实际测量像素的区别，猜值仅限定ROI，不作为输出；20点都有实际颜色支持、全部8作者锚点在各自界限内。连续曲线、被遮挡点和未见标记不通过插值造样本。

主文P7、P18和实际Fig8(a)一致绑定同一HPC-700对称器件；GCD电压0～1V、1M H₂SO₄。P18明确循环30000圈、5A/g、相对初始电容98.59%。窗口依据适用同器件GCD程序，不是从3E相对Ag/AgCl电位继承，也不是声称Fig8(d)存在循环电压插图。按现有共同程序规则，证据足以进入文献报告工况用途。

年份2022仅允许既有跨年份双电极视图，不改2023—2026主集规则。统一物理电流仍未知：作者容量公式中的Cs四倍因子/两电极总活性质量不能定义电流A/g分母。初始参照明确，精确归一化圈号保持未知，不新设必须第1圈的门槛。
