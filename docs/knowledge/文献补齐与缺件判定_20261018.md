# 文献补齐与缺件判定

本轮依据：[文献获取交接](../../文献扩充_大批补齐_20261018/README.md)、原始`records/`、逐文件SHA256与最终核验。这里记录可复用经验，不替代逐测试的科学准入合同。

1. **正文有多种有效载体。** 经过文章自身DOI核验的全文XML，加上正文引用的完整原图，可以作为可阅读、可提取的正文。未取得出版社PDF时列为可选补充，不重复记作“没有全文”。XML原图不全则单列缺图，不假称完整。
2. **SI存在性与获取状态分开。** “论文明确声明SI但文件未取得”“只在猜测URL得到404”“没有定位SI声明”是三种状态。后两者不能直接写为缺SI；也不能说文章一定没有SI。只取得SI的论文仍可能缺正文，两类数量不能相加当论文数。
3. **逐文件检查SI。** SI可能是PDF、Word、Excel或嵌套ZIP。Europe PMC原包内的已声明SI ZIP应保留为原件，并核对ZIP结构与CRC；不能因解包扩展名白名单漏掉ZIP，就反复向用户索要原包里已有的材料。本轮因此恢复7项来源的SI文件，详见`nested_SI_recovery.json`。
4. **ACS官方SI可以独立获取。** 按论文DOI查Figshare API时，须同时核对`resource_doi`精确相等和`acs.figshare.com`出版社库身份，再读取条目文件。检索结果近似题名不能替代精确绑定；SI已取得也不表示付费正文已取得。每个文件保留条目URL、下载URL、哈希与关联依据。
5. **PDF身份不能只看后几页出现的DOI。** 首页须有目标DOI及合理题名覆盖，或完整规范化题名。正文参考文献提到目标DOI不等于当前PDF就是目标文章。本轮已对全部5份新保存主文PDF执行更强首页核验；XML核对文章元数据节点，不用全文任意位置匹配DOI。
6. **勘误不作独立实验。** [ACS勘误10.1021/acssusresmgt.5c00386](https://doi.org/10.1021/acssusresmgt.5c00386)修正[原文10.1021/acssusresmgt.4c00258](https://doi.org/10.1021/acssusresmgt.4c00258)的SEM/XPS图和元素组成，并补充分析方法。以后引入原文须关联修正前后证据；原文尚未在本轮已知DOI基线中。[Molecules勘误10.3390/molecules30030521](https://doi.org/10.3390/molecules30030521)仅改通讯作者顺序，不涉及实验数据，不能据此无端冻结已有科学记录。
7. **检索词与真实体系之间有差距。** 摘要包含cellulose可能只是粘结剂、模板或凝胶电解液；含biomass也可能主体是NiS、MOF或其它复合材料。先将明显背景、勘误与旁系分开，普通碳候选仍需全文逐测试核对。三电极表征不能变成三电极循环。凝胶前驱体与凝胶电解液分开判断。
8. **失败原因不等于文章无效。** 403、429、证书链或没有公开PDF路径应如实记录。本轮仅对证书链失败使用Windows默认TLS验证的curl复核，没有关闭证书验证、修改系统配置或共享运行时。不得通过放宽身份核验来提高下载成功数。

下载任务按旧证据缺口、体系相关性、三电极线索与覆盖范围排序，不按性能高低筛选。所有新来源暂存；正文、SI取得、逐记录提取、用途准入与真实训练分别计数。完成下载以后继续补证据，不将清单完成率冒充数据库训练就绪率。
