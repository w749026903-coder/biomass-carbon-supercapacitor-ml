# 全量提取的分层、表候选与竞争证据

2026-10-25；适用生物质衍生多孔碳文献库。出处与完整读表范围见[第二批](../../文献全量利用复核_20261025/批次02_紫玉米芯与对照/README.md)、其table_review_receipt.json和source_protection.json。仅核过的表与方法段支持以下判断，不声称两篇所有曲线完成。

1. 材料参数与比电容测试分层。同一材料在CV、GCD、EIS、酸液、碱液和不同归一化单位下的比电容，按实际测试记录存储；不能合成材料的一个不变特征，更不能混入循环保持率标签。全部辅助任务也必须按同DOI来源整组隔离。
2. DOI 10.1021/acsenvironau.3c00048自身Fig4/6限定CV5mV/s、GCD0.5A/g，SI Table7S有八列分组表头；逐列看原页后绑定。F/cm³与F/g不互换，CV扫描速率不存A/g，EIS无CV速率。
3. SI Tables7S、8S、9S的AC-5% EIS酸/碱70/25与25/70冲突，不能因看似对调就自动纠正。四报告值和出处共存，冻结标准值。AC-30%XPS元素标签与BE也不能自动互换；保留作者数值并限定。
4. “Below the error”与“未报告”不同。正文Table1 AC-30%的四个“-a”存null并注明低于误差，不能填0；SI Table7S两个“-”存未报告。XML可用ASCII“-”呈现脚注，解析器需核对原脚注，不能只识别Unicode负号。
5. 摘要76%/50000圈不能解决循环配置/电解液/循环与读数电流的图文竞争。材料表可先提取，循环候选继续冻结；不能整篇搁置，也不能整篇放行。未知电流质量分母不另设全局拒绝门槛。
6. DOI 10.3390/molecules29225413以resorcinol/formaldehyde制备，未报告生物质来源，保留为方法参考。比较表中“This work”可定位自身样品，其它六行不是该文新增六个实验来源。不从“与生物质材料类似”的讨论推断其原料属于生物质。
7. 原959自动表候选有跨两张表合并的情况，候选数不是实际表数，更不是样本数。第二批10张表对应8候选。已提取指定字段不等于整篇全部参数完成；历史725属性有171项同源表线索，同源SHA不等于准确表单元匹配，不能重复计新增。

实施：文献层v2保留v1完整行，新增SI逐表文档出处、转录原始行、分工况比电容、用途判断与历史对账。新data.literature_v2接口返回实际SI或正文路径/哈希/定位，旧v1 API封版代码保留。404项检查与原文渲染核对通过；工程通过不解除科学争议。所有新材料/测试资格仍0，正式主集43/31、固定39条中38待证，真实拟合0。

防回退：后续每批核验候选→材料→测试→来源组路径；不同方法字段分开、空值不归零、前作不当自身、重复不当独立样本；进度页与SQLite同快照筛选/导出，提取与准入分开。完整目标仍active，不用局部新增量冒充全量完成。
