## 目录归属与空间规则

- `data/`负责稳定调用，`docs/`负责现行入口、知识和进度，`tools/`负责可复用工具。
- `循环稳定性数据库_v0.*`为版本化科学交付，旧文献批次目录为出处和审查历史。原位保留，通过索引区分用途；不为根目录好看而移动并破坏证据路径。
- `.venv`是可用依赖环境，`.git`和LFS对象支撑版本与同步；它们有明确用途，不能仅因大就删除。不在本任务清理系统、共享运行时或外部原文库。
- 临时工作可用已忽略的`.local-literature-cache/`，记录用途；正式需要的原图和证据先移入本批正式目录并核验，再清理缓存。仅被忽略不代表可删除。
- 清理须有明确路径、无证据引用、保留正式替代或可重建来源的依据；逐文件核对哈希和边界，禁止`git clean/reset`、粗暴递归删除和批量改写原始资料。
- 小修改更新已有入口；不重复生成整库副本、全量压缩备份、长交接或一次性脚本。必须新增的交付清单应能解释用途，缓存与失败响应在收尾处理。
