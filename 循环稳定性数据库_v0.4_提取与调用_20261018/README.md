## 以后调用数据库

稳定入口在项目根目录的data/cycling_db.py；不必再到多个Excel或JSON里逐个找值。仅需Python标准库，SQLite默认只读。每次打开默认验证数据库指纹；同一会话内查询使用已验证的索引缓存。

```python
from data.cycling_db import open_database

with open_database() as db:
    review = db.fetch("review_3e")       # 53条，审查用途
    ready = db.fetch("strict_3e")        # 当前0条，不回退到候选
    row = db.by_alias("TE", "TE005")
    evidence = db.evidence(row["endpoint_id"], "concentration_mol_L")
    holds = db.holds(row["endpoint_id"])
```

可选profile：strict_2e、strict_3e、review_3e、all_review、proposal_2e。review/proposal取数会返回用途、字段状态和来源组，但拒绝导出为“已准入训练矩阵”；严格集合为空时也明确报DataNotReady，不悄悄补0、插值或换用候选。

`fetch(..., year_min=2023, year_max=2026)`可按已核出版年过滤。三电极审查集保留较早论文，不能把全部53条都当作2023年以来的主队列。`source_folds(5)`只生成来源分组索引，不训练模型，也不代替前作和材料独立性终审。

`db.search("672.19")`可定位正文/SI页或XML节点；`db.claims(doi=...)`读取隔离的自动线索；`db.queue()`按优先级读取后续逐篇队列。[example_usage.py](example_usage.py)为可直接运行的演示，研究拟合调用为0。

## 数据如何组织

主数据库为[cycling_v0_4.sqlite](cycling_v0_4.sqlite)。继承的v0.3表完整保留；本轮新增表承担模型调用：

- model_materials → model_tests → model_endpoints：材料、实际配置/测试和终点分别记录。同论文多样品、多电流/电解液、多圈数和多温度保持同一来源组。
- field_observations、field_selection、field_selection_history：保留原值与每次选择理由。每字段有单位、状态、源文件哈希、页/节点、原文片段和继承审查依据。
- document_sources、paper_documents、source_segments、source_search：内容哈希去重、主文/SI归属和全文索引；原文件保持原位。
- model_feature_cache：由当前字段选择生成并建立体系、年份、来源组和身份索引。字段审查发生变化而缓存未更新时，接口拒绝读取旧缓存。
- admission_reviews和training_ready_2e/3e：逐条准入独立保存；本轮没有新增approved。
- native_measurement_claims、candidate_measurement_claims、extraction_queue：自动线索、原候选表声明及逐篇待办，均与训练数据隔离。

当前合同见[data_contract.json](data_contract.json)，字段含义与状态见[字段字典.json](字段字典.json)，全部SQL结构见[schema.sql](schema.sql)。元数据、ID、年份、来源组和标签不作为预测输入；循环前表征与循环后信息分开。核心7项和可选总孔体积按用途保留，未知分母不因有A/g字样而转为规范电流。

## 本轮发现并处理的实质问题

1. TE005的KOH浓度由候选6 M更正为原文方法/3E结果一致的2 M；TE044由6 M更正为3 M。旧值和更正证据保留。
2. TE043在原文定位到3000圈的5 A/g循环电流。原本的approx关系得到确认，仍不改成精确标签；电流分母继续待审。
3. FRPCK-Urea方法写6 mol/L KOH，而结果/图注写1 M。规范浓度置空并保留两方证据，不按最新段落选值。
4. YPAC-1的BET表头m²/g与正文cm²/g冲突；FWCA-4和DRY/WET样品总孔体积存在m³/g印刷口径争议。规范输入暂不使用，原报告数值仍可追溯。
5. u-MPC采用自己SI中的1704.20 m²/g，没有套用前体MPC-800的1554.54；NSHPC2从SI补到672.19 m²/g。微孔体积和BJH孔体积不改名成总孔体积。
6. HPC-KCO在−60℃/100℃是同材料的两个测试，已通过材料别名和测试温度分开表达。定性“接近100%”保留为定性线索，不伪装成精确100标签。
7. 方法/CV/GCD窗口与真正长循环窗口分列。只有直接写明长循环范围的证据才新增绑定；没有把整篇表征窗口自动继承给所有循环。
