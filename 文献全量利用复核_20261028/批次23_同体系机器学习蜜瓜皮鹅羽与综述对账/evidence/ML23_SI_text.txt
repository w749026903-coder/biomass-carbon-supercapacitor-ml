This article presents three tables alongside the typical data processing steps employed in developing a machine learning (ML) model.  
The ML model described herein was trained using data compiled from the literature, following standard preprocessing procedures. 
1. Data collection (Table S1) 
Experimental data were extracted from published journal articles, encompassing key performance metrics such as carbonisation temperature and duration, 
surface area, pore volume, voltage window, current density, specific capacitance, and other relevant parameters. These data points were systematically 
compiled and are presented in Table S1. 
2. Data Preprocessing  
To ensure the dataset is suitable for ML model training, the following preprocessing steps were applied: 
• Data Cleaning: Duplicate entries were removed, and all measurements were converted to consistent units. 
• Feature Normalisation: Features were standardised to have zero mean and unit variance. 
• Encoding: Categorical material features were transformed into numerical format using label encoding. 

PAGE 2

• Cross-Validation: The dataset was partitioned to validate model performance and prevent overfitting. 
 
3. Model training 
The ML model was trained to learn the relationship between input features (e.g., surface area, pore volume) and the target variable (e.g., specific capacitance). 
Model performance was evaluated using standard metrics, including the coefficient of determination (R²), root mean square error (RMSE), and mean absolute 
error (MAE).
