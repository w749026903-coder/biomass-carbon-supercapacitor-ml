- Figure1明示煅烧600°C/30min、Ar0.5L/min；只绑定对应已煅烧碳布电极。未煅烧的温度/时长/流量不填0，独立木质素不继承图中的WCF气流值。
- 独立木质素BET0.3576/0.3439m²/g来自SI TableS1，不能代替不可重复测量的复合碳布BET。SI孔宽/孔径保留Å及作者字段，不把未知模型方法混成统一平均孔径；属性预测屏蔽整个孔结构测量块。
