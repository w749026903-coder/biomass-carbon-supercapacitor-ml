## 实际接入量与分母

原文献库有4,670项材料事实，其中4,469项为数值、201项为非点值或空值。本轮按唯一fact_id去重，2,823项数值已有明确输入特征或辅助目标回执，接入率为2,823/4,469=63.17%；其余1,646项逐项列出原因。这是本轮已准备输入的接入率，不是独立样本数，也不是模型实际拟合使用率。纯材料目录另保留全部458个材料/阶段登记、65个来源、全部事实原值、方法/单位、SHA和页表图定位。

按任务去重的数值事实：当前三电极循环表129项、所有现行循环用途262项、全部已接入比电容用途1,017项、材料属性辅助2,732项、前驱体路径111项。任务之间共享事实，不能相加；总去重仍2,823项。

## 使用方法

```python
from data.training_datasets import open_training_datasets

with open_training_datasets() as db:
    cycling = db.matrix('cycle:reported_3e')
    capacity = db.matrix('capacity:3e_reported')
    material = db.matrix('material:ordinary_biomass_pretest:BET_surface_area_m2_g')
    # 每次留出文献时，对所有辅助任务同时排除同族来源
    training_only = db.training_bundle(exclude_sources=['10.1016/j.heliyon.2024.e25628'])
```

返回X、y、feature_names、missing_mask、groups、来源等权sample_weight、协议与来源留出是否可行。没有把空值变成0或提前填补。fact_usage(fact_id)可回查每一项进入了哪张表、哪一列、哪条记录，material_catalog()和canonical_cycles()可读阶段、制备与原观察；review_queue()给出未决身份/准入。常用表另有同名CSV，可直接打开。

## 科学边界与未决

- 物性辅助任务保留明确方法和单位。XPS原子/质量、EDS、Raman比值方向及不同孔结构方法分通道；没有用不明百分比冒充原子百分比，也没有把孔体积印刷单位猜换算。
- 材料属性重建时屏蔽目标所属整个测量块：预测BET时不输入孔面积/孔容去做代数重构，预测XPS时不输入同一XPS组成去凑补数，Raman方向及派生量也整块隔离。
- 前驱体配对只接受明确物理变换路径。比较样品、温度变体或因子矩阵中的基准关系不是前驱体；5组初步配对已转入保留表，不作为当前训练输入。没有把前驱体值伪装成成品实测值。
- 原37待证、15旧字段冻结与苏铁N/O掩码维持；跨循环、比电容和材料任务检查了冻结，原先缺材料参数但协议完整的14个比电容用途仍保留，未凭缺BET额外否决。
- 未接入的1,646项中，有专门用途尚待定义的量、方法/单位或成分基准未决、竞争报告、不同阶段/参考体系及不确定度元数据。每项保留原值与出处，不能靠改名字强行变成循环训练标签。201项非点或空值单列，不混称未报告。
- 本轮新增拟合0次。v1.2此前560次训练结果不改，也不宣称数据接入已经改善精度。后续需要使用本入口冻结新的有限实验，并在各任务同步按文献/前作家族留出。
