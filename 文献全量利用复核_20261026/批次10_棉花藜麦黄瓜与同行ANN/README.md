## 曲线与同行机器学习

70个新增采样来自4面板/13曲线组：棉花25、黄瓜10、NFAC温度20及配比15。同一NFACc曲线跨面板共享组。累计128图点/23组/7面板。局部标记像素范围加2px校准给出有界近似量，不是统计置信区间；图点不冒充精确正文标签或独立实验。原图轴、颜色、像素、SHA和误差均在curve_samples.json及SQLite中。

NFAC同行ANN预测比电容F/g，不是循环保持率。其“200余样本”不等于200篇独立论文，90/10随机拆分没有报告按论文来源隔离；min-max是否只在训练集拟合未明。10输入含Rs，只有预测时实际可用才能使用；不能一律定性为泄漏。正文两层20神经元与权重表10隐节点表述不完全一致，保留争议。8个自身预测的算术均值287.75 F/g与作者289并存。

240个ANN权重/RF重要性数值仅入peer_model_cells_v10，不计材料事实、真实训练样本或新增论文。正文所称Excel数据集不在取得的公共OA包/PDF中，PDF无附件；不能由权重或散点捏造200行数据，也不证明作者没有数据。peer_model_review保留来源、验证方式、边界和缺件。
