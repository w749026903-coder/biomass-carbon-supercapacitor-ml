# 花椒皮籽与椰枣叶：文献 v15

本批从两个尚未进入文献层的原始研究范围提取数据，父库 v14 保留。14个登记包含12个最终碳材料及2个原料；新增156条材料事实，其中154条数值、2条“接近1但无精确值”的空值；24条电容报告、38条响应、12套分阶段制备。它们不是156个独立实验。

当前累计225登记、2447材料数值/2539事实、856电容报告（852数值、2未报告、2仅区间）、2566响应。原959表候选仅新增触及3个，累计149触及/810未触及。3个自身正文表及1个SI比较表的自身行经过审查；SI6个他引行不转成自身实验。所有39个来源仍未声称全篇定量利用完毕。

## 来源和用途

- 花椒皮籽，DOI `10.3390/nano14100836`：十样品孔结构、十个原图印字Raman积分比、两个最佳样品的XPS及正文16个倍率工况。原料成分独立登记，不继承到最终碳。SI p3两条电容复述绑定已有1 A/g工况；不重复扩样。
- 椰枣叶，DOI `10.3390/nano12010122`：两个样品的BET、DFT、DA孔参数及实际Fig3原子百分比和C1s包络内面积。正文4个自身GCD工况。方法与实际Fig5/6均支持Ag/AgCl，正文SCE异文保留，不宣称作者勘误。原XML/ePMC发表年2021保留，不能由卷期/DOI猜新年份。

新增20条普通3E辅助输入，涉及这两个DOI；累计普通3E176条/18DOI，四类辅助192条/19DOI。新批来源权重每篇总和1，无插补、无新拟合。当前循环库仍v0.25，主集44条/32来源、2E31条/25来源，原38条待证、15历史冻结、苏铁绒4个N/O通道均保持。

两条花椒器件循环只作为候选：PAC700约99.1%、SAC600约93.4%，10000圈/1A/g/6M KOH，物理器件循环电压未定位。三电极−1～0V/HgHgO不能移给器件。PAC已在历史循环库登记为`candidate:V05:034`，见`cycle_identity_review.json`；本批只是复核关系，不再加一个独立端点。SAC原图实际标签600与正文一致，图注700异文保留。

## 冲突与方法边界

花椒Table2各组分是全表原子百分比，椰枣Fig3拟合面积是C1s包络内部百分比。PAC700 C组分和80.93与总C80.84有0.09差异，原值均保留，不归一化；花椒两样品S-II/S-IV表中0与可见拟合分量存在争议，这些组分特征冻结，元素总S不改。Date的DA孔容与DFT孔容采用不同模型，不互换或强行闭合；“lower confidence limit”按软件原标签保存。近1的Raman不伪造为精确1。

花椒4mg是浆料投料，实际工作电极约2mg；椰枣1.4/1.8mg·cm⁻²是包含PTFE的涂层负载，不当纯活性碳质量。椰枣初始碳化条件未在本篇报告，球磨5～7h保留范围。花椒KOH的1:1比例来自10wt%×20g溶液/2g炭的配方算术，非额外实测。
