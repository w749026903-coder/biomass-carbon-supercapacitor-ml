## 定义和冲突处置

1. SNPB原文是IG/ID=1.162，原值保留，ID/IG倒数有明确推导标记。CA-AA的2.18与邻近定性描述不一致，暂不选为标准Raman字段。
2. AMFS给出孔半径1.82nm，未直接填成孔直径。RMAC的孔范围积分值和SSC的“介孔+大孔”体积保留各自定义。
3. YZPC-3表中微孔容0.63、总孔容1.223与比值0.37不相容；原表已查看，保留双方，微孔容/比例继续冻结。WET/DRY原m³/g单位冻结不被本轮补字段覆盖。
4. A-BC-0.2本体元素分析N2.77wt%，其未活化前体BC-0.2为1.46wt%；没有互借。NCHU40的6.2wt%没有填给NCHU20。
5. XPS总元素百分数、峰内组分百分数、元素分析质量百分数、原料与成品分列。循环后或ORR后表征排除在事前预测输入之外。新负载值只应用于已核定3E配置。
6. 默认作者报告A/g与未知质量分母共存；没有推算物理电流或擅自要求精确基线圈号。OAC与EUAC的原先冻结/待核历史由父库和新决策前值完整保留。

详见[知识与工作经验](../docs/knowledge/全库复检与材料特征准入_20261021.md)。证据摘录含代理转录/概述，不冒充逐字原文；原件及定位为核查依据。

## 存储与保护

没有复制父SQLite或原文库。自动检索索引采用内容哈希去重、只读上游文本映射与全文索引；候选与已选字段分开。已清理本轮无引用派生缓存431496027字节（约411.51MiB），并将冗余长文本去重键改为短哈希，索引再减少163328000字节，逐值及FTS查询核验一致；当前索引约118.43MiB。见[清理记录](cleanup_record.json)、[索引优化核验](index_storage_optimization.json)。这些是本轮处理峰值占用的释放量，不声称整个项目相对任务开始净缩小。

原PDF、SI、旧数据库、旧实验和可用环境保持。Git同步按根AGENTS限定本任务文件；科学manifest封版后不在原位追加索引或改动已交付版本。
